# A Mon Burmese Dictionary (DATA source)

A modern, offline Mon–Burmese dictionary data source prepared for iPhone and iPad, built with SwiftUI.  
All content is based on the "A Mon–Burmese Dictionary," compiled by Nai Sac Lun (first and second editions).

---

## 📖 About This Project

The Mon2MM Dictionary aims to make the rich vocabulary and knowledge of Nai Sac Lun's "A Mon–Burmese Dictionary" easily accessible in digital form, supporting the preservation and study of the Mon language.

All dictionary data was meticulously converted and proofread to ensure accuracy and faithfulness to the original printed works.

---

## 🏗️ Data Source and Preparation

- **Source:**  
  - “A Mon–Burmese Dictionary,” compiled by **Nai Sac Lun** (First & Second Editions)
- **Acquisition:**  
  - Data was kindly provided in Microsoft Word format, using the legacy Mon ASCII font call 'Motmalom'.
- **Conversion:**  
  - I use the [N-Uni2Uni.zip](https://storage.googleapis.com/google-code-archive-downloads/v2/code.google.com/mon2uni/N-Uni2Uni.zip) converter, that developed by "Nai Tala Chan" to transform old Motmalom ASCII text into modern Unicode (Mon Unicode standard), ensuring correct display on all devices.
- **Automation:**  
  - I used **Kofax RPA** to extract, map, and structure dictionary entries from the MS Word files, generating a clean database for use in the app.
- **Verification:**  
  - Every word and definition was carefully checked against the printed dictionaries for accuracy in spelling and meaning.
