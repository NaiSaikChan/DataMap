ဆ (န) ခုနစ်လုံးမြောက်မွန်ဗျည်း။
,ဆ (န) အဆ။/ ၜါဆ = နှစ်ဆ။/ (သဗဓ) သမျှ။/ “ဆကၠောန်လဝ်ဂှ် ရံၚ်ခိုဟ်ဒၟံၚ်ရ။”= “လုပ်ပြီးသမျှ ကြည့်၍ကောင်းသည်။”/ “ဆကွတ်နွံဂှ် အ္စာပ္ကတ်ကဵုမၚ်ဗၠာဲ အိုတ်သ္အးရ။” = “ရှိသမျှအ တတ်ကို ဆရာသည် လုလင်အား အကုန်သၚ်ပေးလိုက်၏။”/ (ဝိ) လောက်မျှ။/ “ကၠဇၞော်ဆ ဂၠဴရ။” = “ကျားသည် နွားလောက်ကြီးသည်။”/ (နစ) သလောက်။ မျှလောက်။/ “ဆဂှ်ရဒး ကၠောန်။” = “ထိုမျှလောက်သာ လုပ်ရမည်။”/ (ကြိ) မှန်းဆသည်။/ “မူဒှ်ကၠုၚ်မာန်ရော ဆစမ်ရံၚ်ညိ။” = “ဘာဖြစ်လာနိုင်မလဲ မှန်းဆကြည့်ပါ။”
,ဆဂး (သဗဓ) သို့ရာတွင်။ သို့သော်လည်း။ ဒါပေမဲ့။
,ဆဆဵု — (ကြိဝိ) အရမ်းကာရော။ ပစ်စလက်ခတ်။ တန်ဖိုးမထားဘဲ။ ထိန်းသိမ်းခြင်းမရှိဘဲ။/ ကၠောန်ဆဆဵု = ဖြစ်သလိုလုပ်သည်။ သေသေသပ်သပ်မလုပ်။/ မၞိဟ်ဆဆဵု = ပစ်စလက်ခတ်လူ။ စည်းမရှိကမ်းမရှိသောသူ။/ “အပေါတ်တအ်ဂှ် ရပ်စပ်စကာတုဲ လ္ပထောံလဝ်ဆဆဵုညိ။” = “ပစ္စည်းတို့ကို အသုံးပြုပြီးလျှင် ပစ်စလက်ခတ် မပစ်ထားပါနှင့်။”
,ဆဗၞတ် (ကြိဝိ) တော်ရုံတန်ရုံ။/ “တၞံကြုက်ဏအ်သတ်ဆဗၞတ်ရ။” = “ဤသရက်ပင်သည် တော် ရုံတန်ရုံသီး၏။”/ ‘လောန်ဗၞတ်’ ၊ ‘ဒးဗၞတ်’ တို့နှင့်နှိုင်းယှဉ်။/ (ဝိ) မျှလောက်။/ “အဲလေပ် လိက်မန် ဆဗၞတ်ဂစိုတ်စှ်ရ။” = “မွန်စာကို အသတ်ဆယ်မျိုးမျှသာ ကျွန်တော်တတ်ပါသည်။”
,ဆဝတ်ပြေ၊ ဆဗၞတ်ဝတ်ပြေ — (ကြိဝိ) ဝတ်ကျေတန်းကျေ။
,ဆၜိုတ် (ဝိ) မျှ။ မျှလောက်။ မျှသာ/ “အဲမိက်ဂွံဟီု ဆၜိုတ်ဏအ်ရ။” = “ဤမျှသာ ငါပြောချင်သည်။”/ ‘ဆ’ ရှု။
,ဆာ (နဝိ) (အရည်) ကျဲသော။ မပျစ်ခဲသော။/ “ပုၚ်ၜိုဟ်ဂှ် ဆာလောန်အာရ။” = “ထမင်းပြုတ်သည် အရည်ကျဲလွန်းသည်။”/ “ပ္ဍဲကာလဂှ် သၟတ်ဗြဴဂှ် ဆီဥတုဆဒးဗၞတ် ဟွံခန်လောန် ဟွံဆာ လောန်မဒှ်ရ။” (ဇ—၄၉၇။ အစွောံ။) = “ထိုအခါ­ ထိုမိန်းမငယ်သည် ရာသီသွေးအနေတော် မပျစ်လွန်း မကျဲလွန်းဖြစ်၏။”/ “လှိုက်သရီုဂှ် ဍာ်လုပ်တုဲ ဆာဒၟံၚ်ရ။” = “ထိုရွှံ့ညွန်ပျောင်းသည် ရေဝင်၍ မပျစ်ခဲဘဲ ပျော့နေသည်။”
,ဆာဆာ (နဝိ) အရည်ကျဲကျဲဖြစ်သော။/ ပုၚ်ၜိုဟ်ဆာဆာ = အရည်ကျဲကျဲဆန်ပြုတ်။
,ဆိ (န) အမျိုးသမီးအၚ်္ဂါဇာတ်။
,ဆဳဒဝ် (ကြိ) တားမြစ်သည်။/ ‘ဆေဝ်ဒဝ်’ ရှု။
,ဆု (န) သစ်။/ တၞံဆု = သစ်ပင်။
,ဆုကလဴ = ကလောပင်။
,ဆုကလှာၚ်၊ ဆုကလာၚ် = ကံပြင်းပင်။ (သၠကလှာၚ် = ကံပြင်းရွက်)
,ဆုကသမ် = ကြို့ပင်။ (‘ဆုဗြီုဗြံ’ နှင့်အတူတူ။)
,ဆုကၠ = ကျွန်းသစ်။
,ဆုတသော်ပါၚ် = ပါးပျဉ်း။ မြစ်ပျဉ်း။ (ပါဠိ—ပါရောဟ)
,ဆုနာဍူ = ပိတောက်ပင်။ ပိတောက်သား။
,ဆုပြာန် = ပျဉ်းကတိုးသစ်။
,ဆုဗြီုဗြံ = ကြို့ပင်။
,ဆုမုက် = တည်ပင်။ (သတ်မုက် = တည်သီး)
,ဆုသ၊ ဆုသြ = ထိမ်ပင်။
,ဆုသ္ဍဴ = ထင်းရူးပင်။
,ဆုသြိုဟ် = ကုက္ကိုပင်။
,ဆုအနာၚ် = အနန်းပင်။ အနန်းသား။
,ဆုကြက် (န) သစ်မာ။ သစ်အကောင်းစား။
,ဆုထၜောံ၊ ဆုထၜေါမ် (န) သစ်လုံး။
,ဆုဒကုတ် (န) သစ်တုံး။
,ဆုဒလာဲကျာ် (န) ဘုရားပွင့်တော်မူရာသစ်ပင်။ ဗောဓိပင်။
,ဆုမယိ၊ ဆုမယေအ် (န) တောစိုးသစ်ပင်။ နတ်ရှိသည်ဟူ၍ လူတို့ပူဇော်သော အလွန်ကြီးမား သည့်သစ်ပင်။
,ဆုသက (န) ဒန်ပူ။ တံပူ။
,ဆုအပြောံ၊ ဆုအပြောမ် (န) သာမန်သစ်။ သစ်အညံ့စား။
,ဆူဒလူ (ကြိ) ယိမ်းယိုၚ်သည်။ ဒယီးဒယိုင်သွားသည်။/ “မတ်အဲဂၠုအာတုဲ အဲမကွာ်ဆူဒလူစဴရောၚ်အဴ။” (ဇ—၄၁၆။ အစွောံ။) = “အကျွန်ုပ်မျက်စိကွယ်သွားသဖြင့် အကျွန်ုပ်သည် ဒယိမ်းဒယိုင် လျှောက်ပြန်လာပါသည်။”/ “ပရိုၚ်သ္ၚိတူအိုတ် ကောန်သမ္ဘာချိုတ်ဂှ် လၟမိၚ်တုဲ ယဲပူမှ်စံၚ်တူရာန် သကိုတ်တုဲ — တ္ၜူမာဲဝိဝိၚ် ထောံကၠေံဂၠိက်ယာတ်တုဲ ဒြေပ်ဆူဒလူစဴအာသ္ၚိရ။” (ဇ—၂၂၂။ အစွောံ။) = “မုဆိုးသည် အိမ်မီးလောင်ခြင်း သားမယားသေဆုံးခြင်း သတင်းကိုကြားလေသော် သောကအပူမီး ဖိစီးနှိပ်စက်ရကား မိန်းမူးတွေဝေကာ ကိုယ်အဝတ်တို့ကိုစွန့်လျက် အိမ်သို့ ဒယီးဒယိုင်ပြေးပြန်သွား၏။”
,ဆူလေ (န) ဆူးချုံ။
,ဆေ (ကြိ) ‘ဆေဝ်’ ရှု။
,ဆေတာ (ကြိ) တားမြစ်သည်။ တားဆီးသည်။/ “ဍာ်ပ္ဍဲမှာသၟိတ်ဝွံဂှ် — ဍေံမဇွောဝ်အာဂှ် ညးဂှ် ဆေတာဍေံမာန်ရော။” (ဇ—၂၉၆။ အစွောံ။) = “သမုဒ္ဒရာ­ စီးသွားသောရေကို အဘယ်သူသည် တားမြစ်နိုင်အံ့နည်း။”/ ‘ဆေဝ်တာ’ နှင့်အတူတူ။
,ဆေဒနာ (ကြိ) တားမြစ်သည်။ ကာဆီးသည်။/ “(ဍာ်မှာသၟိတ်ဝွံ) ဆဗၞတ်ဂလိုၚ်ဝွံ မၞးတံသုၚ်” (ခ ဍာ်ဂှ်)ဂးတုဲ ဆေဒနာတုဲ မၚ်မွဲတဴရ။ (ဇ—၂၉၆။ အစွောံ။) = “ဤသမုဒ္ဒရာရေကို သင်တို့သည် ဤမျှသာသောက်ကြကုန်လော့” ဟုဆို၍ ထိုကျီးသည် ကာဆီးလျက်စောင့်၏။/ ‘ဆေဝ်ဒနာ’ နှင့်အတူတူ။
,ဆေဒဝ် (ကြိ) တားမြစ်သည်။ တားဆီးသည်။/ “(ဍာ်မှာသၟိတ်ဝွံဂှ်) ညးသုၚ်ဍေံဖအိုတ်ရ။ ညးဂှ် ဆေဒဝ်မာန်ရော။” (ဇ—၂၉၆။ အစွောံ။) = “ဤသမုဒ္ဒရာရေကို အများသောက်ကြကုန်၏။
,မည်သူတားမြစ်နိုင်အံ့နည်း။”/ ‘ဆေဝ်ဒဝ်’ နှင့်အတူတူ။
,ဆေပလီု (ကြိ) တားမြစ်သည်။ တားဆီးသည်။/ “လပှ်မှာသၟိတ်တံဂှ်ကီု ညးဂှ် ဆေပလီုကၠေံမာန် ရော။” (ဇ—၂၉၆။ အစွောံ။) = “သမုဒ္ဒရာလှိုင်းတို့ကို အဘယ်သူသည် တားဆီးနိုင်အံ့နည်း။”/ ‘ဆေဝ်ပလီု’ နှင့်အတူတူ။
,ဆေယျန် (န) ဒုတ္ထာ။/ ‘သူရိယျန်’ နှင့်အတူတူ။
,ဆေရေ (ကြိ) ‘ဆေဝ်ရေဝ်’ ရှု။
,ဆေလုန် (န) ကျွမ်းထိုးခြင်း။ ကျွမ်းထိုးကစားခြင်း။
,ဆော (န) ကစားဘက်။ ပြိုင်ဘက်။/ “ညးတက်လက်ပၠုဲ ဟၟဲကဵုဆောရ။”= “လက်ဝှေ့ထိုးရန် သူ နှင့်ပြိုင်ဘက်မရှိပါ။”/ (စည်း) အစုံ၊ အရံစသည်ကို ရေတွက်ရာတွင် သုံးသောစကားလုံး။/ ဒၞပ် ၜါဆော = ဖိနပ်နှစ်ရံ။
,ကော်ဆော (ကြိ) စိန်ခေါ်သည်။
,ကေတ်ဆော (ကြိ) ဗွေယူသည်။ အပြစ်လုပ်သည်။/ “ဍေံကောန်ၚာ်ရောၚ်၊ ဍေံဟီုလုတ်အာ လ္ပ ကေတ်ဆောကဵုဍေံညိ။” = “သူဟာ ကလေးဘဲ၊ သူပြောမှားဆိုမှားရှိတာကို ဗွေမယူပါနဲ့။”/ “ဍေံတံသၟိက်ကလှိန်ဗၟက်ဝေၚ်တုဲ ဍေံတံဟီုဝေၚ်ရောၚ်။ ဂလာန်ဍေံတံဟီုဂှ် တၠအဲလ္ပပပၞတ်ညိ။ လ္ပ ကေတ်ဆောညိ။” (ဇ—၂၆၁။ အစွောံ။) = “သူတို့သည် နောက်ပြောင်ကျီစယ်လို၍ ပြောဆို ခြင်းဖြစ်၏။ သူတို့ပြောသောစကားကို သင်သည် အမျက်မထွက်ပါနှင့်၊ ဗွေမယူပါနှင့်။”
,ဂၠာဲဆော (ကြိ) ပြိုင်ဘက်ရှာသည်။/ “(ကုသၟိၚ်ကလိၚ်ဂှ်) ညးဂံၚ်စၞေဟ်ဟွံမွဲ ဂၠာဲဆောကေတ်ဟွံဂွံ မ္ဂးဝွံဂှ် ဇမ္ဗူဒိပ်လ္ၚုအာရသွံ” အမာတ်ချပ်။ (ဇ—၃ဝ၁။ အစွောံ။) = “(ကာလိၚ်္ဂမင်းနှင့်တကွ) စစ်ထိုးဝံ့သောသူမရှိ၊ ပြိုင်ဘက်စစ်ထိုးဘက်ကို ရှာ၍မရဆိုခြင်းမှာ အလုံးစုံသောဇမ္ဗူဒိပ်သည် အချည်းနှီးဖြစ်သွားပေတော့မည်” ဟုအမတ်ကြံ၏။
,ဂွံဆော (ကြိ) ပြိုင်ဘက်ကိုရသည်။/ “အဲဂၠာဲဒၟံၚ်ဆော အလုံဂတာဇမ္ဗူဒိပ် ကေတ်ဟွံဂွံ၊ လၟုဟ်ဝွံ ဂွံဆောရ” သၟိၚ်ကလိၚ်ဂး။ (ဇ—၃ဝ၁။ အစွောံ။) = “ငါသည် ဇမ္ဗူဒိပ်အလုံး­ ပြိုင်ဘက်စစ်ထိုး ဘက်ကို ရှာနေသည်မှာ မရ။ ယခုမှသာ ပြိုင်ဘက်ရတော့သည်” ဟုကာလိၚ်္ဂမင်းဆို၏။
,ဆဵုဆော (ကြိ) ပြိုင်ဘက်တွေ့သည်။/ “အဲဂၠာဲဒၟံၚ်ဆော လအ်ကွေံရ၊ လၟုဟ်ဂွံဆဵုဆော။”= “ငါ ပြိုင်ဘက်ရှာနေသည်မှာ ကြာလှပြီ။ အခုမှ ပြိုင်ဘက်တွေ့သည်။”
,ဒုၚ်ဆော (ကြိ) တစ်ဖက်သား၏စိန်ခေါ်မှုကို လက်ခံသည်။ ယှဉ်ပြိုင်ရန် သဘောတူသည်။
,သ္ပဆော (ကြိ) အဖက်လုပ်သည်။ ပြိုင်ဘက်လုပ်သည်။/ “ဍေံဂှ်ဗြဴတမ္ၚာ ပါၚ်ကြမ်လက်ဂံၚ် ညးဂှ် မွဲလေဝ် ဟွံသ္ပဆောကဵုဍေံရ။”= “သူသည် နှုတ်ကြမ်းပါးစပ်ဆိုးသော တံငါသည်မ ဖြစ်သည်၊ သူ့ကို မည်သူမျှ အဖက်မလုပ်ပါ။”/ “ဂၟာစိၚ်ဂၟာချေံမယုတ်မာတံဂှ် ညးဂှ် မပဆောကဵုဍေံရော ကောန် ဇၚ်ဍေံရ” ဂၞကျာ်ဇၞော်ဂးကဵုပြဘာဝတဳ။ (ဇ—၅၃၁။ အစွောံ။) = “သမီးတော်၊ ယုတ်မာ သောဆင်ထိန်းမြင်းထိန်းတို့ကို ဘယ်သူများအဖက်လုပ်မှာလဲ၊ သူ့ဖာသာရှိပါစေ” မိဖုရားကြီးက ပဘာဝတီအားပြော၏။
,ဆောဖွက် (န) ကစားဘက်။ ပြိုင်ဘက်။ 
,ဆက် (ကြိ) ၁။ ဆက်သည်။/ ‘ဆက်အာဂတညိ။’ = ‘ရှေ့သို့ ဆက်သွားပါ။’/ “တ္ၚဲဏအ် ဒေါအ် လဝ်ဆဝွံကၠာရ၊ တ္ၚဲယးဂတ ဆက်ကၠောန်ပၠန်ရ။” = “ယနေ့ဤမျှရပ်ထားပါဦး၊ မနက်ဖြန်ခါ ဆက်လုပ်မည်။”/ ၂။ တစ်စပ်တည်းဖြစ်သည်။ တစ်စပ်တည်းဖြစ်စေသည်။/ “ဝေၚ်သဘၚ်နက် သတ် ဆက်အာထပှ်တ္ၚဲ။” = “ခုနစ်ရက်ဆက်၍ နက္ခတ်ပွဲသဘၚ် ကစားကြသည်။”/ ၃။ ဆက် သွယ်သည်။/ “စိုပ်ကွာန်ဂှ်မ္ဂး ဆက်ကဵုၝောံမၞိဟ်ကွာန်တုဲ သွက်ဂွံအာဂတ ညးပ္ညုၚ်ထ္ၜးကဵုတရဴ ရောၚ်။” = “ထိုရွာရောက်လျှင် ရွာသူကြီးနှင့်ဆက်သွယ်၍ ရှေ့သို့သွားရန်ခရီးကို သူညွှန်ပြပေး ပါလိမ့်မည်။”/ ၄။ ဆက်သသည်။/ “တြုံတမ္ၚာဂှ် ဂွံကကြၚ်ဇၞော်မွဲတုဲ ကၠုၚ်ဆက်သၟိၚ်ရ။” = “တံငါသည်ယောကျာ်းသည် ငါးကြင်းကြီးတစ်ကောင်ကိုရပြီး ဘုရင်ကို လာ၍ဆက်သသည်။”
,ဆက်ကြက် (ကြိ) အစဉ်အဆက် ရှေ့သို့ဆက်သည်။ ဆက်လက်တည်တံ့သည်။/ “(ပြဘာတ်တြုံ ကဵုပြဘာတ်ဗြဴ) ညးၜါဝွံ ကလိဂွံကောန်တြုံကောန်ဗြဴတုဲ တၞောဝ်ဒတောဝ်တၠပညာ မဂွံဆက်ကြက် အာဂတ မဟွံသ္ဂုတ်ရောၚ်။” (ဇ—၃ဝ၁။ အစွောံ။) = “ပုရိဗိုဇ်ယောကျာ်းနှင့်ပုရိဗိုဇ်မိန်းမ ဤသူ နှစ်ဦးတို့ သားသမီးထွန်းကားသည်ရှိသော် နောင်ပညာရှိမျိုးဆက် မပြတ်ဆက်လက်တည်တံ့နေ လတ္တံ့။”
,ဆက်ကွာဲ (ကြိ) ဆက်သသည်။/ “ဇကုသၟိၚ်ကောသလရးဂှ် ဂျိုၚ်ၚ်ရပ်နၚ်တုဲ ဆက်ကွာဲတၠဂုန်ရအဴ” သာ်ဝွံညးဂၟံၚ်လ္ၚီဂှ် လ္ၚောဝ်ပ္တီသၟိၚ်ရ။ (ဇ—၅၁။ အစွောံ။) = “ကောသလပြည်မင်းအား အရှင်ဖမ်း ၍ အရှင်မင်းမြတ်ကို ဆက်သပါကုန်အံ့” ဟုသူရဲတို့က မင်းအားလျှောက်တၚ်ကုန်၏။/ “ၜိုပ်ကီု ကြေဲကီု မြာ်ကီု ညးကၠုၚ်ဆက်ကွာဲမ္ဂး—။” (ဇ—၂၁၄။ အစွောံ။) = “ဟၚ်္သာသားတို့ကို၄င်း ကြိုးကြာသားတို့ကို၄င်း ဥဒေါင်းသားတို့ကို၄င်း ဆက်လာကုန်သည်ရှိသော်—။” (ညောင်ကန်)/
,ဆက်ဂလာန် (ကြိ) နှုတ်ခွန်းဆက်သည်။ 
,ဆက်စပ် (ကြိ) ဆက်စပ်သည်။
,ဆက်စၠောအ် (ကြိ) ဆက်သွယ်သည်။ 
,ဆက်ဆက် (ကြိဝိ) ဆက်ဆက်။ အဆက်မပြတ်။ အမြဲမပြတ်။ မှန်မှန်။/ “ရာဟုလသာမဏဳတုန် ပြာပ်အာကဵုမိဆက်ဆက်ရ။” (ဇ—၂၈၁။ အစွောံ။) = “ရာဟုလာသာမဏေသည် မိခင်ထံသို့ အဆက်မပြတ်သွားရောက်၏။” 
,ဆက်ဆေန် (ကြိ) ဆွေမျိုးတော်စပ်သည်။ 
,ဆက်ဆောံ၊ ဆက်ဆောမ် (ကြိ) ဆက်ဆံသည်။ စပ်ဆိုင်သည်။ ပတ်သက်သည်။
,ဆက်တဲ (ကြိ) လက်တွဲသည်။
,ဆက်ပါၚ် (ကြိ) နှုတ်ဆက်သည်။ နှုတ်ခွန်းဆက်သည်။/ “ယွံဗမၞး၊ ပ္ဍဲကာလလၟုဟ်ဝွံဂှ် အဲကဵုဗမၞး ဂွံညာတ်ရၚ်သ္ကအ် ဂွံဆက်ပါၚ်ရ။ ပ္ဍဲကၠာတေံဂှ် မူရဴပ္ဍဲဋ္ဌာန်မွဲ အဲကဵုဗမၞး ဂွံဆက်ပါၚ်သၟာန်သၟုက်ဒဒှ်ေ ယှ်ဂှ်ရော” သၟိၚ်ဂး။ (ဇ—၄၅၆။ အစွောံ။) = “ပုဏ္ဏား၊ ယခုအခါ­ ငါနှင့်သင်သည် အချင်းချင်း တွေ့မြင်နှုတ်ဆက်ကြ၏။ ရှေး­ကား မည်သည့်အရပ်­ ငါနှင့်သင်သည် နှုတ်ဆက်မေးမြန်း သိ ကျွမ်းခဲ့ဖူးပါသနည်း။”
,ဆက်မိတ် (ကြိ) မိတ်ဆက်သည်။
,ဆက်လက် (ကြိဝိ) အမှန်။
,ဆက်လမျီု (ကြိ) အသက်ဆက်လက်ရှင်သန်စေရန်အတွက် ထောက်ကူမည့် အာဟာရ၊ ဆေးဝါးစသည်ကို ဖြည့်ဆည်းပေးသည်။ အသက်ဆက်သည်။
,ဆက်ဝဳဝဲ (ကြိ) ရန်စကိုရှည်စေသည်။ ရန်ကိုရန်ချင်းတုံ့ပြန်သည်။/ “ယွံတၠညး၊ လ္ပဆက်ဝဳဝဲကဵုဍေံ ညိရ” ဗောဓိသတ်ဂး။ (ဇ—၅၂၈။ အစွောံ။) = “မြတ်သောမင်းကြီး၊ သူနှင့် ရန်စကိုမရှည်ပါစေ နှင့်တော့။” 
,ဆက်ၜဝ်၊ ဆက်က္ၜဝ် (ကြိ) ဆက်သည်။ အကျိုးဆက်ဖြစ်သည်။ စဉ်ဆက်မပြတ်ဖြစ်သည်။/ “စုတိ အာနူဂှ် စှ်ေဒးနရက် သီုဝဳပက်မဆက်ၜဝ် ဒးဒုၚ်ဒၟံၚ်ဒဒိုက်ရောၚ်။” (ဇ—၇၉။ အစွောံ။) = “ထိုမှ စုတေလတ်သော် ငရဲသို့လား၍ ထိုဝိပက်အကျိုးဆက်ကြောင့် ဆင်းရဲဒုက္ခကို ခံစားနေရ၏။”
,ဆက်အရေဝ် (ကြိ) နှုတ်ဆက်သည်။ နှုတ်ခွန်းဆက်သည်။/ “ကၠဵုဂြိုပ်သမၠီု ဆဵုဇာဒိသိုၚ် ဒဴဟွံဗၠး ဂတးဆက်အရေဝ်ရ။” (ဇ—၁၄၃။ အစွောံ။) = “မြေခွေးမိုက်သည် ခြင်္သေ့ကိုတွေ့သည်ရှိသော် ပြေးရှောင်မလွတ်နိုင်ရကား လှည့်၍နှုတ်ခွန်းဆက်လေ၏။”
,ဆာ် (ကြိ) ကုတ်ခြစ်သည်။/ ဗ္ဂဲဆာ်ကၠဵု = ကြောင်သည် ခွေးကို ကုတ်ခြစ်သည်။
,ဆံက် (န) ကောက်ရိုး။/ ဗွဝ်ဆံက် = ကောက်ရိုးပုံ။/ ‘(ဂၠဴမ္ဂးဂှ်) ကမတ်ချောဲဆံက် မအောန်ကဵုရှ် ဂှ် မစရ။’ (ဇ—၂၈၆။ အစွောံ။) = ‘နွားတို့သည် အရသာနည်းပါးသော မြက်ကောက်ရိုးတို့ကို စားရ၏။’
,ဆိုက် (ကြိ) ကပ်သည်။ နီးကပ်သည်။ ချဉ်းကပ်သည်။ အနီးသို့ရောက်သည်။/ “ညးဂှ် မဂံၚ်ဆိုက် ဍေံရော။” (ဇ—၂၇ဝ။ အစွောံ။) = “အဘယ်သူသည် သူ့အနားသို့ ကပ်ဝံ့အံ့နည်း။”/ “ဍေံဟွံ ကေတ်စဂလာန်မိမဍေံဂှ်ရ မိမဍေံဟွံကဵုဆိုက်သ္ၚိရ။” = “မိဘစကားကို သူနားမထောင်သဖြင့် သူ့မိဘများက သူ့ကို အိမ်မပေးကပ်ပါ။”/ “(သၟတ်ဗြဴဂှ်) ကဵုဍေံကၠုၚ်ဒယှ်ေဆိုက်ညိ” ကောန် သၟိၚ်ဂး။ (ဇ—၂၆၃။ အစွောံ။) = “ထိုမိန်းမငယ်ကို လာ၍အနီးကပ်၍ သီဆိုစေလော့” ဟုမင်း သားဆို၏။/ “(ခမဳပိဂှ်) ကလေၚ်ကၠုၚ်ဘာဇေတဝန်ရ။ ပ္ဍဲမဆိုက်ကဵုဘာဇေတဝန်တုဲ သာ်ဝွံခမဳ ကောဂှ် ဟီုကဵုဒေံဂှ်ရ။—” (ဇ—၃၁၂။ အစွောံ။) = “ရဟန်းသုံးပါးတို့သည် ဇေတဝန်ကျောင်း တော်သို့ ပြန်လာကြ၏။ ကျောင်းတော်အနီးသို့ ရောက်သောအခါ အစ်ကိုဖြစ်သောရဟန်းက ညီဖြစ်သောရဟန်းကို ဤသို့ပြော၏။” 
,ဆိုက်ကဵု (စည်း) (ကြိယာရှေ့ဆက်) လုနီး။ လုနီးပါး။/ “မန်ပ္ဍဲဍုၚ်ရးသေံဂှ် ဆိုက်ဒၟံၚ်ကဵုအိုတ် ကၠက်ရ။” = “ထိုင်းနိုင်ငံရှိမွန်များသည် ကွယ်ပျောက်လုနီးနေပြီ။”
,ဆိုက်ညန်၊ ဆိုက်ညောန် (ကြိ) နီးကပ်သည်။ ချဉ်းကပ်သည်။/ “ဟာဲကလော်၊ အဲပ္တေဟ်ဇကုအဲတုဲ အဲမကၠုၚ်ရောၚ်။ ဗှ်ေလ္ပဆိုက်ညန်အဲ။ ယာံကၠုၚ်ကဵုအဲမ္ဂး နကံအဲဖျုၚ်လဝ်ဂျိဂှ် အဲပန်ပၠောပ်ဗှ်ေရ” ဗောဓိသတ်ဂး။ (ဇ—၅၅။ အစွောံ။) = “ဟယ်ဘီလူး၊ ငါသည် ငါ့ကိုယ်ကိုယုံ၍လာ၏။ ငါ့အနားသို့ သင်မချဉ်းလာလေနှင့်။ အကယ်၍သင်လာငြားအံ့ ငါ၏အဆိပ်လူးမြှားဖြင့် သင့်ကိုပစ်လွှတ်အံ့။”/ “ကာလတၠညးနွံဂှ် တြုံတံဂံၚ်ဆိုက်ညောန်အဲဂှ် ဟၟဲရ။ တၠညးဟွံမွဲတုဲ ပြောဟိတ်ပအနိၚ် အခိုင်ကဵုအဲ၊—။” (ဂၞကျာ်ဟီုဗျဵုသၟိၚ်) (ဇ—၂၂ဝ။ အစွောံ။) = “သင်မင်းကြီးရှိစဉ်­ ယောကျာ်းတို့သည် အကျွန်ုပ်အား ချဉ်းကပ်ဝံ့သည်ဟူ၍ မရှိ။ သင်မင်းကြီးမရှိစဉ် ပုရောဟိတ်သည် အကျွန်ုပ်အား အနိုင်အထက်ပြုကျင့်၏။” (မိဖုယားကုန်းချော၏။)/ “ပ္ဍဲမဆိုက်ညန်ကဵုကာလဗြဲဂှ် ဗောဓိသတ်ဣသိ တိတ်ကၠုၚ်နူဟေမဝန်တုဲ ဂ္ၚေၚ်ကၠုၚ်စိုပ်ဥဒျာန်သၟိၚ် ဍုၚ်ဗာရာဏသဳဂှ်ရ။” (ဇ—၅၂၈။ အစွောံ။) = “မိုးကာလနီးသောအခါ ဘုရားလောင်းရသေ့သည် ဟိမဝန္တာမှထွက်ခဲ့၍ ဗာရာဏသီမြို့ရှိ မင်းဥယျာဉ်သို့ လာရောက်၏။”/ “ဆိုက်ညန်ကဵုဍုၚ်ဗာရာဏသဳ။” (ဇ—၂၅၁။ အစွောံ။) = “ဗာရာဏသီပြည်နှင့် နီးကပ်လာသည်။”
,ဆိုက်ပြာပ် (ကြိ) ထိခြင်းငါးပါးဖြင့်ထိသည်။/ လ္ၚောဝ်မဆိုက်ပြာပ် (ပဥ္စဝန္ဒနာ) = ဦးချရာတွင် ဒူး နှစ်ဖက်၊ တံတောင်နှစ်ဖက်၊ နဖူးတို့ ကြမ်းပြင်­တည်စေခြင်း။ တည်ခြင်းငါးပါးဖြင့်ဦးချသည်။ 
,ဆိုက်ဗ္ဒက် (ကြိ) ၁။ ကျွမ်းကျင်လိမ္မာသည်။ လိမ္မာပါးနပ်သည်။ တတ်သိနားလည်သည်။ အတတ်ပညာ အပြီးသို့ရောက်သည်။/ ဆိုက်ဗ္ဒက်ပ္ဍဲကွတ်သဝ် = ဆေးအတတ်­ ကျွမ်းကျင်လိမ္မာသည်။/ ဆိုက်ဗ္ဒက်ပ္ဍဲလှ်ေဒယှ်ေ = အဆိုအက­ ကျွမ်းကျင်သည်။/ ဆိုက်ဗ္ဒက်ပ္ဍဲဗၞိက် = ကုန်သွယ်ခြင်း­ လိမ္မာသည်။ ကုန်အရောင်းအဝယ်­ ကျွမ်းကျင်သည်။/ ဆိုက်ဗ္ဒက်ပ္ဍဲစၞေဟ် = စစ်ထိုးခြင်း­လိမ္မာသည်။/ ဆိုက်ဗ္ဒက်ပ္ဍဲဥပ္ပါယ် = အကြောင်း­လိမ္မာသည်။ ဥပါယ်­လိမ္မာသည်။ အကြောင်းဟုတ်သည် မဟုတ်သည်ကို သိသည်။/ “ကောန်သကိုပ်သာဂှ် ဆိုက်ဗ္ဒက်ပ္ဍဲပြကိုဟ်ပကာန်ဂၠဴသန်။” (ဇ—၂၉။ အစွောံ။) = “လှည်းကုန်သည့်သားလည်း နွားတို့၏လက္ခဏာကို ပြသောကျမ်းကို တတ်၏။” (ညောင်ကန်)/ “ဟိုတ်စာၚ်ဂှ် ဆိုက်ဗ္ဒက်လောန်အဵု ဟွံဂွံဒွံပးဂှ်သက်က်။” (ဇ—၂ဝ၉။ အစွောံ။) = “ထိုကြက်ဖသည် အလွန်ပါးနပ်သည်ဖြစ်၍ ကျော့ကွင်းကို လုံးဝမထိ။”/ “ခမဳဗၠာဲဂှ် မဆိုက်ဗ္ဒက်ပ္ဍဲမမၚ်မွဲဇကုသန်။” (ဇ—၂ဝ၉။ အစွောံ။) = “ထိုပဥ္စင်းငယ်သည် မိမိ၏ကိုယ်ကို စောင့်ရှောက်ခြင်းအမှု­ လိမ္မာသည်ဖြစ်သတတ်။” (ညောင်ကန်)/ ၂။ ချဉ်းကပ်ခစားသည်။ မှီဝဲ ဆည်းကပ်သည်။/ ဆိုက်ဗ္ဒက်ကဵုရတ်ပိပြကာ = ရတနာသုံးပါးကို ဆည်းကပ်ခစားသည်။/ “ကာ လစိုပ်ဒဒိုက်မ္ဂး ဂပ်ဂဝ်ဆိုက်ဗ္ဒက်တၠပညာရ။” = “ဒုက္ခရောက်သောအခါ ပညာရှိကို မှီဝဲဆည်း ကပ်ရာ၏။”/ (နဝိ) ကျွမ်းကျင်လိမ္မာသော။/ အ္စာသဝ်မဆိုက်ဗ္ဒက်= ကျွမ်းကျင်သောဆေးဆရာ။ / သၟာလှ်ေမဆိုက်ဗ္ဒက် = ကျွမ်းကျင်သောကချေသည်။
,ဆၚ် (ကြိ) ၁။ ခုန်ဆင်းသည်။/ ‘တြုံဂှ် ဆၚ်စှ်ေနူကွဳ။’ (ဇ—၇၈။ အစွောံ။) = ‘ထိုယောကျာ်းသည် လှည်းပေါ်မှခုန်ဆင်းသည်။’/ ၂။ (အုန်းပင်စသည်) အသီးစသီးသည်။/ “တၞံသတ်ဗြဴအဲ တဵုလဝ်ဂှ် ဆၚ်ဒၟံၚ်ဣရ။” = “ငါစိုက်ထားသောအုန်းပင်သည် အသီးသီးနေပြီ။”/ ၃။ (တိရစ္ဆာန်) သားဖွားသည်။ သားကျသည်။/ “ဂၠဴၝောအ်ဂှ် ဆၚ်ကောန်မွဲတုဲရ။” = “ထိုနွားမသည် သားတစ်ကောင်ဖွားပြီးပြီ။”
,ဆၚ်ဍိုက် (ကြိ) ခုန်အုပ်သည်။/ “လတူကၟံၚ်စိၚ်ဇၟူဂှ် အဲဆၚ်ဍိုက်ရ” ကၠဵုဂြိုပ်သမၠီုဂှ်ချပ်။ (ဇ— ၁၄၃။ အစွောံ။) = “အမုန်ယစ်သောဆင်ပြောင်၏ ဦးကင်းထက်­ ငါခုန်အုပ်အံ့” ဟုမြေခွေး မိုက်ကြံ၏။
,ဆၚ်ဒဴ (ကြိ) ကွယ်ပျောက်ဆုံးရှုံးသည်။ (?)/ “(ၜိုန်ဗောဓိသတ်ဣသိတၠၛှာန်ကီုလေဝ်) သြိပ်နိဝဵု ကၠုၚ်စိုပ် ၛှာန်အဘိညာန်ဒးဆၚ်ဒဴကၠေံ—။” (ဇ—၆၃။ အစွောံ။) = “ဘုရားလောင်းဈာန်ရှင်ရ သေ့သည်ပင်လည်း နိဝါရဏတရား လာရောက်နှိပ်စက်လတ်သော် ဈာန်အဘိညာဉ် ကွယ်ပျောက် ဆုံးရှုံးရ၏။”
,ဆၚ်ရာ (န) လိပ်တစ်မျိုး။
,ဆာၚ် (န) လင်ကွင်းကြီး။
,ဆိၚ် (န) (ချည်လုံးမှ လိုသလောက်သောချည်ကို ထုတ်ယူရစ်ပတ်ထားသော) ချည်စု။/ (ကြိ) (ချည်လုံးမှချည်ကို လိုသလောက်) ထုတ်ယူရစ်ပတ်သည်။/ “တောဝ်မွဲပလုဲ ဍေံဆိၚ်လဝ်မွဲဆိၚ် ဇၞော် ဍေံရပ်လဝ်မုဟ်တောဝ်ဂှ်တုဲ တောဝ်ဆိၚ်ဂှ် ဍေံဗိုတ်ပတိုန်ဏာတုဲ ဂၚ်ဒၟံၚ်ပ္ဍဲကၞာၚ်ကြုက်။” (ဇ—၄၈၉။ အစွောံ။) (တောဝ်မွဲပလုဲ = ချည်လုံးတစ်လုံး။/ တောဝ်မွဲဆိၚ် = ချည်လုံးမှ လိုသ လောက်ယူထားသော ချည်စုတစ်စု။) 
,ဆုၚ် (ကြိ) နမ်းသည်။/ ဆုၚ်ကောန်ၚာ် = ကလေးကိုနမ်းသည်။/ ဆုၚ်ရံၚ်သၟူပ္ကဴ = ပန်းအနံ့ကို နမ်းကြည့်သည်။/ “ဗမၞးတံၚ်ပ္တိတ်သၞာ်နူကၞပ်ဂှ်တုဲ ဆုၚ်ရံၚ်ရ။” (ဇ—၁၂၆။ အစွောံ။) = “ပုဏ္ဏားသည် သန်လျက်အိမ်မှ သန်လျက်ကိုဆွဲထုတ်၍ နမ်းကြည့်၏။”/ “ချေံၜါဂှ် ညာတ်ညးသ္ကအ်တုဲ သ္ဍိုက်မၠိုက်အာညးသ္ကအ်တုဲ ဆုၚ်ညးသ္ကအ် ကၠာန်ညးသ္ကအ်—။” (ဇ—၁၅၈။ အစွောံ။) = “ထိုမြင်း နှစ်ကောင်တို့သည် အချင်းချင်းမြင်သည်ရှိသော် ချစ်နှစ်သက်ကုန်သည်ဖြစ်၍ အချင်းချင်းနမ်းကြ ကုန်၏၊ အချင်းချင်းလျက်ကြကုန်၏။”
,ဆေၚ် (ကြိ) ၁။ သက်ဆိုင်သည်။/ “ကိစ္စဏအ် ဟွံဆေၚ်ကဵုမၞးရ။” = “ဤကိစ္စသည် သၚ်နှင့်မ သက်ဆိုင်ပါ။”/ ၂။ ဆိုင်းသည်။ ဆိုင်းငံ့သည်။/ “သြန်ဂတှ်အဲဂၠေံလဝ်ဂှ် လၟုဟ်အဲလေဲကဵုဟွံ မာန်ဏီ၊ ဆေၚ်လဝ်ကဵုမွဲခဏညိကၠာ။” = “ကျွန်တော်ချေးယူထားသောငွေကို ယခုကျွန်တော်မ ဆပ်နိုင်သေးပါ၊ ခဏလောက်ဆိုင်းထားပါဦး။” 
,ဆေၚ်မုက်၊ ဆိုင်မုက် (ကြိ) မျက်နှာချင်းဆိုင်သည်။/ “ဍေံဂၠေံလဝ်သြန်ပ္ဍဲအဲတုဲ ဖေက်ဒးကလေၚ် လေဲသြန်ဂှ် ဍေံဟွံဂံၚ်ဆေၚ်မုက်ကဵုအဲရ။” = “ငါ့ဆီမှာ သူငွေချေးယူထားပြီး ထိုအကြွေးကို ပြန် ဆပ်ရမည်စိုး၍ ငါနှင့် သူမျက်နှာချင်းမဆိုင်ရဲပါ။”
,ဆံၚ် (ကြိ) ၁။ ထပ်ဆင့်သည်။ ထပ်လောင်းသည်။/ “ဒၞာဲဍာ်မပေၚ်တဴနုၚ်ဂှ် ညးဆံၚ်စုတ်ဍာ်ပၠန်။” လ္ပအ်သၟိၚ်ပဿိုန် = “ရေပြည့်နေသောအိုးကို ရေထပ်ဆင့်ထည့်ပြန်သည်။”/ “ယာတ်မွဲဒကုတ်ဂှ် သၟတ်ဗြဴကဵုဒါန်ကုခမဳဂှ်တုဲ သဒ္ဓါက္တဵုဒှ်ပၠန်တုဲ ယာတ်သၟိဟ်မွဲဒကုတ်ဂှ်လေဝ် သၟတ်ဗြဴဆံၚ်ကဵုပၠန်ရ။” (ဇ—၅၂၇။ အစွောံ။) = “ထိုမိန်းမငယ်သည် အဝတ်တစ်ပိုင်းကို ရဟန်းအာလှူပြီးနောက် သဒ္ဓါ တရားဖြစ်ပေါ်ပြန်၍ ကျန်အဝတ်တစ်ပိုင်းကိုလည်း ထပ်ဆင့်၍လှူပြန်၏။”/ ၂။ နောက်မှမကွာ လိုက်သည်။/ “ကမၠတ်ဂှ်ဒြေပ်ဒဴအာ ညးကွာန်ဂမၠိုၚ် ဆံၚ်ဗက်အာကမၠတ်ဂှ်ရ။” = “သူခိုးပြေး လေသော် ရွာသားများက နောက်မှမကွာလိုက်ကြကုန်၏။”/ “မၞးစဴအာဟီုသၠာံဗဇးအသီဗြဴကၠာရ၊ တုဲအဲဆံၚ်အာလၟုဟ်ဝွံရ” ဂစေံတၟအ်ဂးကဵုအသီကၟက်ရ။ (ဇ—၄၈၆။ အစွောံ။) = “သၚ်သွား၍ အဆွေစွန်မကို မကြောက်ရန် နှစ်သိမ့်စေလော့။ ယခုပင်မကွာ ငါလိုက်ခဲ့အံ့” ဝန်လိုငှက်က စွန် ဖိုအားပြော၏။/ ၃။ ရိုက်နှက်သည်။/ ဆံၚ်ဒး = ရိုက်နှက်မိသည်။
,ဆံၚ်ဍေံ (စည်း) ရှိပစေ။ နေပစေ။/ “ဍေံချိုတ်ဆံၚ်ဍေံရ။” = “သူသေလျှင် သေပစေ။”/ ‘ဇၚ်ဍေံ’ ရှု။/ ‘သောၚ်ဍေံ’ ဟုလည်း အချို့သုံးသည်။ စကားတွင် ‘ဣဍေံ’ ဟုပြောကြသည်။
,ဆိုင်မုက် (ကြိ) ‘ဆေၚ်မုက်’ ရှု။
,ဆတ် (ကြိ) အပေါက် (သို့မဟုတ်) နှစ်ခုကြားအတွင်း ထိုးသွင်းသည်။/ “ဆတ်လဝ်သေနာတ်ပ္ဍဲ ဂၞိၚ်။” = “ခါးကြားတွင် သေနတ်ထိုးထားသည်။”/ ‘သၞာ်ဆတ်ဂၞိၚ်တုဲ တိုန်ဍိုက်ချေံတုဲ—။’ (ဇ—၂၃။ အစွောံ။) = ‘သန်လျက်ကို ခါးကြားထိုးလျက် မြင်းကိုတက်စီး၍—။’
,ဆတ္တာ (ပါသက်) (န) ဆတ္တာသည်။ ဆံပင်ညှပ်သူ။ (ပါဠိ—ဆေတ္တာ)/ “ပဟိုတ်ကဵုကောန်ဆတ္တာ မွဲတုဲ သိၚ်္ဂါလဇာတ် ကျာ်တြဲတွံ။” (ဇ—၁၅၂။ အစွောံ။) = “တယောက်သောဆေတ္တာသည်သား ကို အကြောင်းပြု၍ ဟောတော်မူ၏။” (ညောင်ကန်) (ဆေတ္တာသည် = ဆတ္တာသည်)/ “ဆတ္တာသမာဂလုံဂှ် သမာရေက်သော်မ္ဂးရ။” (ဇ—၁၅၂။ အစွောံ။) (ဆတ္တာ = သၟာဂလုံ = သၟာရေက်သော်)
,ဆတ္တဝ် (ကြိဝိ) အမှန်။ အမှန်တကယ်။/ “(ဗြဟ္မဒတ္တကုမာ) လ္ၚောဝ်ဒေဝတဴတုဲ ဟီုဒၟံၚ်ဒီုဒီု ဟွံကဵု ညးမိၚ်ရ၊ ပ္ဍဲကၞောတ်ဂလာန်ဂှ် ဟီုဆတ္တဝ် ကဵုညးမိၚ်ရ။” (ဇ—၅ဝ။ အစွောံ။) = “ဗြဟ္မဒတ်သ တို့သားသည် နတ်အားရှိခိုး၍ လူမကြားအောင် တိုးတိုးပြော၏။ စကား၏အဆုံး­ကား လူကြား အောင် အမှန်တကယ်ပြော၏။”
,ဆာတ် (န) ရေငန်ပိုင်းနေ အဆိပ်ပြင်းသောမြွေတစ်မျို။ ဂျတ်။ (ဤမြန်မာဝေါဟာရ ‘ဂျတ်’သည် မွန်ဝေါဟာရ ‘ဆာတ်’ မှ ဆင်းသက်လာသည်။)
,ဆာတ်ဒး (ကြိ) သီသီကလေးပွတ်၍ ထိမှန်သည်။/ “ဍေံတ္ၚီုထပက်အဲကဵုၜုန် ဆာတ်ဒးအာသ္ကဲအဲ ဂိဒှ်အာဒွဵုသရညိရ။” = “ကျွန်တော့်ကို သူဓါးနှင့်ထိုးရာ ကျွန်တော့်နံပါးကို သီသီကလေးပွတ်၍ ထိမှန်သွားပြီး ကျွန်တော်အနည်းငယ် ဒဏ်ရာရသွားသည်။”
,ဆုတ်—၁ (န) အီး။/ (ကြိ) အီးပေါက်သည်။ လေလည်သည်။
,ဆုတ်—၂ (ကြိ) ဆုတ်သည်။ နောက်ဆုတ်သည်။/ “(စိၚ်ဂှ်) ဒးလွဟ်မဂၠိုၚ် ဖေက်ဘဲဂစိုတ်တုဲ စိၚ် ဆုတ်တိတ်ကၠုၚ်ရ။” (ဇ—၁၈၂။ အစွောံ။) = “ဆင်သည် လက်နက်များထိမှန်၍ သေဘေးမှ ကြောက်သဖြင့် နောက်ဆုတ်ထွက်လာ၏။”
,ဆုတ်ကလေၚ် (ကြိ) နောက်ဆုတ်သည်။ နောက်ပြန်ဆုတ်သည်။
,ဆုတ်ဒဴ (ကြိ) ဆုတ်ခွါသည်။ ဆုတ်ပြေးသည်။/ “ပၞာန်သတြုဆုတ်ဒဴအာတုဲရ။” = “ရန်သူ့စစ် ဆုတ်ပြေးသွားပြီ။”/ “ဟာဲကၠ၊ — ဗှ်ေကၠတၠဂၞေဟ်မသ္ကေက်ရောၚ်။ မူပမဖေက်ကၠိက်ဂှ်ရော။ ဗှ်ေ အာမွဲဝါရ။ လ္ပဖေက်ဍေံ ဗှ်ေလဟဵုလုပ်တုဲ ဍေံမဒးဆုတ်ဒဴအာရ” ဣသိစၞာဲဂး။ (ဇ—၄၉၂။ အစွောံ။) = “ဟယ်ကျား၊ သင်သည်ကား ထက်သောအစွယ်ရှိသောကျားတည်း။ ဘာကြောင့်ဝက် တို့ကို ကြောက်ရမည်နည်း။ တစ်ကြိမ်သွားပါဦး။ မကြောက်နှင့်၊ သၚ်ရှေ့တက်တိုးလျှင် ဝက်တို့ ဆုတ်ပြေးရလိမ့်မည်” ဟုရသေ့စဉ်းလဲဆို၏။
,ဆေတ် (ကြိ) ၁။ စောင်းသည်။/ ၂။ စောင်းချိတ်ပြောသည်။ သွယ်ဝိုက်သောစကားဖြင့် ထိခိုက် ပုတ်ခတ်သည်။ စောင်းမြောင်းသည်။/ “ဍေံဟီုဆေတ်ဒၟံၚ်ကဵုအဲ။” = “ငါ့ကို သူစောင်းချိတ်ပြော နေသည်။”
,ဆောတ် (ကြိ) လွဲချော်သည်။ လွဲမှားသည်။ ချွတ်မှားသည်။ ချွတ်ယွင်းသည်။/ “(ရသိစၞာဲဂှ် ရပ် လေံကၞဟ်ဂှ်တုဲ) ကၠဟ်ဏာဗောဓိသတ်(ဖရာပ်)ရ။ ဗောဓိသတ်ဗလေတ်ကၠေံတုဲ ကၠဟ်ဟွံဒး ‘ဒၟာနူ ညိရဆောတ်အာ’ ရသိဂး။” (ဇ—၂၇၇။ အစွောံ။) = “ရသေ့စဉ်းလဲသည် ဆောက်ပုတ်ကိုကိုၚ် ၍ ဘုရားလောင်းခိုအား ပစ်လွှတ်၏။ ဘုရားလောင်းသည် ကိုယ်ကိုရှောင်လိုက်၍ မထိမှန်။ ‘သီ သီကလေးသာ လွဲသွား၏’ ဟုရသေ့ဆို၏။”/ “ယွံအမာတ်၊ သၟိၚ်ဣိန်မပတၠဂမြင် မပတၠမတ်လ္ၚီဂှ် ဟီုတုဲ ဆောတ်ကီုဟာအမာတ်” သၟိၚ်ဂး။ (ဇ—၃ဝ၁။ အစွောံ။) = “အမတ်၊ မျက်လုံးတထောင် အမြင်ဆောင်သော သိကြားမင်းသည် ပြောပြီးလျှင် လွဲမှားရိုးရှိသလော။”/ “ယာံရပိုဲမန်ညဳသာ သၟဟ်သၟန်အိုတ်မ္ဂး ပိုဲဂွံစိုပ်တိုၚ်ပ္ကဴဇမၞး မဆောတ်ဟွံမွဲရ။” = “တို့မွန်များစည်းလုံးညီညွတ်ကြလျှင် အောင်ပွဲပန်းတိုင်ဆီသို့ ရောက်ရမည်မချွတ်တည်း။”/ “တၠအဲဒေပ်လဝ်စိုတ်စၞာဲတုဲ နရက်ဘုံအပါဲဂှ် တၠအဲစှ်ေဒးဟွံဆောတ်ရ။” (ဇ—၂၇၇။ အစွောံ။) = “ကောက်ကျစ်စဉ်းလဲသောစိတ်ကို သၚ်မွေး မြူထားလျှင် ငရဲအပါယ်ဘုံသို့ သင်လားရောက်ရမည်မချွတ်။”
,ဟီုဆောတ်အာ (ကြိ) အလွဲလွဲအချော်ချော် ပြောမိသည်။ ဆိုလိုသည်ကာတစ်မျိုး ပြောမိသည်က တစ်ခြားဖြစ်သည်။/ “တၠညးကဵုဂၠဴမွဲ ကုအဲဍိက်ညိအဴ” ၜိုန်ဗမၞးသၟိက်ဂးသာ်ဂှ်ကီုလေဝ် ဗမၞးဟီု ဆောတ်အာတုဲ “ဂၠဴအဲဍိက်မွဲဂှ် တၠညးဂိုၚ်လဝ်ညိအဴ” သာ်ဝွံဟီုဒးအာရ။ (ဇ—၂၁၁။ အစွောံ။)/ ‘ဟီုတဆူအာ’ နှင့်အဓိပ္ပါယ်အတူတူ။
,ဟွံဆောတ် (ကြိဝိ) မချွတ်။ မလွဲမသွေ။ ဨကန်မုချ။/ “— မဂွံအာစိုပ် ဟွံဆောတ်ရ။” (ဇ— ၁၉၆။ အစွောံ။) = “ရောက်ရမည်မချွတ်။”
,ဆောတ်ကျာ၊ ချောတ်ကျာ (ကြိ) လေချွန်သည်။ (ပါဠိ—ဒန္တဂဳတ)
,ဆောတ်မှာ (ကြိ) ချွတ်ချော်သည်။ မှားယွင်းသည်။
,ဆောတ်ယောၚ် (ကြိ) လွဲမှားသည်။ မှားယွင်းသည်။ 
,ဆန်—၁ (ပါသက်) (ကြိ) ရေးသားစီကုံးသည်။ စပ်ဆိုသည်။/ ဆန်လိက် = စာရေးသာစီကုံးသည်။/ ဆန်ဒွက် = သီချင်းသီကုံးသည်။ သီချင်းရေးစပ်သည်။/ (ပါဠိ—ဆန္ဒ?)
,ဆန်—၂ (ကြိ) ခွဲခြမ်းဝေငှသည်။ ခွဲဝေသည်။/ “စၞသွက်ကောန်ၚာ်ဂမၠိုၚ်ဂှ် ဆန်လဝ်ဇဳအိုတ်ရဟာ။” = “ကလေးများအတွက် စားစရာကို လူစုံအောင် ခွဲခြမ်းဝေငှပြီးပြီလား။”/ ‘ဆန်ၜန်’ (၃) နှင့်အတူတူ။
,ဆန္ဒ (ပါ) (န) လိုချင်မှု။ အလိုရှိမှု။ ဆန္ဒ။
,ဆန္ဒပြဟ် (ကြိ) ဆန္ဒစောသည်။ လောကြီးသည်။
,ဆန်ၜန် (ကြိ) ၁။ စီစဉ်သည်။ စီမံပြုလုပ်သည်။/ ဆန်ၜန်ကေၚ်ကာ = အလုပ်ကို စီမံခန့်ခွဲသည်။ စီမံဆောင်ရွက်သည်။/ “ပိဏ္ဍပါတ် သီုအမာဲမၞုံကုရှ်ဂှ် နအလေဝ်ဇကုသၟတ်ဗြဴဂှ်ဟေၚ် ဆန်ၜန်တဴ ရိုဟ်ဟ်တ္ၚဲရ။” (ဇ—၁၄။ အစွောံ။) = “ရဟန်းများအတွက် အရသာရှိသော ဟင်းလျာအမည် များနှင့်ဆွမ်းကို သူမကိုယ်တိုင် နေ့စဉ်စီမံချက်ပြုတ်၏။”/ ၂။ ဆည်းပူးသည်။ စုဆောင်းသည်။/ “ပ္ဍဲဘဝအတိက်တေံ ဂွံဆန်ၜန်လဝ်ဓဝ်ကုသဵုမဂၠိုၚ်တုဲ ပ္ဍဲဘဝလၟုဟ် ဂွံပတၠရုပ်တၠပိုန်ရ။” = “အတိတ်ဘဝက ကုသိုလ်ကောင်းမှုများစွာ ဆည်းပူးထားအပ်သောကြောင့် ယခုဘဝတွင် လှသောရုပ် ရည်ရှင် ဘုန်းစည်းစိမ်ရှင်ဖြစ်လာရသည်။”/ ၃။ ခွဲဝေသည်။ ခွဲခြမ်းဝေငှသည်။ ခွဲခြမ်းဝေဖန်သည်။/ “ဘောဇိုန်မပြဲပြဲဂှ် ဂပ်ဂဝ်ပရအ်ဆန်ၜန်ကဵု ခမဳဗမၞးတံရောၚ်သွံ။” (ဇ—၄၂၃။ အစွောံ။) = “ကောင်းမြတ်ကုန်သော ခဲဖွယ်ဘောဇဉ်တို့ကို ရဟန်းပုဏ္ဏားတို့အား ခွဲခြမ်းဝေငှပေးသင့်၏။” 
,ဆာန် (ကြိ) ချစ်သည်။/ “သၟိၚ်တၠသ္ၚိဂၞကျာ်ဂှ် ယဝ်ရဆာန်ဂၞကျာ်မ္ဂး သတ်ကြုက်ဂှ် သၟိၚ်အာကေတ် ကဵုဂၞကျာ်ရ။” (ဇ—၂၈၁။ အစွောံ။) = “မိဖုယား၊ မိဖုယား၏လင်ဖြစ်သောမင်းသည် မိဖုယား အားချစ်လျှင် ထိုသရက်သီးကို မိဖုယားအား ယူဆောင်ပေးလတ္တံ့။” 
,ဆာန်ကၟိန်၊ ဆာန်သၟိန် (ကြိ) ချစ်ခင်သည်။ ချစ်ကြိုက်သည်။/ “ကောန်ဗြဴကဵုကၟိန်ဂှ် ပေၚ်အာယုက် စှ်တြဴသၞာံတုဲ ဆာန်ကၟိန်အာရၚ်သ္ကအ် ဗွဲမလောန်ရ။” (ဇ—၁၂၆။ အစွောံ။) = “သမီးတော်နှင့်တူ တော်တို့သည် အသက်တစ်ဆယ့်ခြောက်နှစ်ပြည့်၍ အချင်းချင်း အလွန်ချစ်ကြိုက်သွားကြ၏။” 
,ဆာန်ဍူ (ကြိ) ကြင်နာသနားသည်။
,ဆာန်ဠာန် (ကြိ) ချစ်စရာကောင်းသည်။/ “ကောန်ၚာ်ဏအ် ဗော်ပလုတ်ဒၟံၚ် ဆာန်ဠာန်ကွေံရ။” = “ဤကလေးသည် ဝဝကစ်ကစ်နှင့် အလွန်ချစ်စရာကောင်းသည်။”
,ဆုန် (န) ဆုန်း။ (= ဟင်းရိုင်းကို ချက်ယူရသော ဆေးတစ်မျိုး)။ ဟၚ်္သပဒါး။ (ပါဠိ—စဳနပိဋ္ဌ) (မှတ်ချက်။ ‘ဟင်းရိုင်း’ သည် ဟၚ်္သပဒါးထုတ်ယူနိုင်သော မြေထွက်သယံဇာတတစ်မျိုးဖြစ်သည်။ ‘ဟၚ်္သပဒါး’ ကို မွန်လို ‘ဇာၚ်ၚု’ ဟုခေါ်သည်။)
,ဆေန်ဆက် (ကြိ) ဘိုးဘေးစဉ်ဆက်မှ ဆင်းသက်သည်။
,ဆိုန် (ကြိ) နယ်သည်။
,ဆိုန်ပတ် (ကြိ) ဆုပ်နယ်သည်။/ “(သတ်ကြုက်ဂှ်) သၟိၚ်ကဵုသံက်ကၠေံသၞံက်ဍေံတုဲ ဖုဲစုတ်သဂြာတုဲ နတဲသၟိၚ်ဂှ် ဆိုန်ပတ်ကၠေံတုဲ စုတ်ဗပေၚ်ဗဗေၚ်တုဲ ဗဂိန်ကဵုထေရ်ရ။” (ဇ—၂၈၁။ အစွောံ။) = “မင်းသည် သရက်သီးခွံကိုခွါ၍ သကာသကြားကိုထည့်၍ မိမိကိုယ်တိုင်လျှင်နယ်၍ အရှင်သာ ရိပုတ္တရာမထေရ်အား သပိတ်ကိုပြည့်စေ၍ လှူ၏။” (ညောင်ကန်)/ “ဗောဓိသတ်ဖုံဍာ်ကဵုမဂှ်ရ။ ဆိုန်ပတ်ဇိုၚ်ပတ်စးတုဲ—။” (ဇ—၃၁၂။ အစွောံ။) = “(ဘုရားလောင်းသည်) အဘကို ရေချိုးစေ ၍ ခြေဆေးခြင်း ကျောက်ကိုဆုပ်နယ်ခြင်း အစရှိသည်တို့ကိုပြု၍—။” (ညောင်ကန်)
,ဆပ်၊ ဆပ်ပၠံၚ်၊ ပၠံၚ်ဆပ် (န) ဆပ်စပါး။/ “(ဗောဓိသတ်)ဒှ်ဗၠာဲတုဲ ရပ်ကေတ်ခ ၜံက် ၜံက်တိဂူတုဲ တဵုသၞေဝ်မပ္တံကဵုဂပဳသ္အဳဆပ်ပၠံၚ်တံဂှ်တုဲ မပဂယိုၚ်လမျီုရ။” (ဇ—၇ဝ။ အစွောံ။) = “ဘုရားလောင်းသည် အရွယ်ရောက်သည်ရှိသော် ပေါက်တူးကိုကိုၚ်လျက် ယာမြေကိုပေါက်၍ ဖရုံသခွားဆပ်စပါး အစရှိသောဟင်းသီးဟင်းရွက်တို့ကို စိုက်ပျိုး၍ အသက်မွေး၏။”
,ဆာပ်—၁ (ကြိ) ၁။ ကျပ်ပူထိုးသည်။ ရေမြှုပ်ဖြင့် ပွတ်သပ်ဆေးကြောသည်။/ “ဇိုၚ်ဂိဂှ် ဆာပ်ကဵု ဍာ်ဂမ္တဴညိ။” = “နာသောခြေထောက်ကို ရေနွေးနှင့် ကျပ်ပူထိုးပေးပါ။”/ ၂။ ရေဆွတ်သည်။/ “ယာတ်သၟာ်ဂှ် ဆာပ်ဍာ်တုဲ ဇိုတ်ကၠေံကၞဳသ္ၚိညိ။” = “ထိုအဝတ်စုတ်ကို ရေဆွတ်ပြီး အိမ်ကြမ်း ပြင်ကို သုတ်ပါ။”
,ဆာပ်—၂ (မြန်သက်) (ကြိ) (ကျေးဇူး) ဆပ်သည်။/ ဆာပ်ဂုန်မိမ = မိဘကျေးဇူးကို ဆပ်သည်။
,ဆာပ်ပျာ (မြန်သက်) (န) ဆပ်ပြာ။
,ဆာံဆာံ (ကြိဝိ) အသံမှန်စွာ။ (?)
,ဆီ (န) သွေး။/ ဆီသြိတ် = ကြံ့သွေး။ 
,ဆီကျာ၊ ဆီဥတု (န) မိန်းမရာသီသွေး။ ဓမ္မတာသွေး။
,ဆီကတဴ (ကြိ) သွေးပူသည်။ ကိုယ်လက်လှုပ်ရှား၍ ကိုယ်ခန္ဓာနွေးထွေးသည်။
,ဆီကၞံ၊ ဆီကၞမ် (ကြိ) သွေးဆူသည်။ စိတ်အလွန်လှုပ်ရှားတက်ကြွသည်။
,ဆီကျာကၞုက်ကၞာဲ (ကြိ) သွေးလေချောက်ချားသည်။ သွေးလေမတည်မငြိမ်ဖြစ်သည်။ စိတ်တုန်လှုပ် ချောက်ချားသည်။
,ဆီကျာကၠုၚ် (ကြိ) (အမျိုးသမီး) ရာသီလာသည်။ ရာသီပန်းပွင့်သည်။
,ဆီကျာဓဝ်ယာ (ကြိ) ရာသီသွေးမှန်သည်။ ဓမ္မတာသွေး အချိန်မှန်မှန်လာသည်။
,ဆီကျာအိုတ် (ကြိ) သွေးဆုံးသည်။ (အမျိုးသမီးများတွင် သက်ကြီးပိုင်း­ ဓမ္မတာသွေးပေါ်ခြင်း လုံးဝရပ်စဲသည်။)
,ဆီခတ် (ကြိ) (ဥပစာ) သတ္တိကောင်းသည်။ ရဲရင့်သည်။ သွေးရဲသည်။
,ဆီဂံက် (ကြိ) သွေးအေးသည်။ စိတ်လှုပ်ရှားမှု၊ စိတ်ထက်သန်မှု ငြိမ်ဝပ်သည်။
,ဆီဇာတိမာန် (န) ဇာတိသွေးဇာတိမာန်။
,ဆီဍာဲ (ကြိ) (ဥပစာ) သွေးရဲသည်။ သတ္တိကောင်းသည်။
,ဆီတၟအ် (န) ကျောက်သွေး။ (ပါဠိ—ဂေရေယျ)
,ဆီပ္ဍူ (ကြိ) သွေးခြည်ဥသည်။ အသားအတွင်းပိုင်း ပွန်းရှနာသွားသည်။
,ဆီပရေအ် (ကြိ) သွေးဆိုးသည်။ ရမ်းကားရန်ပြုတတ်သည်။/ “ဍေံဗ္ၜူအရက်တုဲ ဆီပရေအ်ဒၟံၚ် ရောၚ်။” = “သူအရက်မူးလျှင် သွေးဆိုးသည် (ဝါ) ရမ်းကားရန်ပြုတတ်သည်။”
,ဆီပါ်ဍာ်ဇွောဝ် (ကြိ) သွေးထွက်သံယိုဖြစ်သည်။
,ဆီမၚ် (ကြိ) သွေးစို့သည်။ သွေးခြည်ဥသည်။
,ဆီသၠုၚ် (ကြိ) (ဥပစာ) ဘဝင်မြင့်သည်။ သွေးကြီးသည်။
,ဆီဟီုအရေဝ် (ကြိ) သွေးပြောသည်။ သွေးက စကားပြောသည်။ (ဥပစာ) ဆွေမျိုးတော်စပ်သည်ကို မသိဘဲနှင့် ချင်ခင်ရင်းနှီးစိတ် ဖြစ်ပေါ်သည်။
,ဆီၜေတ် (ကြိ) သွေးတိုးသည်။/ ယဲဆီၜေတ် = သွေးတိုးရောဂါ။
,ဆောံ (ကြိ) ဆုံးရှုံးသည်။/ “အဲပံၚ်လဝ်နာဍဳအဲ အဲကလေၚ်နုက်ဟွံမာန်တုဲ ဒးဒုၚ်ဆောံရ။” = “ကျွန်တော့်နာရီပေါၚ်နှံထားတာကို ကျွန်တော်ပြန်မနှုတ်နိုင်သဖြင့် အဆုံးခံရသည်။”/ “ညံၚ်သ ရာဲဒယှ်ရ လဆောဝ်မှာရာ ဒးကျဆောံတုဲ မရံၚ်ဂွာံကလေၚ်ဇၞးကီု။” (ဇ—၁၄၈။ အစွောံ။) = “သူရဲကျော်ကဲ့သို့ တစ်ခါတစ်ရံမှားယွင်း၍ ရှုံးနိမ့်ဆုံးရှုံးရပြီးနောက် တစ်ဖန်အနိုင်ယူရန် အ ခွင့်ကောင်းကို စောင့်ကြည့်ရာ၏။”
,ဆောံဗျ (ကြိ) အကျင့်သီလမရှိ။ ယုတ်မာသည်။ ကောက်ကျစ်စဉ်းလဲသည်။/ “ကၠဵုမ္ဂးဝွံဂှ် စိုတ်ဍေံ ဟွံခိုဟ် ဆောံဗျလောန်၊ လ္ပဟုဲဟာဲကဵုဍေံညိကောန်” သၟိၚ်ဇာဒိသိုၚ်ဂးကဵုကောန်။ (ဇ—၃၉၇။ အစွောံ။) = “မြေခွေးမည်သည် ယုတ်မာသောစိတ်ရှိ၏၊ အလွန်လျှင် ကောက်ကျစ်စဉ်းလဲ၏။ မြေ ခွေးနှင့်တကွ ပေါင်းဖော်ခြင်းကို မပြုလင့်။” 
,ဆောံမ (ကြိ) ဖေးမကူညီသည်။ ကူညီစောင့်ရှောက်သည်။ စောၚ်မသည်။/ “ဨကရာတ်နာဲပိုဲ ကဵုဂွံ ဗၠးနူသ္ကေံတဲသတြုညိ။ ဒေဝတဴတံ ဆောံမဒ္ဂူမၚ်မွဲဨကရာတ်နာဲပိုဲညိ။” (ဇ—၂၈၉။ အစွောံ။) = “ငါတို့အရှင်မင်းမြတ် ရန်သူ့လက်တွင်းမှ လွတ်မြောက်ပါစေသတည်း။ ငါတို့အရှင်မင်းမြတ်အား နတ်အပေါင်းတို့ စောၚ်မစောင့်ရှောက်ကြပါစေသတည်း။”
,ဆောံလေၚ် (ကြိ) ဆုံးရှုံးသည်။
,ဆာဲ (ကြိ) ၁။ ကောင်းသည်။ တင့်တယ်သည်။/ “သၟိၚ်မဟွံမၚ်မွဲဓဝ်သၟိၚ်စှ်ပြကာဂှ် သၟိၚ်ဂှ်ဟွံဆာဲရ။” = “မင်းကျင့်တရားဆယ်ပါးကို မစောင့်သောမင်းသည် မကောင်း။”/ “ယွံတၠအဲ၊ တ္ၚဲဝွံ မ္ၚဵု မွဲမသ္ပနွံကုအဲဍိက်၊ နက်သတ်ဆာဲဗၠးဒုဟ်ရဟာ။” (ဇ—၄၉။ အစွောံ။) = “အရှင်ဘုရား၊ ယနေ့ အကျွန်ုပ်တို့သည် တခုသောမၚ်္ဂလာကို ပြုပါကုန်အံ့။ နက္ခတ်သည် ကောင်းပါအံ့လော။”(ညောင်ကန်)/ ရာၚ်ဆာဲ = တင့်တယ်သည်။/ ဂေါဝ်ဆာဲ = လှပတင့်တယ်သည်။/ ၂။ သွန်သည်။/ “ဍာ်ပ္ဍဲထၟာဲဂှ် ဆာဲထောံညိ။” = “အိုးထဲမှရေကို သွန်ပစ်လိုက်ပါ။”/ “(သၟိၚ်အိန်)ပရာပ်ဏာကွဳ ပ္ဍဲပါၚ်တရၚ်သ္ၚိသုဇာတာဂှ်တုဲ ဆာဲကဵုဂအဳထဝ်မွဲကွဳဂှ်—။” (ဇ—၃၁။ အစွောံ။) = “သိကြားမင်းသည် လှည်းကို သုဇာတာအိမ်တံခါးဝသို့ ယူဆောင်သွားပြီးလျှင် ရွှေသခွားတစ်လှည်းကို သွန်ချပေး၏။”
,ဆာဲကနှံ၊ ဆာဲကနှမ် (ကြိ) လှပကောင်းမွန်သည်။ တင့်တယ်သည်။/ “ယာတ်ပ္ဍဲသုသာန်ဂှ် မဂပ် ဂဝ်ကဵုပိုဲခမဳရောၚ်၊ မဒှ်မ္ၚဵုပိုဲခမဳရောၚ်။ — ယာတ်မဂ္ညိဂ္ညာတ်ဂေါဝ်ဂပ်ဆာဲကနှံတဴဂှ် ကျာ်အရှန်ပစ္စေဂ ဗုတ်တံ ဟွံပမ္ၚဵုရ။” (ဇ—၈၇။ အစွောံ။) = “သုသာန်­စွန့်ထားသောအဝတ်သည် ရဟန်းတို့နှင့် သင့်လျော်၏။ ရဟန်းတို့၏မၚ်္ဂလာဖြစ်၏။ လှပတင့်တယ်ကောင်းမွန်သောအဝတ်ကို ဘုရားရ ဟန္တာပစ္စေကဗုဒ္ဓာတို့သည် မၚ်္ဂလာဟူ၍ မမှတ်ယူတော်မူကုန်။”
,ဆာဲကိုဟ် (ကြိ) သွန်ပစ်သည်။
,ဆာဲခြာ (ကြိ) ကွဲကွာသည်။ ကွေကွင်းသည်။/ ‘သြာဲခြာ’ ရှု။
,ဆုဲ (ကြိ) ရွေ့သည်။ ရွှေ့သည်။/ “ဆုဲအာဂတတေံညိ။” = “အရှေ့သို့ရွှေ့ပါ (ရှေ့တိုးပါ။)” 
,ဆုဲပြံၚ် (ကြိ) ရွှေ့ပြောင်းသည်။/ “ကွာန်ဂှ်ဍာ်ဇၞော်တုဲ ဒးဆုဲပြံၚ်ထောံဒၞာဲရ။” = “ထိုရွာသည် ရေ ကြီး၍ နေရာရွှေ့ပြောင်းလိုက်ရသည်။”
,ဆဝ် (ကြိ) နှိုးဆော်သည်။/ “တ္ၚဲယးဂတ သ္ၚိပိုဲဒးအလန်ပိဏ္ဍပါတ် ညးဆဝ်လဝ်တုဲရ။” = “မနက် ဖြန်ခါ ငါတို့အိမ်ဆွမ်းအလှည့်ကျတယ်၊ လူလာနှိုးဆော်ပြီးပြီ။”/ “(ဗောဓိသတ်) ကဵုလန်ဖံဇၞော် ဂရၚ်ပ္တီညးဍုၚ်ဂမၠိုၚ်ရ၊ ကဵုကော်ဆဝ်ဟီုရ။” (ဇ—၂၄၁။ အစွောံ။) = “ဘုရားလောင်းသည် စည်လည်စေ၍ မြို့သူအပေါင်းတို့အား သိစေ၏။ ပြောဆိုနှိုးဆော်စေ၏။”
,ဆဝ်မ္ၚုဟ်၊ ဆဝ်ပ္ၚုဟ်၊ ဆဝ်ဗ္ၚုဟ် (ကြိ) နှိုးဆော်သည်။ ဆော်သြသည်။ (ပါဠိ—သမာဒပေတိ)
,ဆေဝ်—၁၊ ဆေ (ကြိ) တားသည်။ တားမြစ်သည်။ တားဆီးသည်။/ “—၊ ဗှ်ေလ္ပဟီု ဗှ်ေကၞပ်” (ဗမၞးအ္စာဂှ်)ဂးတုဲ ဆေဝ်ကၠေံကွးဂှ်ရ။ (ဇ—၃၁၄။ အစွောံ။) = “နၚ်မပြောနှင့်၊ နၚ်နှုတ်ပိတ် တိတ်လေ” ဟုဆရာပုဏ္ဏားသည် တပည့်ကို တားမြစ်၏။
,ဆေဝ်—၂၊ ဆေ (ကြိ) ၁။ ဘေးဖက်အရပ်သို့ လှည့်၍သွားသည်။ ချိုးကွေ့သည်။/ “ညးၜါကွာ်စဴ ကၠုၚ် ညာတ်ဍာ်လစမွဲတုဲ ဆေဝ်လုပ်အာနူဂၠံၚ်ဇၞော်ဂှ်တုဲ ပ္ဍဲသမၞိၚ်တၞံဇြဲဂှ် ဂ္ဇအ်ဇူဒၟံၚ်ရ။” (ဇ—၃၃၃။ အစွောံ။) = “နှစ်ဦးသားလျှောက်ပြန်လာရာ တစ်ခုသောရေကန်ကိုမြင်၍ လမ်းခရီးမမှ ချိုးကွေ့ဝင်၍ ညောင်ပင်ရိပ်­ ထိုင်၍နားနေ၏။”/ “တြုံကုန်ကဵုသၟတ်ဗြဴ ညးၜါမအာဂှ် — တြုံကုန် ဂှ် ဒးပရိုက်ကျာတုဲ တ္ၜိုဟ်ဒဇပ်ဇတဝ်အာ ပ္ဍဲဖလာၚ်ယး ဆေဝ်တိတ်အာနူတြဴညိတုဲ တိတ်သတိက် ကဝေန်ဒၟံၚ်ရ။” (ဇ—၂၃၂။ အစွောံ။) = “ငကုန်းနှင့်သူငယ်မနှစ်ဦးတို့ ခရီးသွားကြရာ ငကုန်းသည် လေအေးဒဏ်ကြောင့် ခိုက်ခိုက်တုန်ချမ်းသည်ဖြစ်၍ အရုဏ်တက်ချိန်­ လမ်းခရီးမှ အ နည်းငယ်ချိုးကွေ့ထွက်ပြီးလျှင် ထွက်၍ကွေးအိပ်နေ၏။”/ ၂။ လမ်းဖယ်သည်။ ဘေးသို့ဖယ် ရှောင်သည်။/ “ပြောဟိတ်ဂှ် ကာလမစဝ်အာကွဳဂှ် စိုပ်ပ္ဍဲဋ္ဌာန်ခမၞောန်ဂှ် ညာတ်ကွဳစောတ်ညးကၠံ ကွဳဂှ်တုဲ ဟီုကဵုညးကွဳစောတ်တံဂှ် ‘ဆေဝ်ကွဳ’ ‘ကွဳဂၠိုၚ်လောန်အာ ဆေဝ်ဟွံမာန်’ ဍေံဂးတုဲ ဍေံ ဟွံဆေဝ်ရ။” (ဇ—၃၃၂။ အစွောံ။) = “ပုရောဟိတ်သည် လှည်းရထားဖြင့် သွားသည်ရှိသော် ကျဉ်းမြောင်းသောခရီး­ လှည်းတစ်ရာနှင့်တကွ လှည်းကုန်သည်တို့ကိုမြင်လျှင် ‘သင်တို့လှည်းကို ဖယ်လော့’ ဟုဆိုရာ ‘လှည်းများလွန်း၍ မဖယ်နိုင်ပါ’ ဟု လှည်းကုန်သည်တို့ဆို၍ မဖယ်ရှောင် ချေ။”/ “ကွဳသၟိၚ်ဨကရာတ်ၜါ — အာဆဵုဒးညးသ္ကအ် ပ္ဍဲဋ္ဌာန်ကရေပ်မွဲဂှ် သွက်ဂွံဆေအာသ္အာၚ် ဟွံ မွဲသက်က်ရောၚ်။” (ဇ—၁၅၁။ အစွောံ။) = “မင်းဧကရာဇ်နှစ်ပါး၏ရထားတို့သည် ကျဉ်းမြောင်း သောနေရာတစ်ခု­ ဆုံမိကြရာ ဖယ်ရှောင်စရာမရှိဖြစ်၏။”/ “ကကၟက်အာကြဴ ကဗြဴအာဂတ ကဗြဴဂွံသမူဇာတုဲ ကဗြဴဆေဝ်ကၠေံ ကကၟက်ဓလူအာဒးဇာ—။”(ဇ—၂၁၆။ အစွောံ။) = “ငါးဖိုသည် နောက်မှသွား၍ ငါးမသည် ရှေ့မှသွား၏။ ငါးမသည် ကွန်နံ့ရသည်ရှိသော် ကွေ့ရှောင်ဖယ်သွား ၏။ ငါးဖိုသည်ကား ရှေ့တိုး၍သွားရာ ကွန်­ငြိ၏။”/ ၃။ (လမ်း၊ မြစ်ချောင်းစသည်) တစ်ခုနှင့် တစ်ခု ပေါင်းဆုံခွဲဖြာသွားသည်။/ “ပ္ဍဲအကြာဂၚ်ၜါ ဂၚ်္ဂါကဵုယမုနာ မဆေဝ်အာရေၚ်သ္ကံဂှ်။” (ဇ— ၂ဝ၅။ အစွောံ။) = “ဂၚ်္ဂါမြစ်နှင့်ယမုနာမြစ်နှစ်ခုတို့ ခွဲဖြာသွားသောနေရာ။” (‘မြစ်ဆုံအရပ်’ ဟူလိုသည်။)
,ဆေဝ်ကြတ် (ကြိ) (ဘေးအန္တရာယ်၊ အခက်အခဲစသည်) ဖြတ်တားဆီးကာသည်။ ပိတ်ဆီးသည်။/ “ယွံအမာတ်တံ၊ ညံၚ်ရဴညးဗၞိက်တံ ဍိုက်ဂၠုၚ်ဇၞော်တုဲ လှောင်အာပ္ဍဲဒေါဝ်မှာသၟိတ်ဂှ် အန္တရာဲဂမၠိုၚ် မ ဆေဝ်ကြတ်မဂိုၚ်လဝ်ကီုရ၊ အဲသ္အာပဂမှဳလၟုဟ်ဝွံပၠန်ဂှ် ကောန်အဲဒိဃာဝုဂှ် မပလီုတရဴအဲရောၚ်။” သၟိၚ်ဂး။ (ဇ—၅၂၉။ အစွောံ။) = “အမတ်တို့၊ လှေကြီးစီး၍ သမုဒ္ဒရာလယ်­ ရွက်လွှင့်သွား သောကုန်သည်တို့အား ဘေးအန္တရာယ်များ ဖြတ်တားပိတ်ဆီး ကိုၚ်ၚၚ်ဘိသကဲ့သို့ပင် ယခုငါ၏ ရဟန်းပြုခြင်းကိုလည်း ငါ့သားတော်ဒိဃာဝုသည် ငါ၏ခရီးကို ဖျက်ဆီးချေ၏။”
,ဆေဝ်တာ (ကြိ) တားဆီးသည်။ တားမြစ်သည်။/ “—၊ အဲသ္အာကီု” ဂၞကျာ်ဂး။ သၟိၚ်ဆေဝ်တာကၠေံ ဟွံကဵုအာ—။ (ဇ—၁၂ဝ။ အစွောံ။) = “အကျွန်ုပ်လည်းသွားပါအံ့” ဟုမိဖုယားဆို၏။ မင်းသည် တားမြစ်၍ သွားခွင့်မပြု။/ “မၞိဟ်သ္ကအ်သၟိၚ်တံဂှ် ဍေံကမြဴရပ်(သၟိၚ်ခဍာ်)ရ။ သၟိၚ်ဆေဝ်တာဟွံကဵု ရပ်—။” (ဇ—၁၄ဝ။ အစွောံ။) = “မင်းချင်းယောကျာ်းတို့သည် ကျီးမင်းကိုဖမ်းရန် အားထုတ် ကြကုန်၏။ မင်းသည်တားမြစ်၍ ဖမ်းခွင့်မပေး။”/ “သတြုတၠညးမက္တဵုဒှ်ဂှ် အဲဍိက်ဆေဝ်တာရ အဴ။” (ဇ—၃ဝ၃။ အစွောံ။) = “သၚ်မင်းကြီး၏ရန်သူတို့ ပေါ်ပေါက်သည်ရှိသော် အကျွန်ုပ်တား မြစ်ပါအံ့။”
,ဆေဝ်ဒဝ် (ကြိ) တားမြစ်သည်။ တားဆီးသည်။/ “ဟွံခိုဟ်ဆေဝ်ဒဝ်၊ ခိုဟ်စဝ်ထ္ၜးဏာ၊—။” = “မကောင်းမြစ်ထာ၊ ကောင်းရာညွှန်လတ်၊—။”/ “သွေက်ဇွဵုအမာတ်ၜါဂှ် သၟိၚ်ကီုလေဝ် ဆေဝ်ဒဝ်ဟွံ မာန်ရ” = “ထိုအမာတ်နှစ်ဦးတို့၏ခိုက်ရန်ကို မင်းသည်ပင်လည်း မတားမြစ်နိုင်။”/ “ဗောဓိ သတ်(တ္ၚေက်) ဒလောံဗတောန်ဒေံဂှ်တုဲ ဆေဝ်ဒဝ်ကၠေံဒေံဂှ် ဟွံကဵုဟီုရ။” (ဇ—၁၄၅။ အစွောံ။) = “ဘုရားလောင်းကျေးသည် ညီအားဆုံးမ၍ မပြောအောင်တားမြစ်၏။”
,ဆေဝ်ပလီု (ကြိ) တားဆီးသည်။ တားမြစ်သည်။/ “သၟိၚ်သၟိက်တိတ်ဂြိုပ် သ္ပခမဳဣသိရ၊ ညးမွဲကီု လေဝ် ဆေဝ်ပလီုဟွံမာန်ဟေၚ်။” = “မင်းသည် တောထွက်၍ ရသေ့ရဟန်းပြုလို၏၊ မည်သူမျှ မင်းအား မတားမြစ်နိုင်။”
,ဆေဝ်ပလေဝ် (န) လျှပ်စီး။/ ဆေဝ်ပလေဝ်ပံက် = လျှပ်စီးလက်သည်။
,ဆေဝ်ရေဝ်၊ ဆေရေ (ကြိ) တူညီသည်။ တူမျှသည်။ တန်းတူဖြစ်သည်။/ “ဗောဓိသတ်မဒှ်ပ္ဍဲဂကူ သေဋ္ဌဳ နအပေါတ်တသိုက်မဂၠိုၚ်သာ် ဆေရေဝ်ဒၟံၚ်ကဵုဒိပ် ညံၚ်ကောန်ဒေဝတဴကီု။” (ဇ—၄ဝ။ အစွောံ။) = “ဘုရားလောင်းသည် သူဌေးမျိုး­ဖြစ်၍ အထူးထူးအပြားပြားသော စည်းစိမ်ဥစ္စာတို့ ဖြင့် နတ်စည်းစိမ်တမျှဖြစ်၏။” (‘ဒိပ်’ ဟူသောမွန်ဝေါဟာရသည် ‘ဒိဗ္ဗ’ ဟူသောပါဠိဝေါဟာရ မှ ဆင်းသက်လာသည်။ ‘နတ်’ ‘နတ်­ဖြစ်သော’ ဟု အနက်ရသည်။)/ “ဗောဓိသတ်အလံၚ် ကျာ်တြဲအရဳယျဂှ် နွံကဵုပြာသာဒ်ပိရ၊ ပြာသာဒ်ပိဝွံဂှ် တုပ်သၟဟ်ဆေဝ်ရေဝ်ဒၟံၚ် ညံၚ်ကဵုပြာသာဒ်ဝေ ဒယန္တဝ်ကီုရ။” (အဓါန်မသုန်။ အစွောံ။) = “အရိမေတ္တေယျဘုရားလောင်း­ ပြာသာဒ်သုံးခုရှိ ၏၊ ဤပြာသာဒ်သုံးဆောင်သည် (တာဝတိၚ်သာနတ်ပြည်ရှိ သိကြားမင်း၏) ဝေဒယန္တာပြာသာဒ် နှင့် တန်းတူညီမျှ၏။”
,ဆေဝ်လုန် (န) ကျွမ်းထိုးခြင်း။/ ဗ္တက်ဆေဝ်လုန် = ကျွမ်းထိုးသည်။
,ဆောဝ်လအ်၊ ဆဵုလအ် (ကြိဝိ) ဘယ်သောအခါ (စကားသုံး)။/ “ဆောဝ်လအ်ဗှ်ေတိုန်ဍုၚ်ရော။” = “နၚ်ဘယ်တော့မြို့တက်မလဲ။”
,ဆဵု (ကြိ) တွေ့သည်။ ကြုံဆုံသည်။/ “အဲဆဵုဍေံကွာ်ဒၟံၚ်ပ္ဍဲဂၠံၚ်ရ။” = “လမ်းတွင် သူလျှောက်နေသည်ကို ကျွန်တော်တွေ့ခဲ့သည်။”/ “ဇဖန်ဂွံဆဵုသာသနာကျာ်တြဲ မှတ်ပ္တုဲလဝ်ဓဝ်ကုသဵုညိ။” = “မြတ်စွာဘုရားသာသနာကို ကြုံဆုံခိုက် မဖြစ်မနေလုံ့လထုတ်၍ ကုသိုလ်ကောင်းမှုပြုထားပါ။”/ “ကွဳသၟိၚ်ဨကရာတ်ၜါ — အာဆဵုဒးညးသ္ကအ် ပ္ဍဲဋ္ဌာန်ကရေပ်မွဲ—။” (ဇ—၁၅၁။ အစွောံ။) = “မင်းဧကရာဇ်နှစ်ပါး၏ရထားတို့သည် ကျဉ်းသောနေရာတစ်ခု­ ဆုံမိကြ၏။”
,ဆဵုပါၚ်ဟီု (ကြိ) တွေ့ကရာလျှောက်ပြောသည်။ ထင်မိထင်ရာလျှောက်ပြောသည်။/ “သေဋ္ဌဳတၠပိုန်တၠ ဂတိဝွံ ဟွံတီစၟတ်တုဲ ဂလာန်မ္ၚဵု ဆဵုပါၚ်မဟီုဟွံတန်ဒှ်ရ” ညးဒိုက်ဂှ်ချပ်။ (ဇ—၄။ အစွောံ။) = “ဤဘုန်းပညာရှိသူဌေးသည် အကြောင်းအမှန်ကိုမသိဘဲ မၚ်္ဂလာရှိသောစကားကို တွေ့ကရာ လျှောက်ပြောသည် မဖြစ်တန်ရာ။” (အကြောင်းအမှန်ရှိ၍သာ ပြောခြင်းဖြစ်မည်ဟူလို။)
,ဆအ်လအ် (ကြိ) လွန်ကျူးသည်။ လျှပ်ပေါ်သည်။ ငမ်းသည်။/ “(ဗြဴမ္ဂးဝွံ မဒှ်ဟိုတ်ဒဒိုက်ရောၚ်)၊ နွံကဵုလဟီုပွ မဆအ်လအ်မလုလန် ညံၚ်ဂစေံခဍာ် မလုလန်ပ္ဍဲဖျုန်ကီု။” (ဇ—၆၁။ အစွောံ။) = “မိန်းမတို့မည်သည် ဒုက္ခ၏အကြောင်းတည်း။ အသားတို့­ငမ်း၍ လျှပ်ပေါ်သောကျီးငှက်ကဲ့သို့ လွန်ကျူးလျှပ်ပေါ်သော အပြောအဆို အပြုအမူရှိကုန်၏။”/ (?)
,ဆောအ် (ကြိ) ထိုးဆွသည်။ မြှောက်ပင့်သည်။
,ဆိုအ် (ကြိ) ဆို့သည်။ ပိတ်ဆို့သည်။ 
,ဆိုအ်ဗ (ကြိ) ဆို့နစ်သည်။/ ဆိုအ်ဗတဴပ္ဍဲသြိုဟ် = ရင်ထဲတွင်ဆို့နစ်သည်။
