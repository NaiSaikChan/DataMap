ဓ (န) တစ်ဆယ့်ကိုးလုံးမြောက်မွန်ဗျည်း။
,ဓဂါ၊ ဒဂါ (န) ရင်ဂတ်သီးပင်။
,ဓဂဳ၊ ဂဂဳ (န) ကင်းခြေများ။
,ဓဂိုက် (န) ကနကုတ်မြွေ။
,ဓဂါတ် (ကြိ) ‘ဒဂါတ်’ ရှု။
,ဓဂိတ်၊ ဒဂိတ် (န) ကြမ်းပိုး။
,ဓဂုတ် (ကြိ) ဈေးဆစ်သည်။/ “ရာန်ဖျာမ္ဂး ဓဂုတ်တုဲရာန်ညိ။” = “ဈေးဝယ်လျှင် ဈေးဆစ်ပြီး ဝယ်ပါ။”
,ဓဂိုန် (န) ဝါဆိုလ။/ (ကြိ) ဆောက်တည်သည်။/ ‘ဒဂိုန်’ ရှု။
,ဓဂဵု၊ ဂဂဵု (န) ၁။ မိုးချုန်းခြင်း။ မိုးကြိုး။/ ဂဂဵုဂတးပန် = မိုးကြိုးပစ်သည်။/ ဂဂဵုဒရိၚ် = မိုးချုန်းသည်။/ ၂။ သစ်ပင်အၚုတ်၊ သစ်ၚုတ်။/ ‘ဒဂဵု’ ရှု။
,ဓဂြာ၊ သဂြာ (န) သကြား။/ ဓဂြာက္ၜၚ် = ချွတ်ထားသောသကြား၊ သကြားအဖြူ။/ ဓဂြာတၟအ် = သကြားခဲ။
,ဓဂြီု (ကြိ) ဖမ်းသည်။/ ဗ္ဂဲဓဂြီုကၞိ = ကြောင်က ကြွက်ကိုဖမ်းသည်။
,ဓစုက်၊ ဂစုက် (န) ဆူးငြောင့်။/ ဒးဓစုက် = ငြောင့်စူးသည်။
,ဓစုန်၊ ဒစုန် (န) တောင်ဝှေး။
,ဓဇူ (ကြိ) ယိုသည်။/ ‘ဒဇူ’ ရှု။
,ဓဇဲ၊ ဒဇဲ (န) လက်သမား။
,ဓဇက်၊ ဒဇက် (ကြိ) ဆွဲသည်။ ဒရွတ်တိုက်ဆွဲသည်။/ ‘ဒဇက်’ ရှု။
,ဓဇာၚ် (န) ဆတ်သွားပင်။
,ဓဇေၚ် (န) သဇင်ပန်း။
,ဓဇောတ် (ကြိ) စိမ့်သည်။/ ၜိုဟ်ဓဇောတ် = စိမ့်ပြီးချမ်းသည်။/ ဂိဓဇောတ် = အရိုးစိမ့်အောင်နာသည်။
,ဓဇိုတ် (န) ခြေသုတ်။/ (ကြိ) သုတ်သည်။/ ဓဇိုတ်ဇိုၚ် = ခြေသုတ်သည်။
,ဓဇန်၊ ဒဇန် (ကြိ) ရက်စက်သည်။/ ဓဇန်သဟာသဳ = ရက်စက်ကြမ်းကြုတ်သည်။/ ဒေပ်စိုတ်ဓဇန် = ရက်စက်သောစိတ်ရှိသည်။
,ဓဇိပ်၊ ဒဇိပ် (န) နေစာမြက်။
,ဓဇီ (ကြိ) ခုတ်စဉ်းသည်။/ (န) စဉ်းကော။/ ဓဇီစာၚ် = ကြက်သားစဉ်းကော။
,ဓဇဝ် (န) ကစော်ရည်။ စိမ်ရည်။
,ဓဇိုဟ် (န) သပွတ်ပင်။ သပွတ်သီး။
,ဓည၊ ဒည (ကြိ) ရွံ့သည်။ ရိုသေသည်။/ ဒညကမၠ = ကြောက်ရွံ့သည်။/ ညှာဒည = မဝံ့မရဲ ဖြစ်သည်။ အားနာသည်။
,ဓညိက် (ကြိ) ညိတ်သည်။/ ဓညိက်က္ဍိုပ် = ခေါင်းညိတ်သည်။
,ဓညော် (ကြိ) လည်ကိုဆန့်သည်။
,ဓညံက် (ကြိ) ညိတ်သည်။/ ဓညံက်ကအ် = လည်ညိတ်သည်။
,ဓညောန် (ကြိ) ဟိန်းဟောက်သည်။
,ဓညောဝ် (န) ကြောင်ပန်းရွက်။
,ဓဒု၊ ဂဒု (ကြိ) ထုသည်။ ရိုက်သည်။
,ဓန (ကြိ) သနသည်။ ယုတ်ညံသွားသည်ဟု မှတ်ထင်ခံစားရသည်။/ “ဂွံလဝ်ဂဝံခိုဟ်ဟ်တုဲ ဂၠောန်ဒးသၟဝ်တေၚ်ဂၞိန်မ္ဂး ဓနအာရောၚ်။” = “အဆောင်ကောင်းကောင်းရထားပြီး ထမီတန်းအောက် လျှိုမိလျှင် သနသွားလိမ့်မည်။”/ “ဒွံဝတ္ထုမဟွံသ္အး ဓနအာ။” (ဇ—၇၁။ အစွောံ။) = “မသန့်သောဝတ္ထုနှင့် ထိမိသဖြင့် သနသွားသည်။”/ (ပါ) (န) ပစ္စည်းဥစ္စာ။ ဓနဥစ္စာ။
,ဓနိတအက္ခရ (ပါ) (န) (သဒ္ဒါ) အင်အားစိုက်ထုတ်၍ အသံတင်းတင်း ရွတ်ဆိုရသောအက္ခရာ။ သံတင်းအက္ခရာ။ ဓနိတအက္ခရာ။/ ‘သိထိလအက္ခရ’ လည်းရှု။
,ဓနဳ (န) ပျဉ်းမပင်။/ (ပါ) (နဝိ) ချမ်းသာသော။
,ဓနု (သသက်) (န) ဓနုရာသီ။ (ဆယ့်နှစ်ရာသီတွင် လေးစွဲယောကျာ်းရုပ်ဖြင့် မှတ်အပ်သော နဝမရာသီ။)
,ဓနဴ (ပါသက်) (န) အသူရာမည်သောဘီလူး။ ဒါနောရက္ခိုသ်။
,ဓနက်၊ ဒနက် (န) ၁။ နယ်ကြားမှတ်တိုင်။/ ပယျဵုဓနက် = နယ်ကြား။ နယ်နိမိတ်။/ ၂။ ကျော့ကွင်း။/ ပံါဓနက် = ကျော့ကွင်းထောင်သည်။/ “လၟအာပံါဓနက် ကေတ်သၟိၚ်မြာ်ထဝ်။” (ဇ— ၁၅၉။ အစွောံ။) = “မုဆိုးသည် ရွှေဥဒေါင်းမင်းကို ဖမ်းယူရန် ကျော့ကွင်းထောင်၏။”
,ဓနေၚ် (န) ဒညင်းသီး။/ ဓနေၚ်ကၞာဲ = ဒညင်းသီးအကြီးစား။/ ဓနေၚ်ဂစေမ် = ဒညင်းသီးအသေးစားမျိုး။
,ဓနန် (န) စဉ်းတီတုံး။ စဉ်းနှီးတုံး။/ (‘ဒန်’ (ကြိ) ပွားလာသော ဝေါဟာရဖြစ်သဖြင့် ‘ဒနန်/ဒၞန်’ ဟုဖြစ်သင့်သည်။) “ဍေံပ္ဍဵုလဝ်ကအ်ဗောဓိသတ်ကဵုဓနန်တုဲ—။” (ဇ—၁၉၄။ အစွောံ။) = “မင်းချင်းတို့သည် ဘုရားလောင်း၏လည်ကို စဉ်းနှီးတုံး­ ဖိထားပြီးလျှင်—။”/ ‘ဒၞန်’ ရှု။
,ဓနီ (န) အသိုက်အမြုံ။/ တိုန်ဓနီ = (တိရစ္ဆာန်များ) အိပ်တန်းတက်သည်။/ (ကြိ) ၁။ ပေကတ် ကတ်ဖြစ်သည်။/ “ချေံဏအ်ဓနီကွေံကွေံရ။” = “ဤမြင်းသည် အလွန်ပေကတ်သည်။”/ ၂။ ရှောင်လွှဲသည်။
,ဓနီပူ (န) အိပ်မွေ့သီး။
,ဓနေဟ် (န) ဖနောင့်။/ ဓနေဟ်ဇိုၚ် = ခြေဖနောင့်။
,ဓနေအ် (န) ဂုံညင်း။/ ဝေၚ်ဓနေအ် = ဂုံညင်းကစားသည်။
,ဓဗ၊ ဂဗ (ကြိ) တွေ့ဆုံသည်။
,ဓဗး (ကြိ) ‘ဂဗး’ နှင့်အတူတူ။/ “လ္ၚဵုထနိက် လ္ၚဵုဓဗး လ္ၚဵုဇီုကဵုတၟံ—။” (ဇ—၂၂ဝ။ အစွောံ။) = “အချို့သူတို့သည် ကန်ကျောက်ကုန်၏၊ အချို့ရိုက်ပုတ်ကုန်၏၊ အချို့သူတို့ကား ကျောက်ခဲဖြင့် တိုက်ဆောင့်ကုန်၏။”
,ဓဗိုၚ် (ကြိ) ခုတ်လှဲသည်။/ ဓဗိုၚ်တၞံဆု = သစ်ပင်ခုတ်လှဲသည်။/ ‘ဒဗိုၚ်’ ရှု။
,ဓဗာန် (ကြိ) ကပ်သည်။/ “တၞးလိက်ဏအ်ဓဗာန်လဝ် ပ္ဍဲဗဒၚ်ညိ။” = “ဤစာရွက်ကို နံရံတွင် ကပ်ထားပါ။”
,ဓဗိုန် (န) ဗုံ။ ပတ်မ။ စည်။
,ဓဗြ (န) အနယ်။
,ဓဗြိုက် (ကြိ) အစုအဝေးဖြစ်သည်။ ပြွတ်သိပ်သည်။/ “ကြုက်တၞံဏအ် သတ်ဓဗြိုက်ဒၟံၚ်ရ။” = “ဤသရက်ပင်သည် ပြွတ်သိပ်ပြီးသီးသည်။”
,ဓမကရိုန်၊ ဓမကရိုဏ်၊ ဓမ္မကရိုဏ် (ပါသက်) (န) ရဟန်းတို့၏ ပရိက္ခရာရှစ်ပါးတွင် ပါသောရေစစ်။ ဓမကရိုဏ်။ (ပါဠိ—ဓမ္မကရဏ)
,ဓမာနူ (ဝိ) (သဗဓ) အကြောင်းကြောင့်။/ ‘ဒၟာနူ’ ရှု။
,ဓမဳ (ကြိ) အနီးကပ်၍ကြည့်သည်။/ ဓမဳရံၚ် = အနီးကပ်၍ သေချာစွာကြည့်သည်။/ ‘ဇၟဳရံၚ်’ ရှု။
,ဓမၚ်၊ ဒမၚ် (န) ၁။ သက်တံ။/ ၂။ ဒမင်း။ (ပင်လယ်စပ်နှင့် မြစ်ဝများတွင် ငါးသယ်၊ ပုစွန်ငယ်များကို ထောင်ဖမ်းရသော ကတော့ပုံ ငါးဖမ်းကိရိယာ။) ဖရံက်ဒမၚ် = ဒမင်းငပိ။ (မြန်မာဝေါဟာရ ‘ဓမင်း’သည် မွန်ဝေါဟာရ ‘ဓမၚ်’ မှ ဆင်းသက်လာသည်။)/ ၃။ ထုပ်လျောက်။
,ဓမုၚ် (န) ၁။ လေမှုတ်သားရေဖားဖို။/ တံၚ်ဓမုၚ် = အဂ္ဂိရပ်ထိုးသည်။/ ၂။ မြောင်း။/ ဓမုၚ်ဍာ် = ရေမြောင်း။
,ဓမုၚ်ယန် (န) ယက်ကန်းစင်။
,ဓမာတ် (န) ပန်းထိမ်။ ပန်းဘဲ။/ ‘ဒမာတ်’ ရှု။
,ဓမာန်၊ ဒမာန် (ကြိ) အလိုလျောက်ပြောမိသည်။/ ကြာန်ဓမာန် = ရမ်းကားသည်။/ ယာံဓမာန် = ငိုကြွေးမြည်တမ်းသည်။
,ဓယိ (ကြိ) လိမ်းသည်။/ ဓယိကၠေၚ် = ခေါင်းဆံပင်ကို ဆီလိမ်းသည်။/ ကၠေၚ်ဓယိ = ခေါင်းလိမ်းဆီ။
,ဓယူ (န) တံစက်မြိတ်။/ ‘ဒယူ’ ရှု။
,ဓယာ် (န) တောင်စလဲပင်။ တောင်စလဲသီး။
,ဓယိုန် (ကြိ) ‘ဒယိုန်’ ရှု။
,ဓယှ် (ကြိ) ကျော်ကြားသည်။/ “ဣတေံပြာကတ်ဓယှ်တဴရ။” (ဇ—၂ဝ၂။ အစွောံ။) = “သူသည် ထင်ရှားကျော်ကြား၏။”/ ‘ဒယှ်’ ရှု။
,ဓရာ (န) ‘ဒရာ’ ရှု။
,ဓရဳ၊ ဒရဳ (န) စဉ့်အိုးကြီး။/ ‘ဇရဳ’ ရှု။
,ဓရိုက်၊ ဒရိုက် (ကြိ) လှုပ်သည်။/ “ဖျုၚ်ဂဥုဲမ္ဂး ဓရိုက်ပလၚ်ဂဥုဲကၠာတုဲ ဖျုၚ်ညိ။” = “ဆေးတိုက်လျှင် ဆေးပုလင်းကို လှုပ်ပြီးတိုက်ပါ။”/ ‘ဂရိုက်’ ရှု။
,ဓရိုက်က္ဍိုပ်၊ ဂရိုက်က္ဍိုပ် (ကြိ) ခေါင်းခါသည်။ ငြင်းပယ်သည်။
,ဓရံၚ် (န) ‘ဒရံၚ်’ ရှု။
,ဓရာံ၊ ဒရာံ (န) ကျီ။/ ‘ဇရာံ’ ရှု။
,ဓရီု (ကြိ) ‘ဒရီု’ ရှု။
,ဓရေဲ (န) ကနစိုးသီး။
,ဓရိုဟ် (ကြိ) တွန်းသည်။/ ‘ဒရိုဟ်/ဇရိုဟ်’ ရှု။/ “ဗှ်ေဓရိုဟ်ဖတုံဖျေံအဲ ပ္ဍဲဗပါ်တၟအ်ဂှ် ဗှ်ေဝိုတ်အာရဟာ။” (ဇ—၁၉၃။ အစွောံ။) = “တောင်ကမ်းပါးပြတ်­ ငါ့ကို နင်တွန်းချပစ်ခဲ့သည်ကို နင်မေ့သွားပြီလား။”
,ဓလ၊ ဇလ (န) ဆူး။/ ဒးဓလ = ဆူးစူးသည်။
,ဓလူ (ကြိ) ‘ဒလူ’ ရှု။
,ဓလိၚ် (ကြိ) သယ်သည်။ ပင့်၍သယ်ဆောင်သည်။/ (န) ထမ်းစင်။ လူထမ်းယာဉ်။/ ‘ဒလိၚ်’ ရှု။
,ဓလုၚ်တုတ် (ကြိ) ယက်ကန်းရက်ရန် ချည်ရှယ်သည်။/ ‘ဒလုၚ်တုတ်’ ရှု။
,ဓလန် (ကြိ) မျက်လုံးပြူးသည်။ ပြူးအောင်လုပ်သည်။/ မတ်ဓလန် = မျက်လုံးပြူးသည်။/ ဓလန်လဝ်မတ် = မျက်လုံးပြူးပြသည်။
,ဓလီု၊ ဒလီု (ကြိ) ၁။ ဖုံးအုပ်သည်။ ခြုံသည်။/ ဓလီုယာတ် = စောင်ခြုံသည်။/ ဓလီုက္ဍိုပ် = ခေါင်းမြီးခြုံသည်။/ ၂။ လွှမ်းမိုးသည်။ ဖိစီးသည်။/ ‘ဂလီု’ ရှု။
,ဓလီုဍိုက်၊ ဓလီုပ္ဍိုက် (ကြိ) လွှမ်းမိုးဖိစီးသည်။/ ‘ဂလီုဍိုက်’/‘ဂလီုပ္ဍိုက်’ ရှု။
,ဓလာဲ (ကြိ) လဲလျောင်းသည်။ မှီသည်။/ ‘ဒလာဲ’ ရှု။
,ဓလဵု၊ ဓလဵုခၞံၚ်၊ ဓလဵုထဏံၚ် (ကြိ) လူပါးဝသည်။ ရိုင်းပျသည်။ မိုက်ရိုင်းသည်။/ “ကောန်ၚာ်ဏအ် မိမဍေံဟွံဝေတ်လဝ်တုဲ ဓလဵုခဏံၚ်ကွေံရ။” = “ဤခလေးသည် သူ့မိဘများမဆုံးမ၊ ထားသဖြင့် အလွန်ရိုင်းပျသည်။”/ ‘ဒလဵု/ဒလဵုခၞံၚ်/ဒလဵုထဏံၚ်’ ဟုလည်းရေးသည်။/ ‘ပဒလဵု’ (ကြိ) လည်း ရှု။
,ဓဝါ (န) အလှည့်။/ ဒးဓဝါ = အလှည့်ကျသည်။
,ဓဝိၚ် (န) ပူပင်သောက။/ ‘ဒဝိၚ်’ ရှု။
,ဓဝါန် (န) အုံဆေး။ ကျပ်စည်းရန်ဆေး။
,ဓဝဲါ (န) ထားဝယ်မြို့။/ ဂကူဓဝဲါ = ထားဝယ်လူမျိုး။
,ဓဝုဲ (ကြိ) လွှဲသည်။/ ဓဝုဲခရေၚ် = ပုခက်လွှဲသည်။
,ဓအူ (န) လဲလူရွက်ပင်။
,ဓာတုစေတဳ (ပါ) (န) ဓါတ်တော်ကိုဋ္ဌာပနာ၍ တည်သောစေတီ။ ဓာတုစေတီ။
,ဓာတုဗေဒ (ပါ) (န) ဒြပ်စင်တို့တည်ရှိပုံ၊ ပြုမူလှုပ်ရှားပုံတို့ကို လေ့လာသောသိပ္ပံပညာရပ်။ ဓာတုဗေဒ။
,ဓိကဵု (န) မေးခွန်း။ အခက်အခဲ။ ပြဿနာ။
,ဓိတာန် (န) အင်ကြင်းပင်။ (ဆအလတြရေေ) “ပ္ဍဲတၞံဓိတာန်မွဲ မဍိုက်ပေၚ်သီုပ္ကဴမရာၚ်ဆာဲတဴဂှ် ဂစေံကွဴမွဲ ဍုန်ဒၟံၚ်တုဲ။” (ဇ—၂၆၉။ အစွောံ။) = “ကောင်းစွာပွင့်သော တခုသောအင်ကြင်းပင်­နားလျက် တခုသောဥသြသည်—။” (ညောင်ကန်) “ပ္ဍဲကာလဂှ် ဗောဓိသတ်ပိုဲ ဒှ်ဒေဝတဴ ပ္ဍဲဂြိုပ်ဟေမဝန်ကီု ဒှ်ဒေဝတဴဆုဓိတာန်။” (ဇ—၇၄။ အစွောံ။) = “ထိုအခါ ဘုရားလောင်းသည် ဟိမဝန္တာအရပ်­ တခုသောအင်ကြင်းတော­ ရုက္ခဇိုဝ်းနတ်၏အဖြစ်ဖြင့်ဖြစ်၏။” (ညောင်ကန်) “ဗောဓိ သတ်ပိုဲရသိ ဂ္ဇံဒၟံၚ်အသၟဝ်တၞံဓိတာန်ဂှ်—။” (ဇ—၃၁၃။ အစွောံ။) = “ဘုရားလောင်းသည် ထိုဥယျာဉ်­ ကောင်းစွာပွင့်သော အင်ကြင်းပင်ရင်း­ (ထိုင်နေ၏။) (ညောင်ကန်) (မှတ်ချက်။ ‘ဓိတာန်’ သည် ‘အင်ကြင်းပင်’ သာဖြစ်သည်။ ‘ကက္ကိုပင်’ မဟုတ်ပါ။ ‘ကက္ကိုပင်’ ကို ‘တၞံသြိုဟ်’ ဟုခေါ်သည်။)
,ဓိဝါန် (န) တော။
,ဓိဝိုဟ် (န) ဂမုန်းတစ်မျိုး။
,ဓုတၚ် (ပါသက်) (န) ဓူတင်။ (ကိလေသာကို ပယ်ခွါနိုင်သောအကျင့် = ဒ္ဂေတ်မကလှ်လဖှ်ကၠေံကိလေသ) (ပါဠိ—ဓုတၚ်္ဂ)
,ဓဴလဳ (ပါသက်) (န) မြူ။ မြူမှုန့်။ ဖုန်။ (ပါဠိ—ဓူလဳ)
,ဓုၚ် (န) ရေမြေလယ်ယာစောင့်နတ်။
,ဓံၚ်သဳ၊ ဓံသဳ (ပါသက်) (ကြိ) ပျက်စီးသည်။
,ဓိုၚ် (ကြိ) လွှင့်ထူသည်။ ထောင်သည်။/ ဓိုၚ်ယာ = ရွက်လွှင့်ထူသည်။/ ဓိုၚ်ကၞဴ = ခြင်ထောင် ထောင်သည်။
,ဓတ် (န) အင်အား။/ ဓတ်ချေံမသုန် = မြင်းငါးကောင်အား။
,ဓါတ် (ပါသက်) (န) ၁။ (ဘုရား၊ ရဟန္တာစသည်၏) ဓါတ်တော်။/ ဓါတ်ကျာ် = ဘုရားဓါတ်တော်။/ ၂။ ဓါတ်။ ဓါတ်ကြီးလေးပါးကို မျှတစေသောအစာ။/ ဗ္စဓါတ် = ဓါတ်စာကျွေးသည်။
,ဓါတ်ကၞုက်ကၞာဲ (ကြိ) (ခန္ဓအတွင်း­) ဓါတ်ချောက်ချားသည်။
,ဓါတ်စလိုက်စလာဲ (ကြိ) ‘ဓါတ်ကၞုက်ကၞာဲ’ နှင့် အဓိပ္ပါယ်အတူတူ။
,ဓါတ်ပန် (ကြိ) ဓါတ်ကြီးလေးပါး။/ “ပထဝ (ဓါတ်တိ)၊  အာပေ (ဓါတ်ဍာ်)၊  ဝါယေ (ဓါတ်ကျာ) မွဲ၊  တေဇေ (ဓါတ်ပၟတ်) ွဲ ဣဝွံဓါတ်ပန်ရ။” = “ပထဝ (မြေဓါတ်) အာပေ (ရေဓါတ်) ဝါယော (လေဓါတ်) တေဇေ (မီးဓါတ်) ည်းဟူသော ဓါတ်ကြီးလေးပါး။”
,ဓါတ်သော် (န) (မြတ်စွာဘုရား) ံတော်။/ ဓါတ်သော်ဂမျိုၚ် = ဆံတော်ရှင်။
,ဓိုတ် (ကြိ) (ဓါးစသည်) တုံးသည်။/ “မြဏအ်ဓိုတ်အာရ။” = “ဤဓါးတုံးသွားပြီ။”
,ဓါပ် (န) ဗုံရှည်။ အိုးစည်။ ဒိုးပတ်။
,ဓုပ် (န) ၁။ ကန်တော့ပွဲ။/ ၂။ (အနာကျပ်ထုပ်ထိုးရန်) ကျပ်ထုပ်။/ (စည်း) အထုပ်။/ ပၞာၚ်မွဲဓုပ် = ဖရောင်းတိုင်တစ်ထုပ်။/ ဓုပ်သ္ဍဴ = ဖရောင်းတိုင်ထုပ်။
,ဓုပ်ပြကာ (ပါသက်) (န) ၁။ ပြာသာဒ်အထွတ်။ ထုပိကာ။ (ပါဠိ—ထူပိကာ) ၂။ (ဥပစာ) အထွတ်အမြတ်။ အထွတ်အထိပ်။
,ဓမ္မ (ပါ) (န) ၁။ ဟုတ်မှန်သောတရား။/ ၂။၊ တရားဓမ္မ။ ဗုဒ္ဓ၏တရားတော်။
,ဓမ္မကထိုက် (ပါသက်) (န) တရားဟောပုဂ္ဂိုလ်။ ဓမ္မကထိက။/ “လကုဏ္ဍကဘဒ္ဒိယထေမ္ဂးဂှ် — မဒှ်ဓမ္မကထိုက်ရောၚ်။ နွံတဝှ်ဓဝ်မမိပ်ရောၚ်။” (ဇ—၂ဝ၂။ အစွောံ။) = “ လကုဏ္ဍကဘဒ္ဒိယမ ထေရ်သည် ဓမ္မကထိကဖြစ်၏။ သာယာစွာသောအသံဖြင့် တရားဟောတတ်၏။”
,ဓမ္မကရိုန်၊ ဓမ္မကရိုုဏ် (ပါသက်) (န) ရေစစ်။ ဓမ္မကရိုဏ်။ (ပါဠိ—ဓမ္မကရဏ)
,ဓမ္မခန် (ပါသက်) (န) ဓမ္မခန်။ ဓမ္မက္ခန္ဓာ။ (မြတ်စွာဘုရား ဟောတော်မူအပ်သော တရားအစုအပေါင်း။) ‘ဓမ္မက္ခန်’ နှင့်အတူတူ။
,ဓမ္မစေတဳ (ပါ) (န) ၁။ ပိဋကတ်တော်လာ တရားတော်တို့ကို ဋ္ဌာပနာထားရာစေတီ။/ ၂။ ပိဋကတ်ကျမ်းဂန်များ။
,ဓမ္မစက် (ပါသက်) (န) ၁။ ဓမ္မစကြာတရားတော်။/ ၂။ တရားတော်၏ တန်ခိုးအရှိန်အစော်။
,ဓမ္မတာ (ပါ) (န) ဓမ္မတာ။ အလေ့သဘော။ အမြဲဖြစ်သောသဘော။ ဇာတိသဘော။/ “ဒၞာဲညးမ ကၠောန်လဝ် ဍေံပလီုကၠေံရောၚ်။ ဣဝွံဓမ္မတာကၞုဲတံရ။” (ဇ—၂၅၇။ အစွောံ။) “သူတစ်ပါးပြု လုပ်ထားသည်ကို ဖျက်ဆီးပစ်ခြင်းသည် မျောက်တို့၏ဇာတိသဘောဖြစ်၏။”/ “ပွမဂ္ၚေၚ်သာ်ဝွံ မဒှ်ဓမ္မတာကလော်ဗြဴတံဂှ်ရ။” (ဇ—၁၉၆။ အစွောံ။) = “ဤသို့လှည့်လည်ခြင်းသည် ထိုဘီလူးမ တို့၏ အလေ့သဘောတည်း။”/ “မၞးမဒှ်ဗြဴမဂွတုဲမဟွံဂံၚ်အာတ်ဂှ် မဒှ်ဓမ္မတာဗြဴတံရ။” (ဇ—၅၃၅။ အစွောံ) = “သင်သည် မိန်းမသားဖြစ်၍ ရှက်သဖြင့် မတောင်းဝံ့ခြင်းသည် မိန်းမတို့၏ဓမ္မတာ ပင်တည်း။”
,ဓမ္မဒါန (ပါ) (န) တရားအလှူ။ ဓမ္မဒါန။
,ဓမ္မဒူတ၊ ဓမ္မဒုတ် (ပါ/ပါသက်) (န) ဓမ္မဒူတ။ တရားတမန်။ သာသနာပြုပုဂ္ဂိုလ်။
,ဓမ္မဒေသနာ (ပါ) (န) တရားဓမ္မဟောခြင်း။ ဟောပြောသောတရား။ ဓမ္မဒေသနာ။
,ဓမ္မဓိဋ္ဌာန် (ပါသက်) (န) ပုဂ္ဂိုလ်ကိုမရည်စူးဘဲ တရားသဘောကို ရည်စူးခြင်း။/ ‘ပုဂ္ဂလဓိဋ္ဌာန်’ လည်းရှု။
,ဓမ္မဘဏ္ဍာဂါရိက (ပါ) (န) (ဂေါတမမြတ်စွာဘုရား၏) တရားဘဏ္ဍာစိုး။ (ရှင်အာနန္ဒာ။)
,ဓမ္မရာဇာ (ပါ) (န) ၁။ တရားမင်း။ မြတ်စွာဘုရား။/ ၂။ တရားနှင့်အညီ အုပ်စိုးသောဘုရင်။
,ဓမ္မရတ် (ပါသက်) (န) တရားရတနာ။
,ဓမ္မဝါဒဳ (ပါ) (န) ဖြောင့်မှန်သော အယူဝါဒရှိသူ။ ဓမ္မဝါဒီ။
,ဓမ္မဝတ် (ပါသက်) (န) တရားလမ်းကြောင်းကျင့်ဝတ်။ ဓမ္မဝတ်။
,ဓမ္မသေနာပတိ (ပါ) (န) တရားစစ်သူကြီး။ ဓမ္မသေနာပတိ။ (ရှင်သာရိပုတ္တရာ) ‘သကိုပ်ပၞာန် ဓဝ်’၊ ‘ဒကိုပ်ပၞာန်ဓဝ်’ နှင့်အဓိပ္ပါယ်အတူတူ။
,ဓမ္မသာတ် (ပါသက်) (န) တရားဥပဒေဆိုင်ရာကျမ်း။ ဓမ္မသတ်။/ ‘ဓမ္မသာတ်ဝါရေဝ်ရောဝ်’ = ‘ဝါရီရူဓမ္မသတ်’၊ ဓမ္မသာတ်မနုရသိ = မနုဓမ္မသတ်။ (မဟာသမ္မတမင်းလက်ထက်က အသုံးပြုသော မနုရသေ့စီရင်သည့်ဓမ္မသတ်။)
,ဓမ္မာစရိယ (ပါ) (န) ၁။ ပါဠိ၊ အဋ္ဌကထာစသည်ကို သင်ကြားပို့ချရေသာဆရာ။/ ၂။ စာချတန်း စာမေးပွဲအောင်မြင်သူ။
,ဓမ္မာရီု (ပါသက်) (န) တရားအာရုံ။ ဓမ္မာရုံ။
,ဓမ္မိယလဒ္ဓ (ပါ) (န) တရားသဖြင့် ရှာဖွေရရှိသောပစ္စည်း။ ဓမ္မိယလဒ္ဓ။
,ဓမ္မက္ခန် (ပါသက်) (န) မြတ်စွာဘုရားဟောတော်မူအပ်သော တရားအစုအပေါင်း။ ဓမ္မက္ခန္ဓာ။
,ဓမြိၚ်ကမြဴ (ကြိ) (ကျယ်လောင်သော) သံပြုသည်။ မြည်ဟည်းသည်။
,ဓမြိုတ်၊ ဓရိုတ် (န) ကြေးဝါ။
,ဓမြိပ်၊ ဒမြိပ် (န) မျက်စိတစ်မှိတ်။
,ဓမၠ (န) ဓါးပြ။/ ‘ဓမၠမွဲဂှ် ညးရပ်ဂွံတုဲ—။’ (ဇ—၁၉၃။ အစွောံ။) = ‘ဓါးပြတစ်ယောက်ကို လူများ ဖမ်းမိ၍—။’/ ‘ဒမၠ’ ရှု။
,ဓီု (ကြိ) ၁။ အုပ်ဆိုင်းသည်။ ညို့မှိုင်းသည်။/ တ္ၚဲဓီု = နေရောၚ်မှိန်သည်။/ ၂။ ဉာဏ်ထိုင်းသည်။ နုံ့သည်။ ပညာနုံ့သည်။
,ဓီုဓုဲ၊ ဓုဲဓီု (ကြိ) ထုံထိုင်းသည်။ မိုက်မဲသည်။ လိမ္မာပါးနပ်ခြင်းမရှိဖြစ်သည်။
,ဓီုၜီု (ကြိ) ထုံထိုင်းသည်။ ညာဏ်ထိုင်းသည်။
,ဓဝ်၊ ဓရ် (သသက်) (န) ၁။ တရား။/ ဓဝ်မေတ္တာ = မေတ္တာတရား။/ ဓဝ်သဳလ = သီလတရား။/ ဓဝ်လောဘ = လောဘတရား။/ ၂။ အမှု။/ ဓဝ်တလန် = လှည့်စားမှု။/ ဓဝ်ပ္တေဟ် = ယုံကြည်မှု။ ယုံကြည်ချက်။/ ဓဝ်မေထုန် = မေထုန်အမှု။
,ဓဝ် (ကြိ) ၁။ ဖြောင့်မှန်သည်။ ဟုတ်မှန်သည်။ မလိမ်လည်။/ “ပဟိုတ်ကဵုခမဳမွဲ ဟီုဟွံဓဝ်ဂှ်ရ ဘိမ္ဗသေဏဇာတ် ကျာ်တြဲတွံရ။” (ဇ—၈ဝ။ အစွောံ။) = “မဟုတ်မမှန်ပြောဆိုသော ရဟန်း တစ်ပါးကို အကြောင်းပြု၍ ဘီမသေနဇာတ်ကို မြတ်စွာဘုရားဟောတော်မူ၏။”/ “ဟီုကဵုဓဝ်၊ ယာံဟီုဟွံဓဝ်တုဲ ဗှ်ေသ္ဒးအိုတ်လမျီုရ။” (ဇ—၄ဝ၂။ အစွောံ။) = “မှန်မှန်ပြော၊ မှန်မှန်မပြောပါက သင်အသက်ကုန်ရလိမ့်မည်။”/ ၂။ (စကား) ရှေ့နောက်ညီသည်။/ “ပါၚ်တလအဲဟွံဓဝ်သွံ။” (ဇ—၈ဝ။ အစွောံ။) = “သင့်နှုတ်သည် (သင့်စကားသည်) ရှေ့နောက်မညီပါလား။”/ ၃။ ပုံမှန် ပကတိဖြစ်သည်။ အချိန်အခါမှန်သည်။/ “ယြဴသၟိၚ်မွဲ ဗွဲစၟတ်ဂှ်ဟီုတုဲ ဗြဲဂူဓဝ်လောန်သန်ရ။ သၟိၚ် ဟီုမုသာတုဲ ဗြဲဂူဟွံဓဝ်ရ။” (ဇ—၄၂၂။ အစွောံ။) = “အကြင်မင်းသည် မှန်သောစကားကိုဆိုလျှင် ပုံမှန်ပကတိမိုးရွာ၏။ မင်းသည် မုသားကိုဆိုသည်ရှိသော် မိုးရွာမမှန်တော့။”/ ၄။ တည့်သည်။ တည့်မတ်သည်။ မတိမ်းစောင်း။/ “သၠဒကေဝ်ဂှ် တဴဓဝ်ဒၟံၚ်အကြာဝတ္ထုၜါဂှ်ရ။” = “ထို ချိန်ခွင်သည် ထိုဝတ္ထုနှစ်ခုအကြား­ တည့်မတ်စွာတည်နေသည်။”
,ဓဝ်ကဵု (ဝိ) မျက်နှာချင်းဆိုင်၊ တည့်တည့်၊/ “သ္ၚိညးနွံဓဝ်ကဵုသ္ၚိပိုဲရ။” = “သူ၏အိမ်သည် ကျွန်တော်တို့အိမ်နှင့် မျက်နှာချင်းဆိုင်တွင်ရှိသည်။”
,ဓဝ်စိုတ် (န) စိတ်အလို။ နှလုံးအလို။/ (သေဋ္ဌဳ) ၟိက်ပလီုကၠေံ ဓဝ်စိုတ်လဗၚ်တံတုဲ ဂလာန်ဝွံမ္ဂး။” (ဇ—၅၃။ အစွောံ။) = (သူဌေးသည်) ထိုသေသောက်ကြူးတို့၏ နှလုံးအလိုကို ဖျက်ဆီးလိုသည်ဖြစ်၍ (ဤစကားကိုဆို၏။) (ညောင်ကန်)
,ဓဝ်ဓဝ် (ကြိဝိ) ၁။ တည့်တည့်။/ ‘အာဓဝ်ဓဝ်ညိ။’ = ‘တည့်တည့်သွားပါ။’/ ၂။ မှန်မှန်။ အမှန်အတိုင်း။ မလိမ်မညာ။/ “မဟီုကဵုအဲဓဝ်ဓဝ်ညိ။” (ဇ—၅၃၁။ အစွောံ။) = “ငါ့ကို သင်မှန်မှန်ပြောပါ။”
,ဓဝ်မိတ် (န) အဆွေခင်ပွန်းတရား။ အဆွေခင်ပွန်းတို့ ကျင့်ရာသောတရား။/ “အသပ္ပရိုဟ်ဟွံတီဂုန် ညးမဒြိုဟ်ကဵုမိတ်ဝွံ ပလီုဓဝ်မိတ်တုဲရ။” (ဇ—၁၃၁။ အစွောံ။) = “ကျေးဇူးမသိသော မသူတော်သည် အဆွေခင်ပွန်းကိုပြစ်မှား၍ အဆွေခင်ပွန်းတရားကို ဖျက်ဆီးခဲ့ပြီ။”
,ဓဝ်ယာ (ကြိ) မှန်သည်၊ ပုံမှန်ဖြစ်သည်။ ပကတိအတိုင်းဖြစ်သည်။/ “သၞာံဏအ် ကျာဗြဲဓဝ်ယာဒၟံၚ်ရ။” = “ဤနှစ်မိုးလေမှန်သည်။”/ “ဟိုတ်နူညးဂမၠိုၚ် မဟွံဂွံတန်တဴပ္ဍဲဓဝ်တုဲဂှ် ကျာဝိတ္ထဳပိုက်ဟွံဓဝ်ယာ ဗြဲလေဝ်ဂူဟွံဓဝ်ယာကီုရ။” (အဓါန်မသုန်/အစွောံ) = “လူအပေါင်းတို့ တရား­မတည် သောကြောင့် လေတိုက်ရာလမ်းကြောင်းသည်မမှန်၊ မိုးရွာလည်းမမှန်တော့။”
,ဓဝ်သၚ်္ဂဟ (န) သင်္ဂဟတရား။ စည်းရုံးသိမ်းသွင်းကြောင်းတရား။ (၁၊ ဒါန — ပေးကမ်းခြင်း။ ၂၊ ပီယဝါစာ — ချစ်ဖွယ်စကားဆိုခြင်း။ ၃၊ အတ္ထစရိယ — အကျိုးဆောင်ခြင်း။ ၄၊ သမာ နတ္တတာ — မိမိနှင့် တန်းတူဆက်ဆံခြင်းဟူ၍ လေးပါးရှိသည်။)
,ဓဝ်သစ္စပန်ပြကာ (န) သစ္စာလေးပါး။ မြတ်စွာဘုရားဟောကြားသည့် မှန်ကန်သောတရားလေးပါး။ (၁၊ ဒုက္ခသစ္စာ — ဆင်းရဲအမှန်။ ၂၊ သမုဒယသစ္စာ — ဆင်းရဲကြောင်းအမှန်။ ၃၊ နိရောဓ သစ္စာ — ဆင်းရဲငြိမ်းရာအမှန်။ ၄၊ မဂ္ဂသစ္စာ — ဆင်းရဲငြိမ်းကြောင်းအမှန်။)
,ဓဝ်သၟိၚ် (န) နိုင်ငံကိုအုပ်စိုးသောမင်းတို့ ဖြည့်ကျင့်အပ်သည့်ကျင့်ဝတ်။ မင်းကျင့်တရား။/ ဓဝ်သၟိၚ်စှ် ပြကာ = မင်းကျင့်တရားဆယ်ပါး။ ၁။ ဒါန = ပွမပ္တုဲဒါန် (အလှူပေးခြင်း) ၂။ သီလ = ပွမ ဒဂိုန်သဳမသုန်မဗိုန် (သီလဆောက်တည်ခြင်း) ၃။ ပရိစ္စာဂ = ပွမသၠးဒြပ်ကဵုဒါန် (ပေးကမ်းစွန့် ကြဲခြင်း) ၄။ အဇ္ဇဝ = မၞုံကဵုစိုတ်တမ္ၚူ (ဖြောင့်မတ်မှန်ကန်စွာကျင့်ခြင်း) ၅။ မဒ္ဒဝ = မၞုံကဵု စိုတ်မဍိုန်ဍောတ်ပ္ဍဲသတ် (ကိုယ်နှုတ်နှလုံး နူးညံ့သိမ်မွေ့ခြင်း) ၆။ တပ = မဟွံဂွံကတဴသတ်? (ဥပုသ်ဆောက်တည်ခြင်း) ၇။ အက္ကောဓ = မဟွံဂွံဇၞော်ပၞတ် (အမျက်မထွက်ခြင်း) ၈။ အဝိၚ်္ဟံသာ = မဟွံဂွံပရိုက်ပျဲပျာံညး (မညှဉ်းဆဲခြင်း) ၉။ ခန္တီ = မအေၚ်ဒုၚ်လဟီုပြဝညး (သည်းခံခြင်း) ၁ဝ။ အဝိရောဓန = မဟွံဂွံထောံတၞောဝ်ဒ္ဂေတ်တၠပညာတမၠာတမၠာတေံ (မဆန့်ကျင်ခြင်း)
