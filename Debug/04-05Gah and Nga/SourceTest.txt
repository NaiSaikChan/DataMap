ဃ (န) စတုတ္ထမွန်ဗျည်း။
,ဃဏိၚ် (န) ခေါင်းလောင်း။/ ‘ခဏိၚ်/ခၞိၚ်’ နှင့်အတူတူ။ (ပါဠိ—ဃဏ္ဍ)
,ဃမုဲ (န) စုန်း။/ ‘ဗမုဲ’/‘ဂမုဲ’ ရှု။
,ဃရ (န) အၚ်တုံ။
,ဃရာဝါသ (ပါ) (န) အိမ်ထောင်ပြုခြင်း။ ဃရာဝါသ။
,ဃရေက် (ကြိ) ‘ဂရေက်’ ရှု။
,ဃရေက်ဂဗေက် (ကြိ) ‘ဂရေက်ဂဗေက်’ ရှု။
,ဃရံက် (န) သုံးမြှောက်မြက်။
,ဃိ (ကြိ) (ဘန်း) (ဝတ်စားဆင်ယင်မှု) ခေတ်မဆန်ဖြစ်သည်။ ခေတ်နောက်ကျသည်။
,ဃော (သဗဓ) စဉ်။ အတောအတွင်း။/ “ဃောဗြဲဂူ ဒုၚ်ဍာ်” = “မိုးရွာတုန်း ရေခံ။”/ (စည်း) ပြုလုပ်နေစဉ်ကို ပြသောစကားလုံး။/ “ဃောကွာ်ကၠုၚ် ဆဵုဒးဇြုံရ။” = “လျှောက်လာစဉ် မြွေကိုတွေ့မိသည်။”/ ‘အဃော’ ရှု။
,ဃောသ (ပါ) (န) အသံပြင်းသောအက္ခရာ။ ဃောသအက္ခရာ။
,ဃံက် (န) အကောက်။/ ဃံက်တဲ = လက်ကောက်ဝတ်။/ (ကြိ) ခေါက်သည်။/ ဃံက်က္ဍိုပ် = ခေါင်းခေါက်သည်။
,ဃံၚ် (န) အကြီးအကဲ။ ရွာသူကြီး။
,ဃိုၚ် (ကြိ) ချီသည်။ သုတ်ချီသည်။/ “ခဍာ်မွဲ ဃိုၚ်ဏာကရ။” = “ကျီးကန်းတစ်ကောင် ငါးကို ချီသွားသည်။”/ ‘ဂိုၚ်’ ရှု။
,ဃိတ် (ယိုး) (ကြိ) စဉ်းစားသည်။ တွေးတောသည်။
,ဃိုတ် (ကြိ) တုံးသည်။/ “ၜုန်ဏအ်ဃိုတ်အာရ” = “ဤဓါးတုံးသွားပြီ။”
,ဃဵု (ကြိ) အလျင်စလိုလျှောက်သည်။/ “ယွံအမူ၊ ဃဵုအာအလဵုရော။” = “ဦးလေး၊ ဘယ်ကို အ လျင်စလိုလျှောက်သွားသနည်း။”/ “စိၚ်ဒြၚ်ဂှ် ဍေံညာတ်မၚ်ဗၠာဲဗက် ဍေံဃဵုကၠုၚ် ညံၚ်ပဝန်ကံရ။” (ဇ—၃၇၄။ အစွောံ။) = “ထိုဆင်ပြောင်သည် လုလင်ကိုမြင်သည်နှင့် ပစ်လွှတ်သောမြှား၏အမြန် နှုန်းကဲ့သို့ လျင်မြန်စွာလာ၏။”
,ၚ—၁ (န) ပဥ္စမမွန်ဗျည်း။
,ၚ—၂ (န) လယ်တော။/ ‘ဗ္ၚ’ ရှု။
,ၚဳ (ကြိ) ရှာသည်။/ ၚဳစဲ = သန်းရှာသည်။/ ၚဳအှ်ော = ထင်းခွေသည်၊ ထင်းရှာသည်။/ ‘သ္ၚဳ’/ ‘သ္ၚေဝ်’ လည်းရှု။
,ၚဳဂၠိပ်၊ ၚဳဂၠိတ် (ကြိ) ‘သ္ၚဳဂၠိပ်’/‘သ္ၚဳဂၠိတ်’ ရှု။ 
,ၚဳမုက် (ကြိ) ‘သ္ၚဳမုက်’ ရှု။
,ၚု (န) ရှိန်းခို။ (ဆေးဖက်ဝင်) (ပါဠိ—ဇတုက)/ တၞံၚု = ရှိန်းခိုပင်။
,ၚဴ (န) ဖား။/ ၚဴဂနေအ် = ဖားဂုံညင်း။/ ၚဴၝောအ် = စားဖား။/ ၚဴပဏီ၊ ၚဴဂၜိုပ် = ဖားပြုပ်/ ၚဴသၠ၊ ၚဴသၠလမ္စံက် = ဖားညို။/ “ဗောဓိသတ်ပိုဲ ဒှ်ၚဴသၠ—။” (ဇ—၂၃၉။ အစွောံ။) = “ဘုရားလောင်းသည် ဘားညိုအမျိုး­ဖြစ်၏။” (ညောင်ကန်)
,ၚး (န) စားကြွင်း၊ အကြွင်းအကျန်။/ ပုၚ်ၚး = စားကြွင်းထမင်း။/ စၚးညး = သူတစ်ပါး၏ စား ကြွင်းစားကျန်ကို စားသည်။/ “ပုၚ်ၚးစဏာမယုတ်တဴဂှ် အဲစရောၚ်သွံ။” (ဇ—၁၇၉။ အစွောံ။) = “ယုတ်ညံ့သောဒွန်းစဏ္ဍား၏ စားကြွင်းထမင်းကို ငါစားမိသည်တကား။”/ ‘ဒေန်သၞာတၟိ မဟွံ ဒှ်ၚးညး’ = ‘သူတစ်ပါးတို့ မသုံးဆောင်ရသေးသော ညောင်စောင်းအသစ်။’/ “ပဟိုတ်ကဵုညးမ သုန်ကၠံမစၚးညးဂှ်တုဲ ဝါလောဒကဇာတ် ကျာ်တြဲတွံ။” (ဇ—၁၈၃။ အစွောံ။) = “ဤဝါလောဒ ကဇာတ်ကို — ငါးရာကုန်သော စားကြွင်းစားတို့ကို အကြောင်းပြု၍ ဟောတော်မူ၏။”(ညောင်ကန်)/ (ကြိ) သုတ်သင်သည်။ ရှင်းလင်းသည်။/ “အုပ်ရာပ်မပေၚ်ကြာန်ဒၟံၚ်ဂှ် ၚးထောံညိ။” = “ချုံနွယ်ပိတ်ပေါင်းများ ပြည့်ယှက်နေသည်ကို ခုတ်ထွၚ်ရှင်းလင်းလိုက်ပါ။”
,ၚးတး၊ တးၚး (ကြိ) သုတ်သင်သည်။ ရှင်းလင်းသည်။/ “ဒးလဗိုတ်ကျာတုဲ ကၞာၚ်ဆုသၠဆု ပြဟ် စှ်ေပြးဇးဒၟံၚ်ဂၠိုၚ်သန် ပၟၚ်ဥဒျာန်တအ် အုဲၚးတးဟွံမာန်ဟေၚ်။” = “မုန်တိုင်းသင့်၍ သစ်ကိုင်းသစ် ရွက်များ များစွာကျိုးကျပြန့်ကြဲနေ၏။ ဥယျာဉ်စောင့်တို့သည် သုတ်သင်ရှင်းလင်းအံ့သောငှာ မ တတ်နိုင်။”/ “မၚ်ဗၠာဲဒိုက်ဂတ်ဂှ် (တၞဟ်နပူဇဴဒေဝတဴတုဲ) ဆုသ္အာၚ်ကေတ်ဟွံဂွံတုဲ ဆုတောင်မွဲတၞံဂှ် မၚ်ဗၠာဲတးၚးကၠောန်ၜိုတ်ရ။” (ဇ—၁ဝ၉။ အစွောံ။) = “ထိုသူဆင်းရဲလုလင်သည် နတ်ပူဇော်ရန် အလို့ငှာ အခြားသစ်ပင်ကိုမရ၍ တစ်ခုသောကြက်ဆူပင်ကို သုတ်သင်ရှင်းလင်း၏။”
,ၚာ်တြုံ (န) ယောကျာ်းလေး။
,ၚာ်ဗြဴ (န) မိန်ကလေးငယ်။
,ၚုက် (ကြိ) (တစ်ချောင်းတည်းသောလက်သည်းဖြင့်) ကုတ်နှိပ်သည်။/ “ဒၞာဲဂၟိတ်ကိတ်လဝ်ဂှ် ၚုက် ကဵုသၞေမ်တဲ။” = “ခြၚ်ကိုက်ထားသောနေရာကို လက်သည်းဖြင့် ကုတ်နှိပ်သည်။” 
,ေၚက် (န) ၁။ သွား။/ၚေက်ဍာ်တှ် = နို့သွား။/ၚေက်တိုန် = သွားတက်သည်။ သွားပေါက်သည်။/ ၂။ အသွား။/ၚေက်ဂရး၊ၚေက်ထဲ = ထွန်သွား။/ၚေက်တုတ် = ယက်ကန်းယဉ်သွား။/ၚေက်ဂတေက် = လွှသွား။
,ငံက် (ကြိ) (မဖြောင့်)ကောက်သည်။/ ‘တ္ၚံက်’ ရှု။ 
,ငံက်ေၚဲ၊ ငံက်ၚာ် (ကြိ) ကောက်ကွေးသည်။/ ‘တ္ၚံက်တ္ၚေဲ’ ရှု။
,ငိုက် (ကြိ) အတတဖြစ်သည်။/ “မၞိဟ်ဏအ်ငိုက်ကွေံကွေံရ။” = “ဤလူတော်တော်အ တဲ့သူပဲ။”
,ၚၚ် (ကြိ) အံ့အားသင့်သည်။ ကြောင်သွားသည်။
,ၚာၚ် (န) (ဂဏန်း၊ ပုစွန်၊ ကင်းမြီးကောက်စသည်၏) လက်မ။/ ၚာၚ်ဂတာံ = ဂဏန်းလက်မ။/ ၚာၚ်ၚုဲ = ပုစွန်လက်မ။/ ၚာၚ်အယဴ = ကင်းမြီးကောက်လက်မ။
,ၚာၚ်ၚုဲ (န) ဗီဇာတ်ပင်။
,ၚုၚ် (ကြိ) မှိုၚ်သည်။ 
,ၚုၚ်ၚ (ကြိ) တွေဝေမှိုၚ်ေၚးသည်။ မျက်နှာမသာမယာဖြစ်သည်။/ ၚုၚ်ၚဇြဟောံ = စိတ်မကြည်မ သာဖြစ်ပြီး မှိုၚ်ေၚးသည်။/ ‘လ္ၚုၚ်လ္ၚ’ နှင့်အတူတူ။
,ငတ်၊ ၚောတ် (ကြိ) အစာကြေသည်။/ “စၞမဂၠိုၚ် လောန် ကောန်စိၚ်ဂှ်ဂိုၚ်စတုဲ ပ္ၚတ်အဟာဟွံငတ်တုဲ ကောန်စိၚ်ဂှ်က္တဵုဒှ်ယဲ။” (ဇ—၄၁ဝ။ အစွောံ။) = “ထိုဆင်ငယ်သည် များစွာသောအစာကိုစား၍ အစာကြေအောင်မခြေနိုင်သဖြင့် ဖျားနာသွား ၏။”/ “ယွံသဟာဲ (ဖရာပ်)၊ ဂၞဴအဲပငတ်အဟာရဟွံငတ်တုဲ ဂၞဴအဲဂိ အဲအာဟွံမာန် တလအဲမွဲအာရ” ခ္ဍာ်ဂး။ (ဇ—၃၇၅။ အစွောံ။) = “အဆွေခို၊ ငါ၏ဝမ်းသည် အစာကြေအောင်မခြေနိုင်သဖြင့် ငါသည်ဝမ်းနာ၏။ သင်တစ်ဦးတည်းသာ သွားလေလော့” ဟုကျီးဆို၏။/ ‘ပငတ်’ (ကြိ) လည်း ရှု။
,ၚိတ် (ကြိ) မျိုသည်။/ တိၚိတ် = မြေမျိုသည်။
,ၚိတ်ဍာ်ပါၚ် (ကြိ) တံတွေးမျိုသည်။ (စားချင်၍) သွားရည်ယိုသည်။/ “ညာတ်ညးစဂှ် ၚိတ်ဒၟံၚ်ဍာ် ပါၚ်ရ။” (ဇ—၅၃၅။ အစွောံ။) = “သူတစ်ပါးစားသည်ကိုမြင်၍ (စားချင်၍) တံတွေးမျိုနေရသည်။”
,ၚေတ် (ကြိ) ညစ်ပေသည်။ 
,ၚေတ်ပေတ် (ကြိ) ညစ်ပတ်ပေရေသည်။
,ၚောတ် (ကြိ) (အနာဒဏ်ရာစသည် ရောၚ်ရမ်းမှု) လျော့ကျသည်။/ ၚောတ်စှ်ေ = ဖူးရောင်ရာမှ လျော့ကျသည်။
,ၚာန် (န) ငန်း။ ငန်းဖမ်းရောဂါ။/ ဂဥုဲၚာန် = ငန်းဆေး။ 
,ၚာန်တိုန် (ကြိ) ငန်းဖမ်းသည်။ အဖျားတက်သည်။
,ၚာန်သနနိပါတ် — (န)သည်းခြေ၊ လေ၊ သလိပ် သုံးပါးဖောက်ပြန်၍ ဖြစ်သောငန်းဖျား။ ငန်းသနနိ ပါတ်။
,ၚေပ် (ကြိ) ညှပ်သည်။/ “လ္ၚပၟတ်ဂှ် ၚေပ်ကဵုသ္ကေပ်ပသဲညိ။” = “မီးခဲကို သံညှပ်နှင့်ညှပ်ပါ။”
,ၚာံ၊ ၚာမ် (ကြိ) ထောက်ကန်သည်။ ထောက်တွန်းသည်။ (ပါဠိ—ခမ္ဘတိ)/ ၚာံလဝ်သ္ၚိ = အိမ်ကို ထောက်ကန်ထားသည်။
,ၚာဲ (န) ပင်လယ်ကျောက်ပုစွန်။/ (ကြိဝိ) တဝဲလည်လည်။/ ကွာ်ၚာဲ = တဝဲလည်လည်လျှောက်သည်။ 
,ၚုဲ (န) ပုစွန်။/ ၚုဲဒဂေါၚ် = ပုစွန်ထုပ်။/ ၚုဲတံၚ်တေဲ = ပုစွန်ဆိတ်။
,ၚောဲ၊ ၚဲ (ကြိ) ဝေးသည်။/ “ကွာန်ဂေါစရဂှ် ဟွံၚောဲလောန် ဟွံဆိုက်လောန်။” (ဇ—၂၉၈။ အစွောံ။) = “ဆွမ်းခံရွာ မဝေးလွန်း မနီးလွန်းရှိ၏။”/ ‘သ္ၚောဲ’ ရှု။
,ေၚဝ်၊ ၚဳ (ကြိ) ကြည့်သည်။/ ‘သ္ၚေဝ်/သ္ၚဳ’ ရှု။
,ၚုဟ် (န) တန်ဖိုး၊ အဖိုးအခ။/ “ပလောအ်ဏအ် ဒးကဵုၚုဟ်မူစိရော။” = “ဤအင်းကျီ တန်ဖိုး ဘယ်လောက်ပေးရသလဲ။”/ (ကြိ) အိပ်ရာမှနိုးသည်။/ “ကောန်ၚာ်ၚုဟ်ရ။” = “ကလေးနိုး ပြီ။”
,ၚုဟ်က္တဵု (ကြိ) နိုးထသည်။ နိုးကြားထကြွသည်။
,ၚုဟ်က္ဍၚ် (ကြိ) ဈေးကြီးသည်။
,ၚုဟ်စှ်ေ (ကြိ) ဈေးကျသည်။
,ၚုဟ်ဍာ်တှ်မိ (ကြိ) နို့ဖိုး။ (ဥပစာ) မိခင်၏မွေးကျေးဇူး။
,ၚုဟ်တန် (ကြိ) ဈေးတော်သည်။ ဈေးချိုသည်။
,ၚုဟ်တိုန် (ကြိ) ဈေးတက်သည်။
,ၚုဟ်ဒး (ကြိ) ဈေးတော်သည်။ ဈေးပေါသည်။
,ၚုဟ်မး (န) တန်ဖိုး။/ ဟွံတီကဵုၚုဟ်မး = တန်ဖိုးမဖြတ်နိုင်သော။/ “ကၟိန်ဍုၚ်မ္ဂးဂှ် ဟွံတီကဵုၚုဟ် မးရောၚ်။” = “တိုင်းပြည်မည်သည်မှာ တန်ဖိုးမဖြတ်နိုင်ပါ။”
