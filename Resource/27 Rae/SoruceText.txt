ရ—၁ (န) နှစ်ဆယ့်ခုနစ်လုံးမြောက်မွန်ဗျည်း။
,ရ—၂ (စည်း) ၁။ (ကြိနောက်ဆက်) သည်။ ၏။/ အာရ = သွားသည်။/ “မံၚ်ပ္ဍဲသ္ၚိရ။” =“အိမ်မှာနေသည်။”/ ၂။ အဟုတ်ဝါကျ—မဟုတ်ဝါကျနောက်ဆုံးစကားလုံး။/ ညးကၠုၚ်ရ။ = သူလာသည်။/ ညးဟွံကၠုၚ်ရ။ = သူမလာပါ။/ ၃။ ညွှန်ကြားဝါကျနောက်ဆုံးစကားလုံး။/ အာညိရ။ = သွားပါတော့။/ ၄။ —မည်သည်၊ —သည်ရှိသော်ဟူသောအနက်ဖြင့် ကတ္တားနောက်­ ကပ်၍သုံးသောစကားလုံး။/ “ပၟတ်ရဂဵု ဍာ်မသိုဟ်ရ။” (ဇ—၁၃၃။ အစွောံ။) = “မီးလောင်ခြင်းမည်သည်ကို ရေဖြင့်ငြိမ်းစေကုန်၏။” (ညောင်ကန်)/ “အဲရဂွံအာကၠာမ္ဂး ဂၠံၚ်တြဴလေဝ် ဟွံဂတာပ်လီုဏီ။” (ဇ—၁။ အစွောံ။) = “ငါသည် ရှေ့မှသွားသည်ရှိသော် — မပျက်သည်သာလျှင်ဖြစ်သောခရီးဖြင့် သွားရအံ့။” (ညောင်ကန်)
,ရကိုဟ် (သသက်) (န) ဘီလူး။/ ‘လကိုဟ်’ နှင့်အတူတူ။
,ရခေၚ်၊ ယခေၚ် (န) ရခိုင်လူမျိုး။ ရခိုင်တိုင်းရင်းသား။/ “ယခေၚ်ဓဝဲါ၊ ဂၠိုၚ်ဒၞာဲဒေသ။ ဗိက်တၞၚ်သဳ၊ ဇဳရးသဗ္ဗ။” (လိက်သောဝိန်ဇဲယ။ မာံရောဂေါ။) = “ရခိုင်နှင့်ထားဝယ်တို့သည် မြိတ်နှင့်တနင်္သာရီတိုင်းအလုံး နေရာဒေသများစွာ­ရှိ၏။”
,ရစောန်ရဏောန် (ကြိ) သာယာစွာမြည်သည်။/ ‘လစောန်ရဏောန်’ ရှု။/ “ရစောန်ရဏောန်၊ညံၚ်ဗာတ်ကောန်စှ်။ ရိုဟ်ကျာပရှ်၊ ဗြုညံၚ်ညးက္ၜုၚ်။” (လိက်တပူတဗဝ်။ အစွောံ။) = “ကြေးနောင်ဆယ်လုံးရှိ လခြမ်းပတ်ဝိုင်းကို တီးခတ်သကဲ့သို့ လေတိုက်တိုင်း သာယာစွာမြည်၏။”/“ဂစေံတူဆု၊ ဗြုကၠံၚ်တမှဳ။ ရစောန်ရဏောန်၊ ဗြုဒေါန်သြဳသြဳ။” (လိက်မေဃကောန်ဒြာဲ) =“သစ်ပင်ထက်မှငှက်တို့သည် သာယာစွာမြည်ကြွေး၍ ညင်ညင်သာသာ ဆိုမြည်နေကြကုန်၏။”
,ရတု (သသက်) (န) နွေဦး၊ နွေနှောင်း၊ မိုးဦး၊ မိုးနှောင်း၊ ဆောင်းဦး၊ ဆောင်းနှောင်းတည်းဟူသော ရတုခြောက်ပါး။ ရတု။ ဥတု။
,ရတုထဝ် (န) နှစ် (၅ဝ) မြောက် နှစ်လည်အခါသမယ။ ရွှေရတု။ (golden jubilee)
,ရတုဗိုတ် (န) နှစ် (၆ဝ) မြောက် နှစ်လည်အခါသမယ။ စိန်ရတု။ (diamond jubilee)
,ရတုသြန် (န) (၂၅) နှစ်မြောက် နှစ်လည်အခါသမယ။ ငွေရတု။ (silver jubilee)
,ရနုက်၊ လနုက် (ကြိ) ချောင်ကျသည်။ အတွင်းဘက်ကျသည်။/ “ညံၚ်ရဴတၞံဆု၊ ကဵုသၠဆုကၠာ။ တဴဟွံလနုက်၊ ဒးမံၚ်မုက်ကျာ။” (လိက်ဝိဓူရ) = “အတွင်းဘက်မကျသော လေမျက်နှာစာသင့်နေသော သစ်ပင်သစ်ရွက်ကဲ့သို့။”
,ရနုက်ဗ္ဒန် (ကြိ) မြင်ကွင်းမှကွယ်သည်။ ဖုံးကွယ်သည်။ လျှို့ဝှက်သည်။/ ဋ္ဌာန်မရနုက်ဗ္ဒန် = လူမမြင်သောအရပ်။ လျှို့ဝှက်သောအရပ်။/ “(ကၠဵုဂြိုပ်စၞာဲဂှ်) အလာံမဒှ်သဘဴဓဝ်ဂှ် ယိုက်ပ္တဴလဝ်တုဲ နကဵုစိုတ်မရနုက်ဗ္ဒန်ဟေၚ် သရာံပါပ်မယုတ်မာဂှ် ဒ္ဂေတ်တဴရောၚ်။” (ဇ—၁၂၈။ အစွောံ။) = “စဉ်းလဲသောမြေခွေးသည် တရားတံခွန်ကိုပြု၍ စိတ်တွင်ဖုံးကွယ်လျှို့ဝှက်လျက် ယုတ်မာသောမကောင်းမှုကို ကျင့်၏။”
,ရနုက်ဗပေၚ်—၁ (န) ပြည့်စုံခြင်း။ နှစ်လိုဖွယ်ဖြင့်ပြည့်စုံခြင်း။/ “ပံက်ဏာကဇၞော် ဗလးကၠေံပ္ဍဲလစဇၞော်ဂှ်ရ။ ရနုက်ဗပေၚ်လ္စဂှ်သီုဖအိုတ် ထ္ၜးဗဗဵုကဂှ်တုဲ ဂိုၚ်ပလံၚ်နၚ်ကၠုၚ်ဗလး ပ္ဍဲဇရေၚ်ကဂမၠိုၚ်ပၠန်ရ။” (ဇ—၃၈။ အစွောံ။) = “ဗျိုင်းသည် ငါးကြီးကို ယူဆောင်သွားပြီး ရေအိုင်ကြီး­လွှတ်၏။ထိုငါးကြီးအား အလုံးစုံသော ထိုအိုင်ကြီး၏ပြည့်စုံခြင်းကို ပြသပြီးလျှင် ငါးများရှိရာဆီသို့ ပြန်လည်ယူဆောင်လာ၏။”/ “ရနုက်ဗပေၚ်သမ္ပတ္တိလစဒကှ်သွာဥပ္ပဵု မသက္ကုသၟိဟ် ကဇၞော်ဂှ် ထိုၚ်သးပၟိၚ်ကဂမၠိုၚ်ရ။” (ဇ—၃၈။ အစွောံ။) (ရနုက်ဗပေၚ် = သမ္ပတ္တိ) = “ထိုငါးကြီးသည် ကြာမျိုးစုံရှိသော ထိုအိုင်၏ပြည့်စုံခြင်းကို ငါးများအား အကုန်အစင် ချီးမွမ်းပြောပြ၏။”/ “ၚ်ဓဝ်သဳလ။ န်ပူဂဵုမသိပ်ဂၠိပ်။ (သဗ္ဗသမ္ပတ္တိံ) ၊ န်ရနုက်ဗပေၚ်ပိုန်ဟာန်အိုတ်သီု။ ပ္ဍံဏာဗစိုပ်ကဵုရ။” (ဓမ္မဒေသနာ။ မာံရွှေငိုး။) = “သီလတရားသည် ဖြည့်ကျင့်စောင့်စည်းသူအား အလုံးစုံသော စည်းစိမ်ဥစ္စာ၏ပြည့်စုံခြင်းကို ဆောင်ကြဉ်းပေး၏။”
,ရနုက်ဗပေၚ်—၂ (ကြိ) ဖြည့်ဆည်းသည်။ ဖြည့်ကျင့်သည်။/ “မှာသာရိပိုတ်တုန် နူဂယးဂှ် မရနုက်ဗပေၚ်တဴဝတ်ခမဳရ။” (ဇ—၃ဝ၁။ အစွောံ။) = “အရှင်သာရိပုတ္တရာသည် နံနက်­ ရဟန်းဝတ္တရားကို ဖြည့်ဆည်း၏။”/ “ယွံတၠအဲဣသိ၊ — အဲသၟိက်ရနုက်ဗပေၚ်ဒါန်တၠအဲတုဲ အဲကၠုၚ်ရောၚ်”ဣန်ဂး။ (ဇ—၄၈ဝ။ အစွောံ။) = “ရှင်ရသေ့၊ သင်၏အလှူဒါနကို ဖြည့်ဆည်းပေးလို၍ အကျွန်ုပ်လာခြင်းဖြစ်သည်” ဟုသိကြားမင်းဆို၏။/ “ဗွဲဒဒှ်ကတ်ဗတောန်ပြကိုဟ်ကၞပ်ဂှ်လေဝ် ဟွံဂွံရနုက်ဗပေၚ်—။” (ဇ—၁၄၆။ အစွောံ။) = “စာပေကျမ်းဂန်သင်ကြားခြင်းကိုလည်း မဖြည့်ကျင့်။”/“သ္ဂောံရနုက်ဗပေၚ်ကဵုစိုတ်သၟိၚ်မဇကုဂှ် အဲမကၠုၚ်ရ။” (ဇ—၅၁၃။ အစွောံ။) = “မိမိဖခမည်းတော်၏စိတ်ဆန္ဒကို ဖြည့်ဆည်းပေးရန်အလို့ငှာ ငါလာခဲ့၏။”/ “အဲရနုက်ဗပေၚ်ဂၞပ်စိုတ်အဲညိ။” (ဇ—စန္ဒကုမာ။ အစွောံ။) = “ငါ၏စိတ်အလိုကို ငါဖြည့်ဆည်းအံ့။”/ “တၞဟ်နရနုက်ဗပေၚ်ပါရမဳမရာတ်တုဲ ပ္ဍဲဇရေၚ်မရာတ် အဲမကၠုၚ်ရောၚ်။” (ဇ—ဝေသန္တဝ်။ အစွောံ။) = “သင်မင်းမြတ်၏ပါရမီတော်ကို ဖြည့်ဆည်းရန်အတွက် သင်မင်းမြတ်ထံ ကျွန်ုပ်လာခြင်းဖြစ်၏။”
,ရမတ်၊ ဍာ်ရမတ် (န) မျက်ရည်။/ “ရမတ်ဗြိုက်ဗြိုက်၊ သိုက်စိုတ်မာန်ရော။” (လိက်ဇမ္ဗူပတိ။မာံဒေံဍောတ်။) = “မျက်ရည်ဖြိုင်ဖြိုင်ဖြင့် အဘယ်မှာစိတ်ချမ်းသာနိုင်ပါမည်နည်း။”/ “ရမတ်ဒဇူ၊ နူစက္ခုဒွါ။” (လိက်သုပိဏ္ဏကုမ္မာ။ မၚ်သၚ်ကြာ။) = “စက္ခုဒွါရမှ မျက်ရည်ယို၏။”
,ရမတ်ဖျဖျ (ကြိဝိ) မျက်ရည်စမ်းစမ်း။ မျက်ရည်စက်လက်ဖြင့်။/ “ကောန်ဗြဴရေဝ်ရောတ်၊ ရမတ်ဖျဖျ။” (လိက်သုပိဏ္ဏကုမ္မာ။ မၚ်သၚ်ကြာ။) = “မျက်ရည်စက်လက်ဖြင့် သမီးရေရွတ်မြည်တမ်း၏။”
,ရသဂုန် (ပါသက်) (န) ရသစာပေဂုဏ်။ ရသဂုဏ်။
,ရသာရီု (ပါသက်) (န) ရသာရုံ။ လျှာဖြင့်ခံစားရသောအာရုံ။
,ရသိ (သ) (န) ရသေ့။/ “(ဗမၞးဂှ်) တိတ်ဂြိုပ်ဟေမဝန် ပခမဳရသိ—။” (ဇ—၂၉ဝ။ အစွောံ။) =“ထိုပုဏ္ဏားသည် ဟိမဝန္တာတောသို့ထွက်၍ ရသေ့ရဟန်းပြု၏။”/ ‘ဣသိ’ နှင့်အတူတူ။
,ရသွံ (စည်း) (ကြိနောက်ဆက်) ပါလား။ ပါတကား။ (အာမေဍိတ်ဝါကျ နောက်ဆုံးစကား။ အံ့သြခြင်းကိုပြသည်။)/ ညးကၠုၚ်ရသွံ = သူလာပြီပါလား။/ “ဇၟာပ်သတ်တအ် ဒးဗျုဒးချိုတ်ဖအိုတ်ရသွံ။” = “သတ္တဝါတိုင်း အိုရသေရမည်ချည်းပါတကား။”/ “အရေဝ်ညးဍာံကွေံရသွံ။” =“သူ့စကားတကယ်မှန်ပါလား။”
,ရာ (န) အရာ။ နေရာ။ အဘယ်။ အကြင်။/ “ရာထာန်ကောန်တၠမကြိုက်စိုတ်ကဵုဒးမံၚ် အဲဍိက်ဒၟံၚ်ရ။” (သၠပတ်ဒ္ၚောဝ်သၜောံ) = “အရှင့်သားသဘောကျနေစေလိုသည့် အဘယ်နေရာအရပ်မဆို ကျွန်တော်မျိုးနေပါမည်။”/ “ရာပၟိက်ဂၞပ်စိုတ်မရာတ်မွဲမွဲ မရာတ်နွံပၟိက်ဂှ် မရာတ်ဂးကဵုပိုဲရအဴ။” (ဇ—ဝေသန္တဝ်။ အစွောံ။) = “အရှင်မင်းကြီးအလိုရှိသောအရာကို အကျွန်ုပ်တို့အား ပြောပါလော့။”/ “ရာထပိုဲမသအာရော။” (အကြီုရာဇာဓိရာဇ်) = “ကိုရင်အဘယ်သွားမည်နည်း။”/ “ရာအမှတ်ကျာ်ဂမျိုၚ်မနွံဂှ် ဟွံဂွံနွံတုန်ဟာ။” (အကြီုရာဇာဓိရာဇ်) = “အရှင်မင်းမြတ်၏လိုရာရှိသည်ကို အဘယ်မရဘဲရှိပါမည်နည်း။”/ “လ္ဂန်အိန်ပိုဲဂွံတုဲ ရာမန်ဒုၚ်တဲအဲမာန်ရော” မၚ်ရာဲကယျဝ်ဆွာဂး။ (အကြီုရာဇာဓိရာဇ်) = “လဂွန်းအိန်ကို ငါတို့ရပါက အဘယ်မှာမွန်တို့ ငါ့လက်စွမ်းကို ခံနိုင်ငြားအံ့နည်း” ဟုမင်းရဲကျော်စွာဆို၏။/ “ရာပူဂဵုမွဲ သ္ဂောံမၚ်မွဲပ္ဍဲဓဝ်ခန္တဳဗိုန်တုဲကုသဵုဂှ်ဇၞော်မောဝ်လောန်။” (အကြီုရာဇာဓိရာဇ်) = “ခန္တီတရားကို မြဲစွာစောင့်စည်းသော အကြင်ပုဂ္ဂိုလ်အား ထိုကုသိုလ်သည် အလွန်ကြီးမား၏။”/ (စည်း) ကြိယာကို နာမ်ပြုလုပ်ရန်သုံးသောစကားလုံး။ —ရာ။/ “ဒဒှ်မပကာဂစိုတ် ၜိုန်ပြောဟိတ်တီကီု ပြောဟိတ်ဟွံဂံၚ်ဟီု (ကဵုသၟိၚ်) ၊ ရာမဂွံ ပြောဟိတ်သှ်အာသ္အာၚ်။” (သၠပတ်ဒ္ၚောဝ်သၜောံ) = “သေရလေမည်ကို ပုရောဟိတ်သိငြားသော်လည်း မင်းအားမလျှောက်တင်ဝံ့၍ အခြားသောရရာကို ပုရောဟိတ်ဖြေကြားလိုက်၏။”/ “သစ္ဆုတံဝွံ ရာမဍုဟ်ရုဲစှ်ဂၠဟ်တုဲ သြဝ်ပပြဘိုက်ရ။” (ဇ—ဝေသန္တဝ်။ အစွောံ။) =“ဤသစ်သီးတို့ကို မှည့်ရာရာရွေးချယ်၍ သုံးဆောင်ပါလော့။”/ “လွဵုရာမဒးဂၞပ်စိုတ်ဂှ် မရာတ်ဂိုၚ်လဝ်ပ္တုဲရ။” (ဇ—ဝေသန္တဝ်။ အစွောံ။) = “နှစ်သက်ရာဆုကို သင်မင်းမြတ် အပြီးယူထားပါလော့။”/ “ရာဂတအာ ဂွံဒှ်ဇဲယဇၞး။” (အကြီုရာဇာဓိရာဇ်) = “မျက်နှာမူသွားလေရာရာအောင်ပွဲရလိမ့်မည်။”
,ရာဂ (ပါ) (န) တပ်စွန်းခြင်း။ တပ်မက်ခြင်း။ ရာဂ။
,ရာဂံါ၊ ရာဂါမ် (န) တူရိယာတစ်မျိုး။/ “စံၚ်ဒြဝ်သေဲကျာံ၊ ရာဂံါသဗ္ဗ။” (လိက်သၚ်ဂဒါ။ သဳလဝန္တ။)/ “စံၚ်ဂြဝ်သေဲကျာံ၊ ရာဂံါခရာ။” (လိက်ဝါရဝေါၚ်သ။ အစွောံ။)/ “စမြေဲဂမ္အတ်၊ ရမျှာၚ်ဏတ်ဏံၚ်။ ရဴကွိၚ်ရာဂါမ်၊ ခဍေဝ်ကျာံစံၚ်။” (လိက်ဗောဓိသတ်စှ်။ ပဏ္ဍိတ။)
,ရာဇမာတ်၊ ရာဲဇမာတ်၊ ရာဇာဒၟာတ် (န) ရာဇမတ်အကာအရံ။ (နှီး၊ ဝါးခြမ်းစသည်ဖြင့် မှန်ကူကွက်ပုံရက်ထားသော မင်းလမ်းအကာအရံ။)/ “သဗာန်ဂ္ညိဂ္ညာတ်၊ ရာဲဇမာတ်သ္တီု။” (လိက်ပဒုမဝတဳ) = “လမ်းမကြီးသည် ထူထပ်သောရာဇမတ်တို့ဖြင့် တန်ဆာဆင်ထား၏။”/ ‘တက်ရာဇမာတ်’ (ကြိ) လည်းရှု။
,ရာဇာ (ပါ) (န) ဘုရင်။ မင်း။
,ရာဇာဋ္ဌာနဳ (ပါ) (န) မင်းနေပြည်တော်။ ရာဇဓါနီ။ ရာဇဋ္ဌာနီ။/ ‘ရာဇာဓနဳ’ နှင့်အတူတူ။
,ရာဇာဒမာတ်၊ ရာဇာဓမာတ် (န) ရာဇမတ်။/ “ၜါလ္ပာ်တရဴမသစဴဂှ် ကဵုသြံက်လဝ်က္ဍိုၚ်ဇၞောဝ် စဵုရာဇာဓမာတ်။” (အကြီုရာဇာဓိရာဇ်) = “ပြန်ရာလမ်းနှစ်ဖက်­ ထီးတံခွန်တို့ကိုစိုက်၍ ရာဇမတ်ကာရံထား၏။”/ ‘ရာဇမာတ်/ရာဲဇမာတ်’ နှင့်အတူတူ။
,ရာဇာဒုတ်၊ ရာဇာဒုတ္တ (ပါသက်) (န) ဘုရင့်တမန်တော်။ သံအမတ်။ (ပါဠိ—ရာဇဒူတ)/ “မိၚ်လိက်ကလုတ်၊ ရာဇာဒုတ္တ။” (လိက်ဗောဓိသတ်စှ်။ ပဏ္ဍိတ။) = “ဘုရင့်တမန်တော်၏ စာပါအကြောင်းကို ကြားလတ်သော်—။”/ “ဖအောဝ်ရာဇာဒုတ်၊ ကလုတ်စကာ။” (လိက်သၟိၚ်စိၚ်ဆဒ္ဒန်။နာဲထဝ်စိုပ်။) = “မင်းသံတမန်တော်ကို စေလွှတ်သည်။”/ “အဲပကလုတ်၊ ရာဇာဒုတ်စိ။” (လိက်ဇမ္ဗူပတိ။ မာံဒေံဍောတ်။)
,ရာဇာဒန်၊ ရာဇာဒဏ် (န) ရာဇဒဏ်။ မင်းပေးသောအပြစ်ဒဏ်။/ “ယွံတၠညး၊ ဗမၞးပၠံၚ်ဒြပ်သၟိၚ်အဴ”ဍေံဂး။ “ဒှ်ရသာ်ဂှ် ဒးပရာဇာဒဏ်ရ” သၟိၚ်ဂး။ (ဇ—၈၆။ အစွောံ။) = “အရှင်မင်းကြီး၊ ပုဏ္ဏားသည် မင်း၏ဥစ္စာကို လုယက်၏” လျှောက်တင်၏။ “သို့ဆိုလျှင် ရာဇဒဏ်ပြုရမည်” ဟုမင်းဆို၏။/ “အမာတ်မဟီုဗျဵုဂှ် သၟိၚ်ဗပုန်တီဒုဟ်တုဲ ကဵုပကၠေံရာဇာဒန်တုဲ—။” (ဇ—၂၈၂။ အစွောံ။) =“ခိုးသူမင်းသည် ကုန်းချောသောအမတ်၏ အပြစ်ကိုသိ၍ မင်းဒဏ်ပြုစေ၏။”
,ရာဇာဓနဳ၊ ရာဇာဓါနဳ (ပါ) (န) ၁။ မင်းနေပြည်တော်။ ရာဇဓါနဳ။/ “ကာလဂှ် ပ္ဍဲဍုၚ်ရာဇာဓနဳလ္ၚုအာရ။ သတ္တအ်ဒဴအာ ပ္ဍဲရးသကးတုဲ တန်ဒၟံၚ်ရ။” (ဇ—၇၇။ အစွောံ။) = “ထိုအခါ ရာဇဓါနီမင်းနေပြည်တော်­ ဆိတ်၍ လူအပေါင်းတို့သည် ရပ်စွန်ပြည်နားသို့ ပြေးရှောင်သွားကာ တည်နေကုန်လတ္တံ့။”/ “ပ္ဍဲကွာန်နိဂီုရာဇာဓနဳတံဂှ် မၞးဂ္ၚေၚ်အာတုဲ—။” (ဇ—၃၁၈။ အစွောံ။) = “သင်တို့သည် ရွာနိဂုံးမင်းနေပြည်တို့သို့ လှည့်လည်ကုန်လျက်—။” (ညောင်ကန်)/ “ၜါက္ဍိုၚ်ဗ္တာၚ်ဝွံဒှ်ရာဇာဓနဳဇၞော် သီုၜါဍုၚ်ရောၚ်။” (အကြီုရာဇာဓိရာဇ်) = “မြို့နှစ်မြို့စလုံးသည် မင်းနေပြည်တော်မြို့ကြီးတည်း။”/ “ပ္ဍဲဗညာအူတၠညးစိၚ်ဗ္တာၚ် မကၠောံပသၟိၚ်ဝွံ (ဍုၚ်ဗဂေါ) မဒှ်ရာဇာဓနဳပၠန်ရ။” (အကြီုရာဇာဓိရာဇ်) = “ဆင်ဖြူရှင်ဗညားဦးမင်းက ရွှေ့ပြောင်းမင်းပြု၍ ဗဂိုးမြို့သည် ရာဇဓါနီ မင်းနေပြည်တော်ဖြစ်ပြန်၏။”/ ၂။ မင်းမျိုးမင်းနွယ်များနှင့် ပြည့်စုံသောအရပ်။/ “ရာဇာဓနဳ၊ မွဲခုတ်ပ္ညဳပ္တန်။ တၞောဝ်သၟိၚ်ပြဲဖာ၊ ဂၠိုၚ်ပြကာသန်။” (လိက်သောဝိန်ဇဲယ။ မာံရောဂေါ။) =“ရာဇဓါနီဆိုသည်မှာ မြတ်သောမင်းမျိုးမင်းနွယ်တို့နှင့် ပြည့်စုံသောအရပ်တည်း။”/ ‘ဓနဳပန်သာ်’ (န) လည်းရှု။
,ရာဇာဓိတာ (ပါ) (န) ဘုရင့်သမီးတော်။ မင်းသမီး။
,ရာဇာပသေက် (ပါသက်) (န) မင်းအဖြစ်အဘိသိက်သွန်းခြင်း။/ ‘စရိုဟ်ဍာ်ရာဇာပသေက်။’ (ဇ—၅၁ဝ။ အစွောံ။) = ‘မင်းအဖြစ်တင်မြှောက်ရန် အဘိသိက်ရေသွန်းလောင်းသည်။’
,ရာဇာပုတ္တ (ပါ) (န) ဘုရင့်သားတော်။ မင်းသား။
,ရာဇာပလ္လၚ်၊ ရာဇာပလၚ် (ပါသက်) (န) မင်းထိုင်တော်မူရာပလ္လင်။ ရာဇပလ္လင်။ တရားဟောပလ္လင်။/ “သၟိၚ်မှာသဳလဝဂ္ဇအ်ဒၟံၚ်လတူရာဇာပလၚ်။” (ဇ—၅၁။ အစွောံ။) = “မဟာသီလဝမင်းသည် ရာဇပလ္လင်ထက်­ ထိုင်နေတော်မူ၏။”/ “သၟိၚ်မှာသဳလဝရာဇာတုန် လတူရာဇာပလ္လၚ်ထဝ်သၟဝ်က္ဍိုၚ်ဗ္တာၚ်ဂှ် တန်ဒၟံၚ်တုဲ—။” (ဇ—၅၁။ အစွောံ။)/ “(ကျာ်တြဲ) တိတ်ကၠုၚ်နူဂန္ဓကုဋဳတုဲ တိုန်အာလတူရာဇာပလ္လၚ်တုဲ သၟာန်ခမဳဂမၠိုၚ်ရ။” (ဇ—၂၄ဝ။ အစွောံ။)
,ရာဇာဘိသေက်၊ ရာဇာပသေက် (ပါသက်) မင်းအဖြစ်အဘိသိက်သွန်းခြင်း။
,ရာဇာဝၚ် (ပါသက်) (န) မင်းစဉ်မင်းဆက် အကြောင်းအရာမှတ်တမ်း။ ရာဇဝင်။
,ရာဇာဝၚ်ရိုၚ် (ကြိ) ရာဇဝင်ရိုင်းသည်။ (အစဉ်အဆက် ကဲ့ရဲ့ပြစ်တင်ဖွယ်ဖြစ်သည်။)
,ရာဇာဝတ် (န) ၁။ မင်းကျင့်ဝတ်။/ ၂။ ရာဇဝတ်ပြစ်မှု။/ ၃။ မင်းမှုမင်းရေး။/ “ရာဇာဝတ်ကောံ၊ဓမ္မဝတ်ဇဳ။ လောကဝတ်စိ၊ ဝတ်ပိသၟဟ်ညဳ။” (လိက်ကောန်သၟိၚ်ပိ။ မာံခစုန်အံက်။) = “ရာဇဝတ်၊ ဓမ္မဝတ်၊ လောကဝတ်ဟူသော ဝတ္တရားသုံးပါးနှင့် ပြည့်စုံညီညွတ်သည်။”
,ရာဇာသာတ် (ပါသက်) (န) ၁။ မင်းရေးမင်းရာ။ မင်းအာဏာစက်။ (ပါဠိ—ရာဇသတ္တ)/ “တ္ၚဲရယောၚ်မှာ၊ ပ္ဍဲရာဇာသာတ်။ သၟိၚ်ဨကရာတ်၊ ဒုၚ်ပါၚ်ဝါတ်သန်။” (လိက်ပဒုမဝတဳ) = “မင်းရေးမင်းရာ­ ချွတ်ချော်မှားယွင်းသောနေ့­ မင်းဧကရာဇ်သည် နှုတ်ထွက်သဘောတူနိုင်ခဲ၏။”/၂။ ပြစ်မှုဆိုင်ရာဥပဒေ။ ရာဇသတ်။/ “သၟိၚ်ဟီုတိုန်ကၠာ၊ ကဵုသေဏာရ။ မၞးတအ်စဳရေၚ်၊ လၟေၚ်ဓမ္မ။ တိုၚ်ရာဇာသာတ်၊ ဓမ္မသာတ်ဂျ။ — ပဝေဏဳကၠာ၊ ညးတမၠာပၠ။ ဂစိုတ်ထောံဍေံ၊ ဟွံဒးပြဝ။” (လိက်သောဝိန်ဇဲယ။ မာံရောဂေါ။) = “မင်းသည် သေနာပတိအားဆို၏၊ တရားနှင့်အညီရာဇသတ်ပြစ်မှုဥပဒေအရ၄င်း ဓမ္မသတ်ဥပဒေအရ၄င်း ရှေးသူတို့၏ထုံးတမ်းစဉ်လာအတိုင်း သင်တို့စီရင်ကြကုန်လော့။ သူ့ကိုသတ်ပစ်ရန် မလျောက်ပတ်။”/ “ဒုဟ်ဍေံဇၞော်သန်၊ ကဵုဒန်ရာဇာ။တိုၚ်ဓမ္မသာတ်၊ ရာဇာသာတ်ကၠာ။” (လိက်သောဝိန်ဇဲယ)
,ရာဇာသာန် (န) ဘုရင့်စာချွန်တော်။ မင်းစာချွန်တော်။/ “သကဵုစမိန်ဍုၚ်ဟာ စၞေဟ်ဟာဂးတုဲ ကဵုပလံၚ်ပၠောပ်လိက်ရာဇာသာန်ရ။” (ဇ—၁၈၁။ အစွောံ။) = “ပြည်ကိုမူလည်း ပေးမည်လော၊စစ်ထိုးခြင်းသော်လည်း ပြုမည်လောဟု မင်းစာချွန်တော်သွင်းစေ၏။”/ “ပွမဏာလိက်ရာဇာသာန်တံဂှ်လေဝ် နွံတဴရ။” (ဇ—၄ဝ၉။ အစွောံ။) = “မင်းစာချွန်တော်များ ပို့ရခြင်းသည်လည်းရှိ၏။”
,ရာဇာသမ္ပတ္တိ (ပါ) (န) မင်းစည်းစိမ်။ ဘုရင့်စည်းစိမ်။
,ရာဇိုန် (န) ‘ရာဲဇိုန်’ ရှု။
,ရာဒနာ၊ ရာဒၞာ၊ ရာဓနာ (ကြိ) ဆုတောင်းသည်။ ဆုပန်သည်။/ “ရသိသုမေဓ ရာဒနာသၟိက်ဂွံဒှ်ကျာ်။” = “သုမေဓါရသေ့သည် ဘုရားအဖြစ်ကို ဆုပန်၏။”/ “(ယွံၝောံ) ၊ ရာဒနာပတ္တဏာရ။ဨကရာတ်နာဲပိုဲ ကဵုဂွံဗၠးနူသ္ကေံတဲသတြုညိ” ဗမၞးဂး။ (ဇ—၂၈၉။ အစွောံ။) = “ရှင်မ၊ ဆုတောင်းပတ္ထနာလော့။ ငါတို့၏အရှင်မင်းကြီး ရန်သူ့လက်တွင်းမှ လွတ်မြောက်ပါစေသတည်း။”
,ရာဒနာမိက်၊ ရာဓနာမိက် (ကြိ) ၁။ တောင့်တသည်။ အလိုရှိသည်။/ “ယွံဒေံ၊ ညံၚ်စၞကၠိက်သာလူကဂှ် ဒေံလ္ပရာဒၞာမိက်ရ” ဂၠဴကောဂှ်ဂး။ (ဇ—၂၈၆။ အစွောံ။) = “ညီထွေးစူဠလောဟိတ၊ သင်သည် သာလူကဝက်၏ ယာဂုထမင်းကို မတောင့်တလင့်။” (ညောင်ကန်)/ ၂။ ဆုတောင်းသည်။/ “သၟိၚ်ဂှ် ကောန်ဟွံမွဲတုဲ သမ္ဘာဇကုဂှ် ကဵုရာဒနာမိက်ကောန်တြုံမွဲရ။” (ဇ—၂၆၃။ အစွောံ။) = “မင်းသည် သားမရှိသည်ဖြစ်၍ မိမိမိန်းမတို့ကို သားဆုတောင်းကြကုန်လော့ဟုဆို၏။” (ညောင်ကန်)
,ရာဒေါဝ် (န) ၁။ လုံးကြီးတင်ဆန်ခတ်။ အက္ခရာအထက်တွင်ရေးသော မွန်ဣဳသရသင်္ကေတ။ —ဳ။/ ၂။ အနေတော်။ သင့်တင့်သောအခြေအနေ၊ အရွယ်အစား။
,ရာသဳ (ပါ) (န) ရာသီ။ တန်ခူး၊ ကဆုန်စသော တစ်လကာလအပိုင်းအခြား။/ စှ်ၜါရာသဳ =ဆယ့်နှစ်ရာသီ။
,ရာသဳဥတု (ပါ) (န) ရာသီဥတု။ ရာသီဥတုအခြေအနေ။/ “တ္ၚဲဏအ် ရာသဳဥတုခိုဟ်ဒၟံၚ်ရ။” =“ယနေ့ ရာသီဥတုအခြေအနေ ကောင်းမွန်သည်။”
,ရာဟု (န) ၁။ ဗုဒ္ဓဟူးနေ့ မွန်းလွဲသည်မှ နောက်ပိုင်းကာလ။ ရာဟု။/ ၂။ နေ၊ လကို ဖမ်းယူ၍ခံတွင်း­ ၚုံထားတတ်သည်ဆိုသော အသူရိန်နတ်။/ ရာဟုရပ်ဂိတု = လကို ရာဟုဖမ်းသည်။/၃။ (ဥပစာ) မကောင်းကျိုးကို ပေးတတ်သောသူ။ ဂြိုဟ်ကောင်။
,ရာဟုထကဵု (ကြိ) ဂြိုဟ်မွှေသည်။ အမျိုးမျိုးအဖုံဖုံ ဒုက္ခပေးသည်။
,ရာဟုလုပ် (ကြိ) ဂြိုဟ်ဝင်သည်။ စိတ်အနှောင့်အယှက်ဖြစ်ရသည်။ ဒုက္ခရောက်သည်။
,ရိ—၁ (န) ၁။ ကျည်ပွေ့။/ ရိတဲ = လက်ဖြင့်ထောင်းသောကျည်ပွေ့။/ “ခအဳခိုဟ်၊ ရိခိုဟ်၊ နခိုဟ်၊ ကၞာဲခိုဟ် အဲသၟိက်ဂွံရ” ဍိက်ဗြဴဂး။ (ဇ—၂၈၉။ အစွောံ။) = “ဆုံကောင်း၊ ကျည်ပွေ့ကောင်း၊ တောင်းကောင်း၊ ဆန်ကောကောင်းတို့ကို ငါလိုချင်၏။”/ ၂။ ဝင်ရိုး။/ ရိကွဳ =လှည်းဝင်ရိုး။/ ရိစက် = စက်ဝင်ရိုး။/ ၃။ အူတိုင်။/ ရိပၞဟ် = ပိနနဲသီးအူတိုင်။
,ရိ—၂ (နဝိ) ၁။ မာသော။ မနူးညံ့သော။ မပျော့ပျောင်းသော။/ “ဍုန်လဝ်ပုၚ်ဏအ် ရိအာရ၊ စဟွံဂွံရ။” = “ထမင်းချက်ထားသည်မှာ မာသွားပြီး။ စားလို့မရတော့ပါ။”/ ၂။ ပေကတ်ကတ်ပြုမူတတ်သော။/ “ကောန်ၚာ်ဏအ်ရိဒၟံၚ်ညိရောၚ်။” = “ဤကလေးသည် အနည်းငယ်ပေကတ်ကတ်နိုင်သည်။”
,ရိကွဳ (န) လှည်းဝင်ရိုး။
,ရိတာ (ပါသက်) (န) ဆေးဒန်း။ (ပရဆေးအဖြစ်လည်းကောင်း၊ ပန်းချီဆေးအဖြစ်လည်းကောင်းသုံးရသော အဝါရောင်ကျောက်နု။) (ပါဠိ—ဟရိတာလ)/ “ယွံကောန်ၚဴသၠ မၞုံသာ်မတုပ်တဴရဴရိတာ—။” (ဇ—၂၃၉။ အစွောံ။) = “ဆေးဒန်းကဲ့သို့အဆင်းရှိသော အိုဖားညို—။”
,ရိရေၚ် (နဝိ) ခက်မာသော။ မနူးညံ့သော။ မပျော့ပျောင်းသော။/ ‘ရိ—၂ (၁) ’ နှင့်အတူတူ။/ ပွမရိရေၚ် = ပွမကြံၚ်မ္ၚိုဟ် (ပါဠိ—နိတ္ထဒ္ဓန) (= ခက်မာခြင်း။ တောင့်တင်းခြင်း။)
,ရဳရောတ် (ကြိ) မြည်တမ်းသည်။/ ‘ရေရောတ်’/‘ရေဝ်ရောတ်’ နှင့်အတူတူ။/ “မၞိဟ်တံညးဂမၠိုၚ်ယာံရဳရောတ်အိုတ်ရ။” (ဇ—စန္ဒကုမာ။ အစွောံ။) = “လူအပေါင်းတို့သည် ငိုကြွေးမြည်တမ်းကြကုန်၏။”
,ရုဂှ်ဒ (စည်း) ဤသို့။ ဟူ၍။ (ဣတိဟူသော ပါဠိ၏အနက်)/ “ဨတံသဗ္ဗမ္ပိ၊ န်ချဵုအိုတ်သီုဂှ်ကီုလေဝ်။ အကပ္ပိယတူလန္တိ၊ ချဵုဟွံဂပ်ဂဝ်ရုဂှ်ဒ။ ဝုစ္စတိ၊ ပ္ဍံဂပ်ဂဝ်သ္ဂးရ။” (တြာဲဝိနယသၚ်ရိုဟ်ဂြဳ။စန္ဒိမာ။) = “အားလုံးသောလဲဝါတို့ကိုလည်း မလျောက်ပတ်သောလဲဝါဟူ၍ ခေါ်ဆိုအပ်၏။”/“ဝိမာနံ၊ န်လွဳမာန်။ ရုက္ခပဋိဗန္ဓိတတ္တာ၊ ဟိုတ်မစပ်ကဵုတၞံဆုအဵု။ ရုက္ခဝိမာနန္တိ၊ လွဳမာန်က္တဵုဒှ်ပ္ဍဲတၞံဆုရုဂှ်ဒ။ ဝုစ္စတိ၊ ပ္ဍံဂပ်ဂဝ်တွံလဝ်ရ။” (အဘိဓမ္မတ္ထဒဳပနဳ။ ဂရိုက်သာံ။) = “ထိုဗိမာန်အား သစ်ပင်နှင့်စပ်ခြင်းကြောင့် သစ်ပင်­ဖြစ်သောဗိမာန်ဟူ၍ ဟောအပ်၏။”
,ရုဒှ် (ကြိ) ရုတ်ရုတ်သဲသဲဖြစ်သည်။ အုတ်အော်သောင်းတင်းဖြစ်သည်။/ “နူဘုံနရက်၊ ဒဵုဘဝဂ္ဂါ။ ရုဒှ်လကိုတ်၊ အိုတ်စက္ကဝါ။” (လိက်ဗောဓိသတ်စှ်။ ပဏ္ဍိတ။) = “ငရဲဘုံမှသည် ဘဝဂ်တိုင်အောင်အလုံးစုံသောစကြဝဠာသည် ရုတ်ရုတ်သဲသဲဖြစ်၍ ထိတ်လန့်ကုန်၏။”/ “ကောန်ဒေဝတဴဂမၠိုၚ်ရုဒှ်တုဲ ကဵုတဴသာဓုကာ ပ္ဍဲကာလဂှ်ရ။” (သၠပတ်သုရသာ) = “နတ်သားအပေါင်းတို့သည် အုတ်အော်သောင်းတင်းဖြစ်ကာ ကောင်းချီးသြဘာပေးကြကုန်၏။”/ “ညာတ်နုဘဴကၠာ၊ ပၞာန်သၟိၚ်မာကီု။ ရုဒှ်လကိုတ်၊ ဒေဝအိုဿီု။” (လိက်ပထမဗောဓိ။ မၚ်ဍိက်လ။) = “မာရ်နတ်စစ်၏အာနုဘော်ကို မြင်သည်ရှိသော် နတ်အပေါင်းတို့သည် ရုတ်ရုတ်သဲသဲဖြစ်ကာ ထိတ်လန့်ကုန်၏။”
,ရုရု (ကြိဝိ) တစ်ပြိုင်နက်ကျယ်လောင်သောအသံဖြင့်။ အုတ်အုတ်ကျက်ကျက်။ ရုတ်ရုတ်သဲသဲ။/“ဟာဲကၠဵုသမ်အုဲ၊ ပဆိုက်ပဆိုက် ဍေံတံဂးတုဲ ဍေံတံဗိုၚ်ဇီုဗိုတ်ကၠဟ်အဲ ရုရုရအဴ။” (ဇ—၅၁၆။ အစွောံ။) = “ဟယ်ခွေးကောင်ပုပ်၊ မချဉ်းကပ်လာလေနှင့်ဟုဆိုကာ ထိုသူတို့သည် အကျွန်ုပ်အားအုတ်အုတ်ကျက်ကျက် ရိုက်ခတ်ပစ်ပေါက်ကြကုန်၏။”/ “ယွံသမ္ၚေဟ်၊ တၠအဲပကၠေံခမဳတုဲရဂးတုဲအလုံသ္ၚိတၠအဲ ကောန်သမ္ဘာဍိက်သ္ကံဗော်သွးတအ် ယာံဒၟံၚ်ရုရုရ ဟွံသေၚ်ဟာ။” (ဇ—၁၇၁။ အစွောံ။) = “သူကြွယ်၊ သင်ရဟန်းပြုပြီဟုဆိုကာ သင့်တစ်အိမ်သားလုံး သားမယား၊ ကျေးကျွန်၊အခြံအရံများသည် ကျယ်လောင်သောအသံဖြင့် ငိုကြွေးမြည်တမ်းနေကြကုန်သည် မဟုတ်လော။”/ “သၟိၚ်ဂမၠိုၚ်အာရံၚ် ဟွံညာတ်သၟိၚ်စူဠဏဳတုဲ ရုရုဒှ် ဖေက်လကိုတ်တဴ။” (ဇ—မဟောဟ်သဓ။အစွောံ။) = “ထိုမင်းအပေါင်းတို့သည် သွားကြည့်ကြရာ စူဠနီမင်းကို မမြင်ရသည်ရှိသော်ရုတ်ရုတ်သဲသဲဖြစ်ကုန်၍ ထိတ်လန့်ကုန်၏။”/ “အိုတ်ဒေဝတဴ၊ ဂၞဴစက္ကဝါ။ ကဵုပါၚ်ရုရု၊ ဒုၚ်သာဓုကာ။” (လိက်ကောန်ဂစေံပိ။ နာဲဗျူ။) = “စကြဝဠာအလုံးမှ နတ်ဒေဝါအပေါင်းတို့သည် ကျယ်လောင်သောအသံဖြင့် ကြွေးကြော်ကာ သာဓုခေါ်ကြကုန်၏။”
,ရုရုဒြီုဒြီု၊ ရုရုဂြီုဂြီု (ကြိဝိ) ကျယ်လောင်သောအသံဖြင့်။ အုတ်အုတ်ကျက်ကျက်။ တပြိုင်နက်ကြွေးကြော်လျက်။/ “သၞောဝ်ဝွံ ဒှ်ဗဗွဲဓဝ်ကွေံရ” (မှာဇန်တံ) ဂးတုဲ ကဵုသာဓုကာ ရုရုဒြီုဒြီုရ။ (ဇ—စန္ဒကုမာ။ အစွောံ။) = “—တရားကို ကောင်းစွာဆုံးဖြတ်စီရင်ပေ၏” ဟု ကြွေးကြော်အံ့ချီးကောင်းချီးပေးကြကုန်၏။ (မင်းပူးဦးသြဘာသ)
,ရုသံၚ် (န) (ကြိ) အုတ်အုတ်ကျက်ကျက်ဖြစ်သည်။ ရုတ်ရုတ်သဲသဲဖြစ်သည်။ အုတ်အော်သောင်းတင်းဖြစ်သည်။/ “ပ္ဍဲထာန်ဒေါဝ်တ္ၜဳ၊ ညဳသာဒၞာဲမံၚ်။ နာဲတအ်ပ္ၚောအ်အာ၊ ကၠာညးရုသံၚ်။” (လိက်သၟိၚ်အသး။ နန္ဒသာရ။) = “နေရာကောင်းဖြစ်သော ပင်လယ်အလယ်သို့ သူတစ်ပါးတို့မရောက်သေးမီ အုတ်အော်သောင်းတင်းမဖြစ်သေးမီ သင်တို့အမြန်သွားကြကုန်လော့။”/ “က္ၜိုၚ်ဒြာဲရုသံၚ်၊ ဒြေပ်ညံၚ်ဖေက်ကၠ။” (လိက်သၟိၚ်အသး) = “ဆတ်၊ သမင်တို့သည် ကျားကိုကြောက်၍ ထွက်ပြေးဘိသကဲ့သို့ ရုတ်ရုတ်သဲသဲဖြစ်ကုန်၏။”
,ရုရုသံၚ်သံၚ် (ကြိဝိ) ရုတ်ရုတ်သဲသဲ။ အုတ်အော်သောင်းတင်း။/ “ရုရုသံၚ်သံၚ်၊ ဟောကၠံၚ်သဒ္ဒ။ဂမဳတအ်ကၠာ၊ ထိုၚ်သးညာဏ။ အသဝ်ကွေံရ၊ သောဘဂဝါ။” (လိက်ဝိဓူရ) = “မြတ်စွာဘုရားရှင်၏ အံ့ဖွယ်ဉာဏ်ပညာတော်ကို ရဟန်းအပေါင်းတို့ ချီးမွမ်းနေကြကုန်သည်မှာ အုတ်အော်သောင်းတင်း သောသောညံနေ၏။”/ “အိုတ်ကဵုမၞိဟ်ကီု၊ အိန်ဗြီုဒေဝံၚ်။ ဗိုၚ်ကဵုသာဓု၊ ရုရုသံၚ်သံၚ်။” (လိက်သုဝဏ္ဏသာံ။ မာံသေၚ်။) = “ခပ်သိမ်းကုန်သောလူ၊ သိကြား၊ ဗြဟ္မာအပေါင်းတို့သည် အုတ်အော်သောင်းတင်း ကောင်းချီးပေးကြကုန်၏။”
,ရူပကအလၚ်္ကာရ (ပါ) (န) ရူပကအလင်္ကာ။ (ဂုဏ်ရည်တူနှစ်ခုကို ထပ်တူပြု၍ ယှဉ်တွဲသုံးသောအလင်္ကာ။)
,ရူပနိကာဲ (ပါသက်) (န) ရုပ်ဆင်းသွင်ပြင်။ ရူပနိကာယ်။
,ရူပဗေဒ (ပါ) (န) ရုပ်ဝတ္ထု စွမ်းအင်စသည်တို့ကို လေ့လာသောသိပ္ပံပညာရပ်။ ရူပဗေဒပညာရပ်။
,ရူပဘုံ (ပါသက်) (န) ရုပ်ရှိသော ဗြဟ္မာများဖြစ်ရာ (၁၆) ဘုံ။ ရူပဘုံ။
,ရူပါရီု၊ ရုပ္ပါရီု (ပါသက်) (န) မျက်စိဖြင့်မြင်နိုင်သောအာရုံ။ အဆင်း။ ရူပါရုံ။
,ရူပက္ခန္ဓ (ပါ) (န) ရုပ်တရားအစု။ ရူပက္ခန္ဓာ။
,ရူရူ (ကြိဝိ) တဟူးဟူး။ တဟုန်းဟုန်း။/ “ရဴသၞဍောတ်၊ ပၟတ်လ္ၚ။ စံၚ်ဂြိုပ်ကာယ၊ ခန္ဓညးအဲ။ တူမံၚ်ရူရူ၊ ဇနူဟွံမွဲ။” (လိက်ဝိဓူရ) = “သေးငယ်သောမီးလျှံမီးကျီးခဲသဖွယ် သူသူငါငါ၏ခန္ဓာကိုရှို့ဘိသကဲ့သို့ မရပ်မနား တဟူးဟူးလောင်ကျွမ်းနေ၏။”
,ရူဠှဳ၊ ရုဠှဳ (ပါ) (န) တင်စားခြင်း။ တင်စားခေါ်ဝေါ်ခြင်း။
,ရေဒါ (လိပ်သက်) (န) ရေဒါ။ (အင်္ဂလိပ်၊ radar)
,ရေဒဳယဝ်၊ ရေဒဳယော (လိပ်သက်) (န) ရေဒီယို။ (အင်္ဂလိပ်၊ radio)
,ရေရောတ်၊ ရေဝ်ရောတ် (ကြိ) မြည်တမ်းသည်။ ညည်းတွားသည်။/ “သၟိၚ်စိၚ်မိၚ် (ဒဒှ်သၟိၚ်စုတိ) တုဲနလပှ် ဇွိတ်သပေါတ်ကောန်ၚာ်ဂှ်တုဲ — ရေရောတ်ကရောတ်သ္အဝ် ယာံတဴသ္ၚံသ္ၚံ—။” (ဇ—၁၅၆။အစွောံ။) = “ဆင်မင်းသည် မင်း၏နတ်ရွာစံကြောင်းကို ကြားသိပြီးနောက် မင်းသားငယ်ကိုနှာမောင်းဖြင့်သုံးသပ်၍ ညည်းတွားမြည်တမ်းလျက် သည်းစွာငိုကြွေးလေ၏။”/ “(ဗောဓိသတ်သၟိၚ်စိၚ်ဆဒ္ဒန် ဒးပွန်ကံလၟတုဲ ဂၞကျာ်မဟာသုဘဒ္ဒါဂှ်) သီုကဵုသဓဵုသမ္ၚဟ် ရေရောတ်ဂစေအ်ဂစောတ် ဇွိတ်သပေါတ်တၠသ္ၚိဇကုတုဲ သီုကဵုဍာ်ရမတ် မပေၚ်တဴနကဵုဂဍောၚ်မတ်ၜါဂှ်ရ။” (ဇ—၅၁၄။အစွောံ။) = “ဘုရားလောင်းဆဒ္ဒန်ဆင်မင်းသည် မုဆိုး၏မြှားချက်ကို ထိမှန်၍ မဟာသုဘဒ္ဒါဆင်မိဖုယားသည် ပူဆွေးသောကဖြင့် ငိုကြွေးမြည်တမ်းလျက် မိမိခင်ပွန်းအားပွတ်သပ်၍ မျက်လုံးနှစ်ဖက်တို့­ မျက်ရည်တို့ဖြင့်ပြည့်၏။”/ “ကၠဵုဂှ်ကၠုၚ်စိုပ်စိၚ်ဂှ်တုဲ နလပှ်မိန်ကေတ်ကၠဵုဂှ်တုဲပ္တိုန်ဏာလတူကၟံၚ်တုဲ ဂစေဝ်ဂစောအ် ရေဝ်ရောတ်ယာံတဴရ။” (ဇ—၂၇။ အစွောံ။) = “ခွေးရောက်လာသည်ရှိသော် ဆင်သည်နှာမောင်းဖြင့် ခွေးကိုပွေ့ချီ၍ ဦးကင်းပေါ်­တင်၍ မြည်တမ်းလျက်ငို၏။”/ “ဟီုမံၚ်ကာပ်ကာပ်၊ လ္ၚာပ်ထဂုန်ဗြဴ။ တလက္ဍိုၚ်ပ္ကဴ၊ ရေဝ်ရောတ်တဴတုန်။” (လိက်သၚ်ဂဒါ။ သဳလဝန္တ။) = “မိန်းမကြောင့်ပူဆွေး၍ မင်းသည် တဖျစ်တောက်တောက် ပြောဆို မြည်တမ်း၏။”
,ရေသူ (န) ကျောက်မျက်သွေးသောအတတ်။ ကျောက်မျက်သွေးသမား။/ “ရေသူဃောတောတ်၊ချူမတ်ဗိုတ်ဗၠဲ။” (လိက်ဗြရတ်ဣဏၚ်ကၚ်ရဳ) = “ကျောက်မျက်သွေးသမားသည် စိန်ကျောက်ပုလဲတို့ကို သေချာစွာသွေးနေတုန်းဖြစ်၏။”/ “ရေသူချူမတ်၊ ရတ်ဒစိတ်တန်။ မၞိက်ဗိုတ်ဗၠဲ၊ ဗ္ဂဲဟွံခၠန်။ ဂေါမုတ်မြကၠာ၊ ခုဿရာပၠန်။ သိလ္လာနဳလာ၊ နာနာဂၠိုၚ်သန်။” (လိက်ကောန်သၟိၚ်ပိ။ မာံခစုန်အံက်။) = “ကျောက်မျက်သွေးသမားသည် ကျောက်မျက်ရတနာကိုးမျိုးကို သွေး၏။ ပတ္တ မြား၊ စိန်၊ ပုလဲ၊ ကြောင်မျက်ရွဲ၊ ဂေါ်မုတ်၊ မြ၊ ဥဿဖရား (?) ၊ သန္တာ၊ နီလာဟူ၍ ကျောက်မျက်မျိုးစုံ၏။”/ “ပ္ၚောအ်ထာန်ဖျာ၊ သၟတ်ကွာ်အာရ။ အာဆဵုရေသူ၊ သ္ၚိရတ်မူလ။” (လိက်ပဒုမဝတဳ) = “ဈေးအရပ်သို့ တန်းတန်းမတ်မတ်လျှောက်သွားရာ မူလရတနာဆိုင်­နေသော ကျောက်သွေးသမားကို သွားတွေ့မိ၏။”
,ရဲ (န) ၁။ အပေါင်းအဖော်။ သူငယ်ချင်း။/ “ရဲအဲနူကွာန်တေံ ကၠုၚ်ဝေၚ်သ္ၚိပိုဲရ။” = “ထိုရွာမှကျွန်တော့်သူငယ်ချင်း ကျွန်တော်တို့အိမ်လာလည်သည်။”/ ၂။ အစု။ အဖွဲ့။/ “ကွာန်ဒဇဲနွံမွဲကွာန် ပ္ဍဲကွာန်ဂှ် ဒဇဲၜါရဲနွံ။ မွဲမွဲရဲဂှ် ညးမသုန်ကၠံဟေၚ်။” (ဇ—၄၆၆။ အစွောံ။) = “လက်သမားရွာတစ်ရွာရှိ၏။ ထိုရွာ­ လက်သမားအစုနှစ်စုရှိ၏။ အစုတစ်စုစီ­ လက်သမားငါးရာစီရှိ၏။”/ ကောန်ရဲ = နောက်လိုက်။ တပည့်။ အဖွဲ့ဝၚ်။/ နာဲရဲ = အဖွဲ့ခေါင်းဆောင်။/ ၃။ အရပ်ဒေသတစ်ခုခုမှလူ။/ ရဲကွာန် = ရွာမှလူ။ ရွာသား။/ ရဲဍုၚ် = မြို့မှလာသူ။/ ရဲပလုၚ် = ရပ်ဝေးမှလာသောသူ။/ ၄။ လုပ်ငန်းတစ်ခုခုကို လုပ်ကိုင်သောသူ။/ ရဲဗ္ၚ = လယ်သမား။/ ရဲကၠအ်= ခြံသမား။
,ရဲကၠအ် (န) ခြံသမား။
,ရဲကွာန် (န) ရွာသား။
,ရဲခွာ (န) နောက်လိုက်။ ငယ်သား။
,ရဲဂူ (န) တောင်ယာလုပ်ကိုင်သူ။
,ရဲဇၞးပိုတ် (န) ဇနပုဒ်သား။
,ရဲဍုၚ် (န) မြို့သား။
,ရဲဒဒိုက်၊ ရဲတၠဒဒိုက် (န) ဒုက္ခသည်။
,ရဲပလုၚ် (န) ရပ်ဝေးမှလူ။
,ရဲဗ္ၚ (န) လယ်သမား။
,ရဲရး (န) တောအရပ်မှလူ။ တောသား။
,ရဲသ္ကအ် (န) သူငယ်ချင်းအပေါင်းအသင်း။
,ရဲသာ (န) ခရီးသွားသူ။
,ရော (စည်း) လဲ။ သလဲ။ သနည်း။ (အမေးသဘောဖြင့် ထောက်ပံ့သည့်စကားလုံး။)/ “မူသွရော။” = “ဘာဟင်းလဲ။”/ ‘ကၠုၚ်နူလဵုရော’ = ‘ဘယ်ကလာသလဲ။’
,ရောဂ (ပါ) (န) ရောဂါ။ နာခြင်း။
,ရောဂနိဒါန် (ပါသက်) (န) ရောဂါအကြောင်း။/ ပြကိုဟ်ရောဂနိဒါန် = ရောဂါအကြောင်းကို ပြဆိုသောကျမ်း။
,ရောဂန္တရကပ် (ပါသက်) (န) ရောဂါဘေးဆိုက်သောကာလ။ ရောဂန္တရကပ်။
,ရောမ (လိပ်သက်) (န) ရောမ။/ ဂကူရောမ = ရောမလူမျိုး။/ ဍုၚ်ရောမ = ရောမနိုင်ငံ။
,ရောရုဝ (ပါ) (န) ရောရုဝငရဲ။
,ရောဟိဏဳ၊ ရောဟိနဳ (သသက်) (န) ရောဟဏီကြယ်နက္ခတ်။/ “လျးရတ်တုပ်ဂ္ညိ၊ သၞံၚ်ရောဟိနဳ။” (လိက်ဗောဓိသတ်စှ်။ ပဏ္ဍိတ။) = “ရတနာရောၚ်သည် ရောဟဏဳကြယ်နက္ခတ်နှင့်တူ၏။”/ “သမးအရံၚ်၊ သၞံၚ်ရောဟိဏဳ။” (လိက်သၟိၚ်ဇဲယဒတ္တ) ၊ရဴ၊
,ရဴ (န) ၁။ ထည့်စရာခြင်းတောင်း။/ “စာၚ်ဂှ် ညးစုတ်လဝ်ပ္ဍဲရဴရ။” = “ကြက်ကို ခြင်းတောင်းထဲတွင် သူထည့်ထားသည်။”/ ၂။ ကစားသောခြင်း။/ တေအ်ရဴ = ခြင်းခတ်ကစားသည်။/ (ဝိ) ကဲ့သို့။ သဖွယ်။ လို။/ ရဴဒေဝတဴ = နတ်ဒေဝါကဲ့သို့။/ “ရဴမဂွံအာစိုပ်ဍုၚ်သွဝ်ကီု မဒှ်ပ္ဍဲစိုတ်။”= “နတ်ပြည်ကိုရောက်သွားသကဲ့သို့ စိတ်ထဲတွင်ခံစားရသည်။”
,ရဴဂဴ (ကြိ) ရိုသေသည်။ လေးမြတ်သည်။/ “ကောန်တံဒးရဴဂဴမိကဵုမၜါရ။” = “သားသမီးများသည်မိဘနှစ်ပါးကို ရိုသေလေးမြတ်ရပါမည်။”/ “ဂစေံသဝ်ရဝကာ်၊ ကၞုဲ၊ စိၚ် ညးပိပဒတဴ သီုညးပိဟွံရဴဂဴ ဟွံအဲပရဲ—။” (ဇ—၃၇။ အစွောံ။) = “ခါ၊ မျောက်၊ ဆင်ဟူကုန်သော သုံးယောက်ကုန်သော အဆွေခင်ပွန်းတို့သည် နေကုန်၏။ — အချင်းချင်း ရိုသေတုံ့ဝပ်ခြင်းမရှိကုန်။” (ညောင်ကန်)/ “သၟိၚ်ရှ်ေသှ်ေရဴဂဴအဲဂှ် ဟိုတ်နူဓဝ်သဳလအဲမ္ဂးဟာ” ဗမၞးချပ်။ (ဇ—၃၆၂။ အစွောံ။) =“မင်းသည် ငါ့ကို ရိုသေလေးမြတ်သည်မှာ ငါ၏သီလတရားကြောင့်ပေလော။”
,ရဴဝွံ (ကြိဝိ) ဤကဲ့သို့။
,ရဴသာ်ဂှ် (ကြိဝိ) ထိုကဲ့သို့။
,ရဴသာ်ဝွံ (ကြိဝိ) ဤကဲ့သို့။
,ရံ၊ ရမ် (န) ငမြ်း။/ “ဂွံဖျေံထဝ်ကဵုကျာ် ဒးဒက်ရမ်ရ။” = “ဘုရားကိုရွှေချရန် ငြမ်းချည်ရမည်။”
,ရံပြ၊ ရမ်ပြ (န) ငမြ်း။/ “သၟိၚ်ကဵုဒက်ရံပြတုဲ ဗွဲမသာၚဳဟေၚ် ဖျေံနၚ်ကၞုဲ (ဗောဓိသတ်) တုဲ—။” (ဇ—၄ဝ၇။ အစွောံ။) = “ငြမ်းဖွဲ့၍ ဖြည်းညင်းသာယာစွာ ဘုရားလောင်း (မျောက်မင်း) ကို သက်စေ၍—။” (ညောင်ကန်)
,ရး—၁ (သသက်) (န) တိုင်းပြည်။ တိုင်းနိုင်ငံ။/ “ဍုၚ်ပိုဲမိတ္ထဵုဝွံဂှ် ထပှ်ယောဇနာရောၚ်။ ရးဂှ် ပိကၠံယောဇနာရောၚ်။” (ဇ—၄၈၉။ အစွောံ။) = “မိဓိလာမြို့သည် ခုနစ်ယူဇနာရှိ၏။ တိုင်းနိုင်ငံအပိုင်းအခြားသည်ကား ယူဇနာသုံးရာရှိ၏။” (ညောင်ကန်)/ ၂။ (မြို့ပြဒေသမဟုတ်သော) တောနယ်ဒေသ။ ကျေးလက်ဒေသ။/ “ညးဒၟံၚ်ပ္ဍဲဍုၚ်ဟာ ပ္ဍဲရးဟာ။” = “သူမြို့မှာနေသလား၊ တောနယ်မှာနေသလား။”
,ရး—၂ (ကြိ) ၁။ စဲသည်။ ရပ်သည်။/ ‘ဖျာရးအာရ။’ = ‘ဈေးကွဲသွားပြီ။’/ ဝိုၚ်ရးအာ = လူစုကွဲသွားသည်။ ဝိုင်းကွဲသွားသည်။/ ၂။ (ရေတွင်းကို) ရေထွက်ပိုကောင်းလာစေရန် ရေတွင်းမှရေကို ကုန်ခန်းအောင်ထုတ်ပစ်ပြီး ပြုပြင်သည်။ ဆယ်သည်။/ “ဒြဟတ်ဍာ်သ္ဂောံထတ် ပိုဲရးလဝ်ကမၠိုၚ်ဂှ်ရ။” = “ရေထွက်အားကောင်းလာအောင် ထိုရေတွင်းကို ငါတို့ဆယ်ထားသည်။”
,ရးကး၊ ရးသကး (န) ၁။ တိုင်း။ ကျေးလက်တောရွာ။ ဇနပုဒ်။/ “ညးပဒတဴပ္ဍဲဘာဇေတဝန်တံဂှ်ကီုညးပဒတဴပ္ဍဲရးကးတံဂှ်ကီု—။” (ဇ—၂၄ဝ။ အစွောံ။) = “ဇေတဝန်ကျောင်းတော်­ နေကုန်သောသူတို့သည်၄င်း၊ တိုင်းအလုံး­ နေကုန်သောသူတို့သည်၄င်း။” (ညောင်ကန်)/ “(ကောဂှ်) လောဘဇၞော်တိုန်အာတုဲ ရးကးဖအိုတ်တံဂှ် အာတ်ကေတ်ကဵုဒေံရ။” (ဇ—၄၆၇။ အစွောံ။) = “မင်းသားသည် မရောင့်ရဲနိုင်ဘဲ တဏှာရမ္မက်နှိပ်စက်သဖြင့် ဇနပုဒ်အလုံးစုံကို (ညီတော်မင်းအား) တောင်း၏။” (ခေတ်မီငါးရာငါးဆယ်။ အရှင်ဓမ္မဿာမီဘိဝံသ။)/ “သၟိၚ်ဣန်တုန်ဂှ် — ဗဂူဖျေံဗြဲအလုံရးသ္ကးဂမၠိုၚ်အိုတ်ရ။” (ဇ—၅၂၆။ အစွောံ။) = “သိကြားမင်းသည်လည်း — အလုံးစုံသောတိုင်း­ မိုးကိုရွာစေ၏။” (ညောင်ကန်)/ ၂။ နယ်စွန်နယ်ဖျား။ ရပ်စွန်ပြည်နား။/ “ကာလဂှ် ပ္ဍဲဍုၚ်ရာဇာဓနဳ လ္ၚုအာရ။ သတ္တအ်ဒဴအာ ပ္ဍဲရးသကးတုဲ တန်ဒၟံၚ်ရ။” (ဇ—၇၇။ အစွောံ။) = “ထိုအခါ မင်းနေပြည်တော်­ဆိတ်၍ လူအပေါင်းတို့သည် ရပ်စွန်ပြည်နားသို့သွား၍ နေကုန်လတ္တံ့။”/ ဍုၚ်ကွာန်ရးကး၊ ဍုၚ်ကွာန်ရးသ္ကး = ပြည်ရွာဇနပုဒ်။ ပြည်ရွာတိုင်းကား။
,ရးဍုၚ် (န) နိုင်ငံ။ တိုင်းပြည်။/ “ဗ္ဒဟ်လဝ်လိက်မွဲ၊ ပ္ဍဲရးဍုၚ်မန်။” (လိက်ပုညကာရဳ) = “မွန်နိုင်ငံ­ စာတစ်အုပ်ကို ရေးဖွဲ့ထား၏။”/ ‘ဍုၚ်ရး’ နှင့်အတူတူ။
,ရးဒုဟ် (ကြိ) အပြစ်မှလွှတ်သည်။ အပြစ်မယူ။ ဗွေမယူ။/ “မိတ်သဟာဲၜါတံဂှ် ကယာန်စာန်စးညးသ္ကအ်ညိတုဲ ကလေၚ်ရးဒုဟ်ညးသ္ကအ်ပၠန်ရ။” = “မိတ်ဆွေနှစ်ဦးတို့ အနည်းငယ်ငြင်းခုံဆန့်ကျင်ကြပြီးနောက် အချင်းချင်း ပြန်လည်အပြစ်လွှတ်ကြပြန်သည်။”
,ရးနိဂီု (န) တိုင်းနိုင်ငံ။/ “ယြဴပူဂဵုမွဲ မၞုံပညာတြံၚ်ဍုဟ်ညိတုဲဂှ် ဂွံစဳရေၚ်ဍုၚ်ကွာန်ရးနိဂီုမ္ဂး — ဍုၚ်ကွာန်တံဂှ် မဂွံဇၞော်မောဝ်ဂၠိုၚ်တိုန်အာရောၚ်။” (ဇ—၅၂၈။ အစွောံ။) = “ပညာရင့်ကျက်သောသူသည် မြို့ရွာတိုင်းနိုင်ငံကို စီရင်ရသည်ရှိသော ထိုမြို့ရွာတို့သည် တိုးတက်ကြီးပွားကုန်၏။”
,ရးပး (န) ကျေးလက်ဒေသ။/ “ရးပးနဳဂီု၊ အိုဿီုဍုၚ်တွာန်။” (လိက်မေဃကောန်ဒြာဲ) = “ကျေးလက်ဒေသ၊ နိဂုံးနှင့် အလုံးစုံသောမြို့ရွာများ။”/ “ညးဂြိုပ်ရးပး၊ ညးဍုၚ်ရးဗ္ၚ။” (လိက်ပဒုမဝတဳ)/ “ရးပးဍုၚ်ကွာန်၊ ထာန်မနုဿ။” (လိက်ကကၠာ်။ ကောန်ဍး။) = “လူ့အရပ်ဋ္ဌာနဖြစ်သောကျေးလက်မြို့ရွာ။”
,ရးမည (န) မွန်တိုင်းနိုင်ငံ။ ရာမညတိုင်း။/ “ဟီုလဝ်လိက်မွဲ၊ ပ္ဍဲရးမည။ လိက်ထေအနန်၊ ကမၠောန်ဗုဒ္ဓ။” (လိက်ထေအနန်) = “ရာမညမွန်တိုင်းနိုင်ငံ­ ပျို့တစ်စောင်အကြောင်း ဆိုထား၏။ ထိုပျို့ကား ဗုဒ္ဓမြတ်စွာဘုရား၏အလုပ်အကျွေး အရှင်အာနန္ဒာမထေရ်အကြောင်းဖြစ်၏။”
,ရက္ခိတ (ပါ) (နဝိ) စောင့်ရှောက်သော။
,ရာ် (န) (လယ်တောယာတောရှိ) ယာယီတဲအိမ်။
,ရုက္ခ (ပါ) (န) သစ်ပင်။
,ရုက္ခဇဵု (ပါသက်) (န) ရုက္ခစိုးနတ်။/ “အကာသဇဵု၊ ဘုမ္မဇဵုပၠန်။ ရုက္ခဇဵုကီု၊ သီုဟေမဝန်။” (လိက်သောဝိန်ဇဲယ။ မာံရောဂေါ။) = “အာကာသစိုးနတ်၊ ဘုမ္မစိုးနတ်နှင့် ဟိမဝန္တာမှရုက္ခစိုးနတ်များ။”
,ရုက္ခဗေဒ — (ပါ) (န) အပင်များနှင့်ပတ်သက်သော သိပ္ပံပညာရပ်၊ ရုက္ခဗေဒ။
,ရေက် (ကြိ) လှီးဖြတ်သည်။/ ရေက်ဖျုန် = အသားလှီးသည်။/ ရေက်သော် = ဆံပင်ဖြတ်သည်။
,ရော် (ကြိ) (ကျေးဇူး) ဆပ်သည်။/ “ဂုန်အစာဇၞော်၊ ပိုဲသၟိက်ရော်ရ။” (လိက်သၚ်ဂဒါ။ သဳလဝန္တ။) “ကြီးမားသောဆရာ့ကျေးဇူးကို ငါတို့ဆပ်လိုပါ၏။”
,ရော်ဂတှ် (ကြိ) အကြွေးဆပ်သည်။ အကြွေးလျော်သည်။
,ရော်ဂုန်၊ ရော်ဂုဏ် (ကြိ) ကျေးဇူးဆပ်သည်။/ “ၜိုန်ကျာ်တြဲဇမၞးမာကီုလေဝ် တိုန်တွံဓဝ်ရော်ဂုန်မိဒဵုဍုၚ်သွဝ်တေံရောၚ် ဟွံသေၚ်ဟာအဴ။” (ဇ—၅ဝ၉။ အစွောံ။) = “မာရ်ကိုအောင်နိုင်သော မြတ်စွာဘုရားသည်ပင်လျှင် အမိကျေးဇူးကိုဆပ်ရန် နတ်ပြည်သို့တိုၚ် တက်၍တရားဟောတော်မူသည်မဟုတ်လော။”
,ရံက် (န) စက်သီး။ ရေငင်စက်။
,ရံက်ရာ် (ကြိ) ချည့်နဲ့သည်။ မကြံ့ခိုင်ယိုင်သည်။/ “ခန္ဓဇကု၊ ဝွံဟွံဗိုန်ဂၠိ။ ဒဒိုက်နာနာ၊ ဇရာကၠုၚ်ဖိ။ ကာယရံက်ရာ်၊ ကွာ်တၚ်က္ၜံၚ်ဂိ။” (သုဓမ္မဒေသနာ။ ဂရိုက်သာံ။) = “ဤခန္ဓာကိုယ်သည်မတည်မမြဲ။ ဒုက္ခအမျိုးမျိုးနှင့် ဇရာလာ၍ ဖိစီးနှိပ်စက်၏။ ကာယမခိုင် ယိုင်ချည့်နဲ့၍ လျှောက်သောအခါ ဒူးဆစ်နာ၏။”
,ရိုက်—၁ (န) အိတ်။/ ရိုက်သ္ၚု = ဆန်အိတ်။
,ရိုက်—၂ (ကြိ) ပေါများသည်။/ “အခိၚ်လၟုဟ် ပ္ဍဲဖျာကြုက်ရိုက်ဒၟံၚ်ရ။” = “ယခုအချိန်တွင် ဈေး­သရက်သီးပေါများနေသည်။”
,ရိုက်ကာန် (န) ဂုန်နီအိတ်။
,ရိုက်ဖံ (ကြိ) စည်တီးသည်။ စည်လည်သည်။/ ရိုက်ဖံဇမၞး = အောင်စည်အောင်မောင်းတီးသည်။/“(သၟိၚ်ပဿိုန်) ရိုက်ဖံဇမၞး ဇက်အာရ။” (ဇ—၂၈၃။ အစွောံ။) = “ကောသလမင်းသည် အောင်စည်တီး၍ စစ်ချီထွက်၏။”/ “(သၟိၚ်ဂှ်) ဗလိဒေဝတဴဇြဲဂှ်တုဲ ရိုက်ဖံဇမၞးတုဲ ဇက်အာဗတိုက်ဍုၚ်တက္ကသဵုဂှ်ပၠန်ရ။” (ဇ—၃၅၃။ အစွောံ။) = “ထိုမင်းသည် ညောင်စောင့်နတ်ကို ပူဇော်ပသပြီးလျှင် အောင်စည်အောင်မောင်းတီးလျက် တက္ကသိုလ်ပြည်ကိုတိုက်ရန် ချီတက်သွား၏။”
,ရၚ် (ကြိ) ဆောင်သည်။/ ရၚ်ဏာ = ဆောင်ယူသွားသည်။ ပို့ဆောင်သည်။ (ပါဠိ—နေတိ)/ ရၚ်နၚ် = ဆောင်ယူလာသည်။ (ပါဠိ—အာနေတိ/ အာဟရတိ)
,ရၚ်တာ (န) သစ်သားချောင်းအချွန်များဖြင့် ပြုလုပ်ထားသောခံတပ်။
,ရၚ်တၠုၚ်၊ ရေၚ်တၠုၚ် (ကြိ) ၁။ ဆောင်သည်။ ယူဆောင်သည်။ ယူလာသည်။ (to convey| to bring)/ “အဲဍိက်ရၚ်တလုၚ်သစ္ဆုရအဴ။” (ဇ—၄၈၈။ အစွောံ။) = “တပည့်တော်သည် သစ်သီးတို့ကို ဆောင်ပါအံ့။”/ “တၠသ္ၚိဗှ်ေဂှ် တိတ်အာကုကွဳယာန်တုဲ အာရၚ်တၠုၚ်နၚ်ဗြဴသ္အာၚ်မွဲ နူကွာန်မဟိမုမွဲတေံရယး။” (ဇ—၄၄၆။ အစွောံ။) = “နင့်လင်သည် လှည်းယာဉ်ဖြင့်သွား၍ ဤမည်သောရွာမှ အခြားမိန်းမတစ်ယောက်ကို ယူဆောင်လာသတတ်။”/ “ဇုတ်အ္စာမရၚ်တၠုၚ်နၚ်တံဂှ် (ဇုတ်ကောန်အဲဟွံသေၚ်) ၊ မဒှ်ဇုတ်တၞဟ်သ္အာၚ်ရောၚ်။” (ဇ—၄၄၇။ အစွောံ။) = “ဆရာယူလာသောအရိုးတို့သည် အကျွန်ုပ်သား၏အရိုးမဟုတ်။ အခြားတစ်ပါးသောအရိုးသာတည်း။”/“ကျာ်တြဲရၚ်တၠုၚ်ဇာတ်အတိက်။” = “မြတ်စွာဘုရားသည် အတိတ်ဇာတ်ကို ဆောင်တော်မူ၏။”/ ၂။ ဆောင်ကြဉ်းသည်။ ဖြစ်ပေါ်စေသည်။ (to bring about)/ “ညးဟွံဂွံရၚ်တၠုၚ်ဒတုဲမြမောဝ်ဇကုဂှ် ဟွံဂပ်ဂဝ်ဇိုန်ကဵုဒတုဲမြမောဝ်ကဵုညးကီုရ။” (ဇ—၂၂၃။ အစွောံ။) = “မိမိ၏အကျိုးစီးပွားကို မဆောင်ကြဉ်းသောသူအား မိမိကလည်း သူ့အကျိုးစီးပွားကို မပေးသင့်ပါ။”/ “ကုသဵုဂှ်ရၚ်တၠုၚ်ကဵုတုဲ — ပိုန်ကၟိန်ဍုၚ်ဒဒှ်ဨကရာတ်ဂှ် ဗွဲသွာ (ကလိဂွံရောၚ်) ။” (ဇ—၂၈၄။ အစွောံ။) =“ထိုကုသိုလ်ကောင်းမှုက ဆောင်ကြဉ်းပေးသဖြင့် တိုင်းပြည်စည်းစိမ် မင်းဧကရာဇ်အဖြစ်ကို အလွယ်တကူရရှိ၏။”/ “ယြဴညးမွဲ မမၚ်မွဲဓဝ်မ္ဂး ဓဝ်ဂှ်ဟေၚ် မမၚ်မွဲညးဂှ်ရ။ ပွမမၚ်မွဲဓဝ်ဂှ် ဍေံတံရၚ်တၠုၚ်ကဵုတသိုက်စိုတ် တသိုက်ကာယရ။” (ဇ—၄၄၇။ အစွောံ။) = “တရားစောင့်သောသူအား ထိုတရားက ပြန်၍စောင့်ရှောက်၏။ တရားကိုစောင့်ရှောက်ခြင်းက စိတ်၏ချမ်းသာခြင်းကိုယ်၏ချမ်းသာခြင်းကို ဆောင်ကြဉ်းပေး၏။”/ “ဓဝ်မဂွံလ္ၚတ်မၚ်မွဲလဝ်ဒးရးဂှ် မရၚ်တၠုၚ်ကဵုတသိုက်သွဝ်တရဴဘုံတေံရ။” (ဇ—၅၁ဝ။ အစွောံ။) = “ကောင်းစွာဆည်းပူးစောင့်ရှောက်အပ်သောတရားသည် နတ်ဘုံခြောက်ထပ်­ဖြစ်သော နတ်စည်းစိမ်ချမ်းသာကို ဆောင်ကြဉ်းပေး၏။”/“ရၚ်တၠုၚ်ကဵုဒတုဲမြမောဝ်ဂကူမန်။” = “မွန်လူမျိုး၏အကျိုးစီးပွားကို ဆောင်ကြဉ်းပေးသည်။”
,ရၚ်ပ္တိတ် (ကြိ) ထုတ်နုတ်သည်။ (ပါဠိ—ဥဒ္ဓရတိ)
,ရၚ်သ္ကံ၊ ရေၚ်သ္ကအ် (ကြိဝိ) အချင်းချင်း။/ “ကောကဵုဒေံၜါဂှ် သ္ဍိုက်ဆာန်တဴရၚ်သ္ကအ် ဗွဲမလောန်ရ။” = “ညီအစ်ကိုနှစ်ယောက်တို့သည် တစ်ဦးနှင့်တစ်ဦး အချင်းချင်း အလွန်ချစ်ခင်ကြသည်။”
,ရာၚ် (ကြိ) ပွင့်သည်။/ ပ္ကဴရာၚ် = ပန်းပွင့်သည်။/ “ဒကှ်သ္အာၚ်ရာၚ်တုဲ ဇြအာအိုတ်ရ။ ဒကှ်ဇၞော်မွဲဍောၚ်ဂှ် ဟွံဂွံရာၚ် ဟွံဂွံဇြဟေၚ်မဒှ်။” (ဇ—၃၈ဝ။ အစွောံ။) = “အခြားသောကြာတို့သည်ပွင့်ကုန်၍ နွမ်းကုန်၏။ ထိုကြာပွင့်ကြီးသည်ကား မပွင့်မနွမ်းဘဲရှိ၏။”
,ရာၚ်ဆာဲ (ကြိ) ၁။ တင့်တယ်သည်။/ “ပ္ဍဲအဒေါဝ်သၟန်သၞံၚ်နက်သတ်ဂမၠိုၚ်ဂှ် သၟိၚ်ဂိတုရာၚ်ဆာဲတဴဗွဲမလောန်ရ။” = “ကြယ်နက္ခတ်တာရာများ၏အလယ်­ လမင်းသည် အလွန်တင့်တယ်၏။”/“ဓဝ်သဳလနွံတုဲ ကလောဂမၠိုၚ် မဒးသ္ဍိုက်မၠိုက်ရ။ ပ္ဍဲဒေါဝ်မိတ်ပြဝါဂမၠိုၚ် မရာၚ်ဆာဲတဴရ။” (ဇ—၂၉ဝ။ အစွောံ။) = “သီလရှိသောသူကို အဆွေအမျိုးတို့သည်လည်း ချစ်အပ်သည်ဖြစ်၏။ သီလရှိသောသူသည် အဆွေခင်ပွန်းတို့­လည်း တင့်တယ်၏။” (ညောင်ကန်)/ ၂။ သာယာဝပြောသည်။ သာယာစည်ပင်သည်။/ “တၠပညာနွံပ္ဍဲဍုၚ်တွာန်ဂှ် (ဍုၚ်) တွာန်ဂှ် ရာၚ်ဆာဲထဳတိတန်ကြန်ရောၚ်။” (ဇ—၃ဝ၁။ အစွောံ။) = “ပညာရှိတို့နေသောမြို့ရွာသည် သာယာစည်ပင်၍ တည်တံ့ခိုင်မြဲ၏။”
,ရာၚ်ဗဂါ (ကြိ) ပွင့်လန်းသည်။/ “ပ္ကဴဒကှ်မၞုံကဵုခၟောံမကြံၚ် ဂွံဆဵုကေတ်လျးသၟိၚ်တ္ၚဲတုဲ မပံက်ထာၚ်ရာၚ်ဗဂါတဴရ။” (သၚ်္ခါရဘေဒနဳ။ ဝိန္ဒသာရ။) = “ရင့်သောအၚုံရှိသောကြာပန်းသည် နေမင်း၏ရောင်ခြည်ကို တွေ့ရသောအခါ ပွင့်ချပ်ကိုဖွင့်၍ ပွင့်လန်းလာ၏။”
,ရာၚ်လဒအ် (ကြိ) ပွင့်သည်။ ပွင့်လန်းသည်။/ “ထမောံပ္ကဴဂပ်ဂဝ်ထေက်ကဵုရာၚ်ဂှ်လေဝ် ကဵုပံက်ထာၚ်ရာၚ်လဒအ်ရ။” (သုဓမ္မဒေသနာ။ ဂရိုက်သာံ။) = “ပွင့်သင့်သောပန်းဖူးၚုံများကိုလည်းပွင့်ချပ်ကိုဖွင့်လျက် ပွင့်လန်းစေကုန်၏။”
,ရာၚ်သူ (ကြိ) ပွင့်လန်းသည်။/ “စမ္ပာစမ္ၚာ၊ သ္ဂာရာၚ်သူ။” (လိက်ကောန်သၟိၚ်ပိ။ မာံခစုန်အံက်) = “တရုတ်စကား၊ စကားဖြူ၊ ရင်ခတ်တို့သည် ပွင့်လန်းကြကုန်၏။”
,ရာၚ်အူ (ကြိ) ပွင့်လန်းသည်။/ “စမ္ပာစမ္ၚာ၊ သဂါရာၚ်အူ။” (လိက်ရတနပဇ္ဇောတ) = “တရုတ်စကားပန်း၊ စကားဖြူပန်း၊ ရင်ခတ်ပန်းတို့သည် ပွင့်လန်းကုန်၏။”
,ရိၚ် (ကြိ/နဝိ) စပ်သည်။—သော။ စပ်သောအရသာရှိသည်။—သော။/ ရိၚ်မြေက် = ငရုတ်သီးစပ်သည်။
,ရိၚ်ကတၚ် (ကြိ/နဝိ) ခါးသီးသည်။—သော။/ ဒဒိုက်မရိၚ်ကတၚ် = ခါးသီးသောဒုက္ခ။/ “ပူဂဵုမဒေပ်စၞာဲဝွံ လိုက်ကီု ပလိုက်ကီု ဒဒိုက်မရိၚ်ကတၚ်သ္အဵုသ္အာ်ဟေၚ် မဒးကလိဂွံရ။” (ဇ—၃၈။ အစွောံ။) = “ကောက်ကျစ်စဉ်းလဲသောသူသည် ပစ္စုပ္ပန်­၄င်း တမလွန်­၄င်း ခါးသီးကြမ်းကြုတ်သောဒုက္ခကို ကြုံတွေ့ရ၏။”/ “—ဗွဲကြဴ သီုဒဒိုက်မရိၚ်ကတၚ်ဂှ် ဗှ်ေမဒးဒှ်ရ။” (ဇ—၉၁။ အစွောံ။) = “နောၚ်­ ခါးသီးသောဒုက္ခကို သၚ်ခံစားရလတ္တံ့။”/ “ပ္ဍဲဒဒိုက်နရက်မရိၚ်ကတၚ်ဂှ်မစှ်ေစိန်ဒၟံၚ်ရ။” (ဇ—၁၉၄။ အစွောံ။) = “ငရဲ၏ခါးသီးပြင်းထန်သောဆင်းရဲ­ ကျခံနေရ၏။”
,ရုၚ် (န) ရုံ။ ရုံး။/ ရုၚ်စိၚ် = ဆင်ထားသောရုံ။ ဆင်တင်းကုပ်။/ ရုၚ်ဒါန် = အလှူတင်းကုပ်။/ရုၚ်သ္ဂုတ်သွာတ်အမှု = အမှုဆုံးဖြတ်ရာရုံး။/ တိုန်ရုၚ် = ရုံးတက်သည်။/ ဂ္ဇအ်ရုၚ် = ရုံးထိုၚ်သည်။/ (ကြိ) (သင်္ကန်း) ရုံသည်။/ ရုၚ်သ္ၚာ = သင်္ကန်းရုံသည်။
,ရုၚ်စမုက် (န) တရားဆုံးဖြတ်ရာအရပ်။ တရားရုံး။/ “ဟိုတ်ဂဗုတ်ဟွံမွဲတုဲ သၟိၚ်အမာတ်တံ ဂဇအ်ဒၟံၚ်ပ္ဍဲရုၚ်စမုက်ဂှ် နူဂယးဒဵုကဵုတ္ၚဲမသဝ်အာဂှ် ဗၞတ်ညးမွဲကီု မဒုၚ်စဳရေၚ်အမှုမ္ဂးဂှ် ဟွံဂွံသက်က်ရ။” (ဇ—၁၅၁။ အစွောံ။) = “အမှုအခင်းမရှိသဖြင့် အမတ်တို့သည် တရားဆုံးဖြတ်ရာအရပ်­ နံနက်မှသည် နေဝင်သည့်တိုင် နေကုန်သော်လည်း တစ်ယောက်သောသူမျှ အမှုတိုင်ကြားခြင်းမရှိ။”/ “ပ္ဍဲရုၚ်စမုက်သ္ဂုတ်သွာတ်အမှုဂှ်—။” (ဇ—စန္ဒကုမာ။ အစွောံ။) = “အမှုဆုံးဖြတ်ရာတရားရုံး­—။”/ “စိုပ်ရုၚ်စမုက်၊ လ္ဂူမုက်ရာဇာ။” (လိက်ဗောဓိသတ်စှ်။ ပဏ္ဍိတ။)
,ရုၚ်စာ (န) ၁။ မင်းအရာရှိရုံး။ အစိုးရရုံး။/ အရေဝ်ဘာသာရုၚ်စာ = ရုံးသုံးဘာသာစကား။/ ၂။တရားရုံး။ တရားဆုံးဖြတ်ရာရုံး။ ရုံးပြၚ်ကနား။/ “ပ္ဍဲပသာ်ဗိုန်၊ ဒးတိုန်ရုၚ်စာ။” (လောကသိဒ္ဓိ။အစွောံ။) = “ကဆုန်လတွင် မလွဲမသွေ ရုံးပြင်ကနားတက်ရမည်။”/ “သွေက်ဇဵုဒှ်ကယျာန်၊ ဒးတိုန်ရုၚ်ဋ္ဌာန်စာ။” (လောကသိဒ္ဓိ။ အစွောံ။) = “ငြင်းခုံခိုက်ရန်ဖြစ်၍ ရုံးပြင်ကနားတက်ရလိမ့်မည်။”/ ‘နာဲစာ’ (န) လည်းရှု။
,ရုၚ်ဒါန် (န) အလှူတင်းကုပ်။/ “(ပ္ဍဲ) ပန်ဒိုဟ်ဍုၚ်ဂှ် ရုၚ်ဒါန်ပန်၊ ဒေါဝ်ဍုၚ် ရုၚ်ဒါန်မွဲ၊ ပ္ဍဲမုက်သ္ၚိ ရုၚ်ဒါန်မွဲ (သိုၚ်ခၞံလဝ်) ။” (ဇ—၃၄ဝ။ အစွောံ။) = “မြို့တံခါးလေးမျက်နှာတို့­ အလှူတင်းကုပ်လေးခု၊ မြို့လယ်­ အလှူတင်းကုပ်တစ်ခု၊ မိမိအိမ်တံခါး­ အလှူတင်းကုပ်တစ်ခု ဆောက်လုပ်ထား၏။”
,ရုၚ်ဗစာ (န) တရားရုံး။ တရားဆုံးဖြတ်ရာရုံး။/ “အမာတ်မသုန် မဂိုၚ်ကေတ်ကွေတ်မုတ်တံဂှ် သၟိၚ်ကဵုစဳရေၚ်ဂဗုတ် ပ္ဍဲရုၚ်ဗစာရ။” (ဇ—၅၂၈။ အစွောံ။) = “မှားယွင်းသောအယူရှိသော အမတ်ငါးယောက်တို့ကို မင်းသည် တရားရုံး­ အမှုကိုစီရင်စေ၏။”/ “မၞိဟ်မွဲဂှ် သၞောဝ်ဍေံဇၞးရောၚ်။ သေနာပတိကယကၠေံအမှုဍေံတုဲ ဍေံပၚ်ယဵုကေတ်တဲၜါတုဲ ဍေံတိတ်အာနူရုၚ်ဗစာဂှ်တုဲ ဍေံဂတေဝ်ယာံတဴရ။” (ဇ—၂၂ဝ။ အစွောံ။) = “တစ်ယောက်သောလူသည် တရားနိုင်ရမည့်သူဖြစ်၏။ ၄င်း၏အမှုကို သေနာပတိက အရှုံးဆုံးဖြတ်လိုက်၏။ ထိုသူသည် လက်တို့ကိုမြှောက်လျက် တရားရုံးမှထွက်၍ ငိုကြွေး၏။”/ ‘နာဲဗစာ’ (န) လည်းရှု။
,ရုၚ်အမှု (န) တရားရုံး။ အမှုအခင်းဆုံးဖြတ်ရာရုံး။
,ရေၚ် (ကြိ) အတန်းလိုက်ဖြစ်အောင်စီသည်။ တန်းစီသည်။ စီထားသည်။/ “ဗၞတ်စိၚ်ကၠံဟေၚ်တိတ်ရေၚ်ပတန်လဝ်တုဲ—။” (ဇ—၁၆၃။ အစွောံ။) = “တစ်ရာသောဆင်တို့ကို ထုတ်၍စီတန်းထား၏။”/ “ထးထဝ်ရေၚ်မတ် မၞုံၚုဟ်ထဝ်မွဲလက်။” (ဇ—၂၆ဝ။ အစွောံ။) = “ကျောက်သံပတ္တမြားစီခြယ်ထားသော အဘိုးတစ်သိန်းထိုက်သောရွှေခွက်။”
,ရေၚ်ကာန်၊ ရၚ်ကာန် (ကြိ) ပေါင်းဖက်သည်။ အတူနေသည်။ အတူယှဉ်တွဲသည်။/ “သီုညးၜါသမ္ဘာကဵုတၠသ္ၚိ သၟဟ်သၟန်ရေၚ်ကာန်တဴ အဓါန်မလအ်ကာဖာတုဲ—။” (ဇ—၁၉၄။ အစွောံ။) =“ထိုနှစ်ယောက်ကုန်သော လင်မယားတို့သည်လည်း ကာလရှည်မြင့်စွာ အညီအညွတ် နှစ်ကိုယ်တစ်စိတ်ဖြင့် ပေါင်းဖက်နေကြကုန်၏။”/ ‘မၠေအ်ဒးရေၚ်ကာန်ဂှ်လေဝ် ဒဒိုက်မွဲ။’ (ဇ—၂၂၃။ အစွောံ။) = ‘မချစ်မနှစ်သက်သောသူနှင့် အတူနေပေါင်းဖက်ရခြင်းတည်းဟူသောဒုက္ခ။’/ “က္ဍုဟ်ဒးရေၚ်ကာန်၊ ဆာန်ဒးသာဲခြာ။” (လိက်ခၠေဝ်ရော်ဂုန်မိ) = “မုန်းလျက် ပေါင်းဖက်ရသည်၊ ချစ်လျက် ကွဲကွာရသည်။”/ “ယွံဂၞကျာ်၊ — ပ္ဍဲတ္ၚဲဝွံဂှ် ၝောံစဴစိုပ်တ္ၚဲဂၠုလောန်။ မူရဴဂကောံညးမွဲၝောံသ္ဍိုက်ဆာန်ရေၚ်ကာန်ရော” သၟိၚ်ဂး။ (ဇ— ၅၁၉။ အစွောံ။) = “မိဖုရား၊ ဤယနေ့­သင်သည် အလွန်မိုးချုပ်မှ ပြန်ရောက်၏။ အဘယ်သူနှင့်တကွ သင်ချစ်ကြင်နာပေါင်းဖက်လေသနည်း။”/ “ကာလဒးသဘၚ်ပေဲါ တၠအဲကဵုအဲရၚ်ကာန်အာဂှ် ညးညာတ်—။” (ဇ—မဟောဟ်သဓ။အစွောံ။) = “ပွဲသဘင်အခါကျရောက်၍ အရှင်နှင့်ကျွန်ုပ် အတူယှဉ်တွဲသွားကြစဉ် သူတကာတို့မြင်သော်—။”/ “တြုံတအ်တုန်ကၠာ၊ ဝါစာဂလာန်။ ဖျုၚ်လဝ်သာဲက္တောဝ်၊ အေၚာဝ်မဆာန်။ ပိုဲဗြဴပ္တေဟ်ညး၊ တုဲဒးရေၚ်ကာန်။” (လိက်နဲယသမုဒ္ဒြဳ။ အစွောံ။) = “ယောကျာ်းတို့သည် စကားကောင်းလှ၏။ ချစ်ဟန်ပြု၍ နားမှာပျားသကာလောင်း၏။ ငါတို့မိန်းမသားတွေမှာ ယုံပြီးလျှင်ပေါင်းဖက်ရ၏။”/ “ပသ္ဂောံရေၚ်ကာန်၊ မံၚ်မွဲဟာန်ရော။” (လိက်မေဃသန်) = “ဘယ်သောအခါပေါင်းဖက်၍ အတူနေရအံ့နည်း။”
,ရေၚ်တၠုၚ် (ကြိ) ‘ရၚ်တၠုၚ်’ ရှု။
,ရေၚ်ပၞာန် (ကြိ) (စစ်တိုက်ရန် အဆင်သင့်အနေအထားဖြစ်အောင်) စီတန်းတပ်ဖြန့်သည်။/ “ကာလသၟိၚ်ၜါတိတ်ရေၚ်ပၞာန်တုဲဂှ်—။” (ဇ—၃ဝ၁။ အစွောံ။) = “မင်းနှစ်ပါးတို့သည် စစ်ထိုးကြရန်ထွက်၍ အဆင်သင့်အနေအထားဖြင့် စီတန်းတပ်ဖြန့်ပြီးသောအခါ—။”
,ရေၚ်ဗ္ဂာ (ကြိ) စီတန်းပြည့်နှက်သည်။/ “မှောင်မှတအ်ကီု၊ သီုဒဴဗညာ။ သဳကၠဳတဴဟေၚ်၊ ဂဇအ်ရေၚ်ဗ္ဂာ။” (လိက်ဝါရဝေါၚ်သ။ အစွောံ။) = “မောင်းမတို့သည်၄င်း မှူးကြီးမတ်ကြီးတို့သည်၄င်း စီတန်းပြည့်နှက်စွာ ထိုင်လျက်ခစားနေကြကုန်၏။”
,ရောၚ် (စည်း) (ကြိနောက်ဆက်) အနာဂတ်ကာလကိုပြသောစကားလုံး။/ ‘အဲအာရောၚ်။’ =‘ကျွန်တော်သွားမည်။/ (ဝါကျအဆုံးစကား) “အဲအာဆဵုညးရောၚ်။” = “သူ့ကို ကျွန်တော်သွားတွေ့မည်။”/ ၂။ ဝါကျ၏အဓိပ္ပါယ်ကို လေးနက်စေသောစကားလုံး။/ “တၠညးအံၚ်ဇဲယျဝွံ စိုတ်ဒြိုဟ်သ္ကာတ်ဒဇန်သဟာသဳလောန်သန် ဟွံဂိုဟ်လမျီုသက်သက်ရောၚ်။” (ရာဇာဝံသသံခိပ်။ အစွောံ။) = “သူ့ရှင်အောင်ဇေယျသည် အလွန်လျှင် ကြမ်းကြုတ်ရုန့်ရင်းရက်စက်၏။ အသက်တို့ကို လုံးဝမနှမြောတတ်။” (အံ့သြသည့်သဘော)
,ရံၚ် (ကြိ) ကြည့်သည်။/ တေတေံရံၚ်စမ် = ဟောဟိုမှာကြည့်စမ်း။/ အာရံၚ်မၞိဟ်ယဲ = လူနာကိုသွားကြည့်သည်။/ ရံၚ်လိက် = စာကြည့်သည်။
,ရံၚ်ကောန်ၚာ် (ကြိ) ကလေးကြည့်သည်။
,ရံၚ်စဗေဒၚ် (ကြိ) ဗေဒင်ကြည့်သည်။
,ရံၚ်စံၚ် (ကြိ) ကြည့်ရှုသည်။ စောင့်ရှောက်သည်။/ “အစာတရေံဝွံ ၜိုန်ညးဟွံဂွံစဒါန်အဲကီု ညးချပ်မၚ်မွဲရံၚ်စံၚ်ဒၟံၚ်အဲ” သၟိၚ်ချပ်။ (ဇ—၂၈၉။ အစွောံ။) = “ဆရာဟောင်းသည်တမူကား ငါပေးကမ်းသောဥစ္စာကို မစားရသော်လည်း ငါ့ကို ကြည့်ရှုစောင့်ရှောက်နေသေး၏” ဟုမင်းသည်ကြံ၏။/ “ဟွံကဵုအေၚ်ပ္ညဳ၊ ထေလွဳရံၚ်စံၚ်။” (လိက်ကာကဒိပ္ပ။ မဟာကြၚ်။) = “မထေရ်သည် ငါ့အားမၚတ်စေဘဲ မွေးမြူစောင့်ရှောက်၏။”
,ရံၚ်စိန်စိန် (ကြိ) စိန်းစိန်းကြည့်သည်။ စူးစူးစိုက်စိုက်ကြည့်သည်။
,ရံၚ်စၟဳ (ကြိ) မျှော်ကြည့်သည်။
,ရံၚ်ဒ္ၚေါဝ် (ကြိ) မှန်ကြည့်သည်။
,ရံၚ်မုက် (ကြိ) မျက်နှာကြည့်သည်။ မျက်နှာထောက်သည်။/ ‘သ္ၚဳမုက်’ နှင့်အတူတူ။
,ရံၚ်အကာဲ (ကြိ) အကဲခတ်သည်။ အရိပ်အခြည်ကြည့်သည်။
,ရိုၚ်—၁ (န) ရုံ။ တင်းကုပ်။/ ရိုၚ်စိၚ် = ဆင်ရုံ။ ဆင်တင်းကုပ်။/ ရိုၚ်ချေံ = မြင်းတင်းကုပ်။/“(သၟိၚ်စိၚ်) မံၚ်ဟွံမာန်ကွိုၚ်၊ အပ္ဍဲရိုၚ်ရ။” (လိက်ကောန်သၟိၚ်ပိ။ မာံခစုန်အံက်။) = “ဆင်မင်းသည် ညောင်းညာသည်ဖြစ်၍ တင်းကုပ်­မနေနိုင်။”
,ရိုၚ်—၂ (န) (ကျောက်၊ သစ်လုံး၊ သံစသည်ဖြင့် ပြုလုပ်ထားသော) တိုင်။ တိုင်လုံး။ တိုင်မ။/“သၟိၚ်ကဵုကၠောန်သ္ၚိပသဲ ခိုၚ်ဗိုန်ဇၞော်လှဲတုဲ မၞုံကဵုရိုၚ်ပန်ဒိုဟ် မတၟုဲတဴနပသဲသက်က်ရ။” (ဇ—၅၁ဝ။အစွောံ။) = “မင်းသည် ခိုင်ခံ့ကြီးကျယ်သောသံအိမ်ကို ဆောက်လုပ်စေ၏။ လေးဘက်­ရှိသောတိုင်လုံးတို့သည် သံအတိဖြင့်ပြီးကုန်၏။”
,ရိုၚ်—၃ (နဝိ) ရိုင်းသော။/ “ချေံဏအ် ရိုၚ်ဒၟံၚ်ရောၚ်။” = “ဤမြင်းရိုင်းနေသည်။”
,ရိုၚ်ဇိုၚ် (နဝိ) ရိုင်းစိုင်းသော။ မယဉ်ကျေးသော။/ “သၟတ်တြုံဂှ် ရိုၚ်ဇိုၚ်ကွေံ ဟွံတီသၟူမၞိဟ်ရ။” =“ထိုသူငယ်သည် အလွန်ရိုင်းစိုင်းသည်၊ လူမှုရေးနားမလည်ပါ။”
,ရိုၚ်ရိုၚ် (ကြိဝိ) စုစုရုံးရုံး။ သိုက်သိုက်ဝန်းဝန်း။/ “မှာဗောဓိသတ်၊ သၟိၚ်စိၚ်ဆဒ္ဒန်။ — ဒေါဝ်စိၚ်ဂမၠိုၚ်၊ ရိုၚ်ရိုၚ်ဟွံခၠန်။ ပ္ဍဲဟေမဝန်၊ တန်တဴမံၚ်တုန်။” (လိက်သၟိၚ်စိၚ်ဆဒ္ဒန်။ နာဲထဝ်စိုပ်။) =“ဘုရားလောင်းဆဒ္ဒန်ဆင်မင်းသည် ဟိမဝန္တာတော ဆင်များအလယ်­ သိုက်သိုက်ဝန်းဝန်း မကွဲမကွာနေထိုင်၏။”/ “ဗော်သွးတအ်ဂှ်၊ ရိုၚ်ရိုၚ်သၟဟ်သၟန်။” (လိက်ဟတ္ထိပါလ။ အစွောံ။) = “အခြံအရံပရိသတ်တို့သည် သိုက်သိုက်ဝန်းဝန်း အညီအညွတ်ရှိကုန်၏။”
,ရိုၚ်ရိုၚ်သ္အဳသ္အဳ (ကြိဝိ) စုစုရုံးရုံး။ စုံစုံညီညီ။ သိုက်သိုက်ဝန်းဝန်း။/ “သိုက်သၠိၚ်ဒၟံၚ် — ဒေါဝ်ဗနဳတွဳဝါရဂမၠိုၚ် ရိုၚ်ရိုၚ်သ္အဳသ္အဳ—။” (ပြကိုဟ်ဓမ္မဒေသနာ။ မာံရွှေငိုး။) = “စုစုရုံးရုံးသော အခြံအရံများအလယ်­ စံစားနေလျက်။”/ “ညးမၞုံပၟိက်ကဵုကုသဵုဂမၠိုၚ် ရိုၚ်ရိုၚ်သ္အဳသ္အဳ ဒ္ၚဳပြာပ်ကၠုၚ်အာတ်အခေါၚ်။” (ဓမ္မဒဳပနဳ။ မာံရွှေငိုး။) = “ကုသိုလ်ကိုအလိုရှိကုန်သောသူတို့သည် စုစုရုံးရုံး ရောက်လာခွင့်တောင်းကြကုန်၏။”/ “ရိုၚ်ရိုၚ်သ္အဳသ္အဳ၊ ဗနဳပြဝါ။” (လိက်သၟိၚ်စိၚ်ဆဒ္ဒန်။ နာဲထဝ်စိုပ်။) =“သိုက်သိုက်ဝန်းဝန်း အပေါင်းအဖော်များအလယ်­။”
,ရတ်—၁ (ပါသက်) (န) ရတနာ။/ ရတ်ထပှ်ပြကာ = ဆင်မြင်းစသောရတနာခုနစ်ပါး။/ ရတ်ဒစိတ်သာ် = ကျောက်မျက်ရတနာကိုးပါး။/ ရတ်ပိပြကာ = ဘုရား၊ တရား၊ သံဃာဟူသောရတနာသုံးပါး။
,ရတ်—၂ (ကြိ) ရိတ်သည်။/ ရတ်သြောအ် = စပါးရိတ်သည်။/ ရတ်ချောဲ၊ ရတ်ကၟတ် = မြက်ရိတ်သည်။/ “အဲသ္အာရတ်ကၟတ်ချောဲရ။” (ဇ—၃၄ဝ။ အစွောံ။) = “ငါမြက်သွားရိတ်မည်။”/ (န) ရက်မ။ အိမ်ကြမ်းပြင်ခင်းရန် အောက်ခံတန်း။
,ရတ်ဇံၚ်ကွဳ (န) လှည်းထုပ်။
,ရတ္တဓနဳ (ပါသက်) (န) ဥစ္စာရတနာများ ပေါကြွယ်ပြည့်စုံသောအရပ်။/ “ရတ္တဓနဳ၊ ဟီုပ္ညဳမွဲတန်။ဂၠိုၚ်ရတ်ထဝ်သြန်၊ သ္ဂေဟ်သွဟ်လောန်က္ဍၚ်။” (လိက်သောဝိန်ဇဲယ။ မာံရောဂေါ။) = “ရတ္တဓါနဳဆိုသည်မှာ ရွှေငွေရတနာများ အလွန်ပေါကြွယ်ပြည့်စုံသောအရပ်တည်း။”/ ‘ဓနဳပန်သာ်’ (န) လည်းရှု။
,ရာတ်သြိုဟ် (ကြိ) ၁။ ရင်သပ်ရှုမောဖြစ်သည်။/ “ဂၞိၚ်ဝန်ခဏာၚ်၊ စၚာၚ်ၜါဒိုဟ်။ ညာတ်ဒးရာတ်သြိုဟ်၊ ဂြိုဟ်ဒှ်ဟူဟူ။” (လိက်ပတ္တစာရဳ။ နာဲထဝ်စိုပ်။) = “လုံးဝန်းသေးသွယ်သောခါးနှင့်တင်ပါးနှစ်ဖက်တို့သည် အလွန်တင့်တယ်၏။ မြင်ရသူတိုင်း အသည်းမှာဟူးဟူး ရင်သပ်ရှုမော ဖြစ်ကြရကုန်၏။”/ “ညံၚ်ဒေဝတဴ၊ ဗြဴအဆေဝ်သွဝ်။ ရာညးမညာတ်၊ ရာတ်သြိုဟ်ဂတဝ်။” (လိက်ပတ္တစာရဳ။ နာဲထဝ်စိုပ်။) = “နတ်သမီးရုပ်အဆင်းကဲ့သို့ မြင်သူတိုင်း ရင်သပ်ရှုမောတုန်လှုပ်ရကုန်၏။”/ ၂။ အံ့သြတုန်လှုပ်သည်။/ “သမ္ၚံက်သမ္ၚာတ်၊ ရာတ်သြိုဟ်သ္ပာတ်သ္ဗ။” (လိက်မေဃကောန်ဒြာဲ) = “ထိတ်လန့်အံ့သြတုန်လှုပ်၍ စိုးရိမ်ပူပန်သည်။”/ “ဂၠာဲကၞာတ်ဒေံဗြဴ၊ကောဂၞဴဟွံညာတ်။ ဟွံညာတ်တုဲဝါတ်၊ ရာတ်သြိုဟ်ရရဴ။” (လိက်ကောန်သၟိၚ်ပိ။ မာံခစုန်အံက်။) = “ချစ်နှမကိုရှာသော်လည်း မောင်မတွေ့လေ၊ မတွေ့လေသောကြောင့် အခက်ကြုံကာ တုန်လှုပ်ရ၏။”
,ရိတ်၊ ရိတ်မွဲ (ကြိ) ခြစ်သည်။ ခြစ်ကြည့်သည်။/ “(ညးဗၞိက်လီုမလုလန်ဂှ်) ရပ်ထးဂှ်ၚဳမွဲတုဲ ထဝ်ရောၚ်ဒှ်ချပ်တုဲ ပ္ဍဲစနိန်ထးဂှ် ရိတ်မွဲကဵုမုဟ်တနိၚ် တီဒဒှ်ထဝ်။” (ဇ—၃။ အစွောံ။) = “လောဘရမ္မက်ကြီးသော ရွဲကုန်သည်သည် ခွက်ကိုကိုင်၍ကြည့်သော် ရွှေခွက်ဖြစ်လတ္တံ့ဟု ကြံအောက်မေ့၍ ခွက်၏ကျော­ အပ်ထိပ်စွန်းဖြင့် ခြစ်ကြည့်သည်ရှိသော် ရွှေခွက်ဖြစ်မှန်းသိ၏။”
,ရုဒ္ဒရသ (ပါ) (န) (စာပေ) ကြမ်းတမ်းခက်ထန်မှုရသ။ ရုဒ္ဒရသ။
,ရေတ် (ကြိ) လှည့်ပတ်သည်။ လှည့်လည်သည်။/ “ဗောဓိသတ်မွဲကဵုသၟတ်ဂှ်မွဲ ကွာ်ရေတ်အာပ္ဍဲဥဒျာန်—။” (ဇ—၁၄၉။ အစွောံ။) = “ဘုရားလောင်းနှင့်ထိုသူငယ်တို့သည် ဥယျာဉ်ထဲ­ လှည့်လည်လျှောက်သွား၏။”/ “ဗောဓိသတ်သၟိၚ်ၜိုပ် ပဝ်ရေတ်ကၠေံသိနနရာတ် ပိလတုန်။” (ဇ—၄၇၆။အစွောံ။) = “ဘုရားလောင်းဟင်္သာမင်းသည် မြင်းမိုရ်တောင်ကို သုံးခေါက်လှည့်ပတ်ပျံသန်း၏။”/ “(ဗောဓိသတ် သီုညးဗၞိက်ကွဳဂမၠိုၚ် အာစိုပ်ကန္တာဒမံၚ်ကလော်တံဂှ်တုဲ) — ဟွံသ္တိက်မၚ်မွဲရေတ်တဴ ဒဵုတ္ၚဲယးရ။” (ဇ—၁။ အစွောံ။) = “ဘုရားလောင်းနှင့်အတူ လှည်းကုန်သည်တို့သည် ဘီလူးတို့နေရာ ကန္တာရသို့ရောက်သော် အရုဏ်တက်သည့်တိုၚ် မအိပ်ကြကုန်ဘဲ လှည့်လည်စောင့်ကြပ်ကြကုန်၏။”/ “သမ္ဘာသ္ဍိုက်အဲ — ယာတ်သာ်ချီုသၠောံ သပါတဲဗလဲကအ်အဲဂှ် မဂွံရေတ်ဝေၚ်သဘၚ်နက်သတ်—။” (ဇ—၁၄၇။ အစွောံ။) = “ဝတ်ပန်းဆိုးအဝတ်ကိုဝတ်ရုံ၍ လက်ဖြင့်ငါ၏လည်ကိုဖက်ကာ နက္ခတ်ပွဲသဘင် လှည့်လည်ကစားချင်သော ငါ၏ချစ်ဇနီး။”
,ရေတ်မွဲ၊ ရေတ်ရံၚ် (ကြိ) လှည့်ပတ်ကြည့်ရှုသည်။ လှည့်လည်ကြည့်ရှုသည်။/ “တိုၚ်အကေၚ်မ ရေတ်ရံၚ်ဒပ်စၟဟ်တ္ၚဲ ဖရၚ်မၚ်ဂံၚ်တိတ်ရေတ်ဒပ်ပၠန်။” (အကြီုရာဇာဓိရာဇ်) = “တပ်ကို နေ့စဉ်လှည့်လည်ကြည့်ရှုမြဲအတိုင်း ဘုရင်မင်းခေါင်းသည် ထွက်၍တပ်လှည့်လည်ပြန်၏။”
,ရိုတ် (န) ပေပင်။/ ‘ချူလဝ်ပ္ဍဲသၠရိုတ်။’ = ‘ပေရွက်တွင်ရေးထားသည်။’
,ရည (ပါ) (န) တော။ (ကဗျာသုံး)/ ‘အရည’ နှင့်အတူတူ။
,ရန် (ကြိ) ရည်သည်။ ရည်ရွယ်သည်။/ “ရန်ကဵုညးတုဲ ပိုဲရီုဗၚ်ရ။” = “သူ့အားရည်ရွယ်ပြီး ကျွန်တော်တို့ကူညီသည်။”/ “(ဗမၞးတံဂှ်) ရန်ကဵုဝတ္ထုအမိဿတံဂှ်တုဲ ဍေံစဳရေၚ်ပူဇဴယတ်ဂှ်ရောၚ်”ကျာ်တြဲဂး။ (ဇ—၇၇။ အစွောံ။) = “ထိုပုဏ္ဏားတို့သည် အာမိသကိုငဲ့၍ (ဥစ္စာကိုရည်ရွယ်၍) ယဇ်ပူဇော်ခြင်းကို စီရင်ခြင်းဖြစ်၏။”
,ရန်စ (ကြိ) (မိမိအကျိုးရရှိရန်) ရည်ရွယ်သည်။ ရည်မျှော်သည်။/ “ကောန်ဗၞိက်ၜါ၊ စိုတ်သဒ္ဓာလောန်။ — ဗၞိက်ထဝ်သြန်သွံ၊ ဟွံဂွံရန်စ။ ဒုၚ်ဖျဴဓါတ်ဂၠု၊ သဗ္ဗညုတ။” (လိက်ပထမဗောဓိ။ မၚ်ဍိက်လ။) = “ကုန်သည်ညီနောင်နှစ်ဦးတို့သည် အလွန်သဒ္ဓာစိတ်ထက်သန်၏၊ ကုန်စည်ရွှေငွေကိုမရည်မျှော်ဘဲ သဗ္ဗညုမြတ်စွာဘုရား၏ဓါတ်တော်ကို မိမိတို့ဋ္ဌာနေဆီသို့ ဆောင်ယူ၍ပြန်၏။”
,ရန်တၟံ၊ ရန်တၟအ် (ကြိ) ရည်ရွယ်သည်။ ရည်မှန်းသည်။ ရည်စူးသည်။/ “အပေါတ်ဒါန်ဝွံ အဲရန်တၟအ်လဝ် တၞဟ်နကဵုဒါန်ကုခမဳသၚ်ရ။” = “ဤလှူဖွယ်ဝတ္ထုကို ရဟန်းသံဃာအား လှူဒါန်းရန်ငါရည်စူးထားသည်။”/ “ဍေံရန်တၟံလဝ် သၟိက်ဂွံဒှ်တၠပညာမွဲရ။” = “ပညာရှင်တစ်ယောက်ဖြစ်ရန် သူရည်မှန်းထားသည်။”
,ရန်ဒည၊ ရန်ဓည (ကြိ) ရွံ့သည်။ နောက်တွန့်သည်။/ “လကိုဟ်ကလော်၊ မဇၞော်တေဇ။ စမဳညာတ်ပၠန်၊ ဟွံရန်ဒည။ သုဲကၠုၚ်မွဲကၟပ်၊ ဍေံသၟိက်ရပ်စ။” (လိက်ကောန်သၟိၚ်ပိ။ မာံခစုန်အံက်။) = “တန်ခိုးကြီးသောဘီလူးသည် လှမ်းမြင်သည်ရှိသော် နောက်မတွန့်မရွံ့ဘဲ သူဖမ်းစားလို၍ ခချဉ်းနင်းရွေ့လျားဝၚ်လာ၏။”/ “ပိုဲဗတ်အိုတ်သ္ကန်၊ ဟွံရန်ဓည။” (လိက်ပဒုမဝတဳ) = “ငါတို့အသက်ကုန်သေရသည်ဖြစ်စေ နောက်မတွန့်မရွံ့။”/ “မိဖေက်မံၚ်ပၠန်၊ မိရန်ဓည။” (လိက်ကကၠာ်။ကောန်ဍး။) = “မယ်ကြောက်နေပြီး မယ်နောက်တွန့်ရွံ့နေ၏။”
,ရန်ရန် (ကြိဝိ) ၁။ မှောင်မှောင်ရီရီ။ (?)/ “တ္ၚဲသဝ်ရန်ရန်၊ ညန်ကာလသၟဟ်။” (လိက်မိဍောၚ်ကှ်ေထဝ်။) = “ညနေမှောင်ရီ၍ အချိန်ကာလနီးလာသည်။”/ ၂။ ဖြည်းဖြည်းသာသာ။/ “စှ်ေကၠုၚ်ရန်ရန်၊ ဗန်ကေတ်ကောန်ၜါ။ ဗမဴတှ်ဆာဲ၊ ကဵုကောန်ဗၠာဲမှာ။” (လိက်မိဍောၚ်ကှ်ေထဝ်) =“ဖြည်းဖြည်းသာသာ ဆင်းလာပြီးလျှင် သားနှစ်ယောက်တို့ကိုဖက်ကာ နို့ချိုတိုက်ကျွေး၏။”
,ရာန် (ကြိ) ဝယ်သည်။/ ရာန်ဖျာ = ဈေးဝယ်သည်။
,ရာန်ပါန် (ကြိ) ဈေးဝယ်သည်။ ဝယ်ခြမ်းသည်။/ “ကသာပ်ဝွံ ကဵု (လဗြဴဒိုက်ဂတ်) ရာန်ပါန်ညိတုဲ ကဵုတရိုပ်ကဵုဒါန်ကဵုထေညိ” သၟိၚ်ဂး။ (ဇ—၂၅၄။ အစွောံ။) = “ဤအသပြာကို သူဆင်းရဲအဖွားအိုအား ဈေးဝယ်ခြမ်းစေ၍ မထေရ်အား ဆွမ်းကျွေးစေလော့” ဟုမင်းဆို၏။/ “(မၚ်ဗၠာဲဂှ်) အစောံဇကုမဒိုခ်က္ဍၚ် ဟွံဂံၚ်ရာန်ပါန်မွဲသာ်ရ။” (သၠပတ်ပေါရဏာံ။ အစွောံ။) = “ထိုလုလင်သည်ဆင်းရဲနွမ်းပါးလှသဖြင့် ဘာတစ်ခုမျှ မဝယ်ခြမ်းဝံ့။”
,ရာန်သကိုတ် (ကြိ) ၁။ (ဒုက္ခဝေဒနာ၊ အိုမင်းခြင်းဇရာ၊ အပူဒဏ် အအေးဒဏ်စသည်) ဖိစီးနှိပ်စက်သည်။ ပြင်းထန်သည်။/ ဂမ္တဴရာန်သကိုတ် = အပူနှိပ်စက်သည်။/ လမုဟ်ရာန်သကိုတ် =အချမ်းနှိပ်စက်သည်။/ ဒဒိုက်လၞီစိုတ်ရာန်သကိုတ် = စိတ်သောကဖိစီးနှိပ်စက်သည်။/ တၟောၚ်ရာန်သကိုတ် = ပင်ပန်းခြင်းနှိပ်စက်သည်။/ တဟၚ်ရာန်သကိုတ် = ရေငတ်ခြင်းနှိပ်စက်သည်။/ဗယဵုရာန်သကိုတ် = ဆာမွတ်ခြင်းနှိပ်စက်သည်။/ “ဟာဲကၞုဲဒမိက်၊ ဟိုတ်ဂမ္တဴရာန်သကိုတ်ဗှ်ေဗှ်ေထၚ်ဍာ်တုဲ ဍာ်မဂၠိုၚ် အဲကဵုဒါန်ကဵုဗှ်ေ၊ ဗှ်ေဂွံသုၚ်ဍာ်အဲဖဲတုဲ ပွဗှ်ေဘဗဟေက်အဲပၠန်—။” (ဇ—၁၇၄။ အစွောံ။) = “ဟယ်မျောက်ယုတ်၊ အပူနှိပ်စက်သည်ဖြစ်၍ ရေငတ်သောသင့်အား များစွာသောရေကို ငါပေးခဲ့၏။ ငါပေးသောရေကို ဝအောင်သောက်ပြီးလျှင် ငါ့အားခြောက်သောအမှုကိုသင်ပြုပြန်ဘိ၏။”/ “ဗြဲဇၞော်ဂူဟွံတီဍး ကၞုဲမွဲ လမုဟ်ရာန်သကိုတ်တုဲ သီုကဵုဇတဝ်ဒၟံၚ်က္ဍုက်က်ကိတ်ဒၟံၚ်ၚေက်တုဲ ဂ္ၚေၚ်ကၠုၚ်ရ။” (ဇ—၂၅ဝ။ အစွောံ။) = “မိုဃ်းလအခါ အယဉ်မပြတ် စီးသောမိုဃ်းသည် စွေလတ်သည်ရှိသော် မျောက်သည် အချမ်းနှိပ်စက်သည်ဖြစ်၍ သွားတို့ဖြင့်သွားတို့ကိုခဲလျက် တုန်လှုပ်လျက်သွား၏။” (ညောင်ကန်)/ “ကာလမဗျုအာ ဇရာရာန်သကိုတ်တုဲရုပ်သာ်ကျာ်သြဳဂှ် ဍေံလီုအာအိုတ်ရ။” (ဇ—၄၁၁။ အစွောံ။) = “အိုမင်းသောအခါ ဇရာထောင်းသည်ဖြစ်၍ ကျက်သရေရှိသော ရုပ်အဆင်းသည် ပျက်စီးကုန်၏။”/ ၂။ အနိုင်ယူသည်။ နှိပ်ကွပ်အောင်နိုင်သည်။/ ဂွံရာန်သကိုတ်သတြု = ရန်သူကိုအောင်နိုင်သည်။/ “ယွံတဳလမၞုံပိုန်ကျာ်တြဲ၊ ဗၞတ်သၟာန်မွဲပိုတ်ကီု ဂွံရာန်သကိုတ်ကၠေံ (ပြဘာတ်) ဂှ်သွံ။” (ဇ—၂၄၄။ အစွောံ။) = “ဘုန်းတော်ကြီးသောအရှင်ဘုရား၊ အရှင်ဘုရားသည် တစ်ပုဒ်တည်းသောမေးခွန်းဖြင့်သာလျှင် ထိုပရိဗိုဇ်ကို နှိပ်၍အောင်နိုင်၏။”/ “မၞိဟ်ဂမၠိုၚ်စိုတ်သၟဟ်သၟန် ကောံကရောံကလောဂမၠိုၚ်တုဲဂှ် ဂွံရာၚ်ဆာဲတဴဒးရးဟေၚ်။ သတြုရာန်သကိုတ်ဟွံမာန်ဟေၚ်ရ။” (ဇ—၇၄။ အစွောံ။) = “လူတို့သည် ဆွေမျိုးတို့နှင့်တကွ တစ်စိတ်တစ်ဝမ်းတည်း ညီညွတ်သည်ရှိသော် တင့်တယ်ကောင်းမြတ်၏။ ရန်သူသည် မနှိပ်စက်နိုင်။”/ ၃။ နိုင်ထက်ကလူမူသည်။ အနိုင်ကျင့်သည်။ ညှဉ်းဆဲနှိပ်စက်သည်။/“သၟိၚ်ဂှ် လောဘဇၞော်တုဲ ကေတ်အခေါန် ရာန်သကိုတ်ညးလောန်။” (ဇ—၄၇၈။ အစွောံ။) =“ထိုမင်းသည် လောဘကြီး၏။ အခွန်အတုတ်ကိုယူရာတွင် လူများအား အနိုင်ကျင့်နှိပ်စက်၏။”/“ဗြဴရာန်သကိုတ်တၠသ္ၚိဂှ် ဗြဴညံၚ်နာဲဂးယၟု။” (ဇ—၂၆၉။ အစွောံ။) = “လင်အား အနိုင်အထက်ပြုသောမယားကို အရှင်နှင့်တူသောမယားဟူ၍ ဆိုအပ်၏။”/ ၄။ နှိပ်ကွပ်သည်။ ဖိနှိပ်ဆုံးမသည်။/ “ယြဴပူဂဵုမထေက်ကြိုက်ကဵုရာန်သကိုတ် မပ္တံကမၠတ်ဒမၠတံဂှ် မ္ဒးရာန်သကိုတ်ရ။” (ဇ—၅၂၁။ အစွောံ။) = “(ခိုးသူအစရှိသော) နှိပ်ကွပ်ထိုက်သောသူကို နှိပ်ကွပ်ရာ၏။” (ညောင်ကန်)/ ၅။ ပြစ်တင်ရှုတ်ချသည်။ ပြစ်တင်ကြိမ်းမောင်းသည်။/ “(အမာတ်တၠဒုဟ်ဂှ်) သၟိၚ်ဟီုရာန်သကိုတ်ဗွဲမလောန်—။” (ဇ—၇၉။ အစွောံ။) = “မင်းသည် အပြစ်ကျူးလွန်သောအမတ်ကိုပြင်းထန်စွာပြစ်တင်ရှုတ်ချ၏။”/ “ဟီုရာန်သကိုတ်တုဲ မဟီုဒၠောအ်ဗ္တောန်ဂှ် ပူဂဵုဂွံတန်ပ္ဍဲဒၠောအ်ဗ္တောန်တၠပညာဂှ် ပူဂဵုဂှ် ဒှ်ပူဂဵုမပြဲရ။” (ဇ—၄ဝ၆။ အစွောံ။) = “ပြောဆိုကြိမ်းမောင်း၍ ဆိုဆုံးမခြင်းဖြင့် ထိုပညာရှိအဆုံးအမ­ တည်သောသူသည် သူကောင်းမည်၏။”
,ရုန် (ကြိ) ရုန်းသည်။/ “(သၟိၚ်ဒြာဲထဝ်ဒးစုတ်ဓနက်) ရုန်တရဲဓဇက်မွဲလစုတ်ဂှ် စၞာံဇိုၚ်ဂှ် ထကုတ်အာရ။ ရုန်မွဲလစုတ်ပၠန် ဖျုန်ဇိုၚ်ထကုတ်အာရ။” (ဇ—၃၅၉။ အစွောံ။) = “ရွှေသမင်မင်းသည်ကျော့ကွင်းမိ၍ တစ်ချက်ဆောင့်ဆွဲရုန်းလိုက်ရာ ခြေထောက်အရေသည် ပြတ်၏။ တစ်ချက်ရုန်းလိုက်ပြန်ရာ ခြေထောက်အသားသည် ပြတ်၏။”
,ရုန်ဂစာန် (ကြိ) ရုန်းကန်သည်။ အားစိုက်ရုန်းသည်။/ “သၟိၚ်ဒြာဲထဝ်ဒးစုတ်ဓနက် ရုန်ဂစာန်သီုဒြဟတ် ဂၠိုၚ်ကဵုလတုန်တုဲ စၞာံဒကုတ် ဖျုန်ဒကုတ် လတေၚ်ဒကုတ် စိုပ်အာဇုတ်ရ။” (ဇ—၃၅၉။အစွောံ။) = “ရွှေသမင်မင်းသည် ကျော့ကွင်းမိ၍ အကြိမ်များစွာ အားစိုက်ရုန်းကန်ရာ အရေ၊အသား၊ အကြောတို့သည် ပြတ်ကုန်၏။”
,ရုန်ဒဴ (ကြိ) လွတ်မြောက်အောင်ရုန်းကန်သည်။ ရုန်းထွက်သည်။/ “ဇုက်ဂွံါရာဂ၊ လောဘတံၚ်ဂြဲ။ရုန်ဒဴဟွံမာန်၊ ဍုၚ်နဳဗာန်သ္ၚောဲ။” (လိက်လက္ခဏပိ) = “ရာဂနှောင်ကြိုး လောဘဆွဲရာနောက်သို့လိုက်ကာ မရုန်းထွက်နိုင်ဘဲ နိဗ္ဗာန်နှင့်ဝေးရ၏။”/ “တီဟွံမွဲဂုန်၊ သၟိက်ဂွံရုန်ဒဴ။ ညာတ်ပိုန်ကာမ၊ ကမၠဒမြဴ။” (လိက်ဝိဓူရ) = “ကာမစည်းစိမ်ကိုမြင်၍ ထိတ်လန့်တုန်လှုပ်၏၊ အကျိုးကျေးဇူးမရှိကြောင်းသိကာ ရုန်းထွက်ချင်၏။”
,ရုန်မဵု (နဝိ) ၁။ ရင့်သီးသော။ မောက်မာသော။ ရုန့်ရင်းသော။/ ဂလာန်မရုန်မဵု = “ရုန့်ရင်းသောစကား။ ရင့်သီးသောစကား။/ “ဍေံဟီုဂလာန်သ္ကာတ်မြဟ်ရုန်မဵု။” (ဇ—၃၉။ အစွောံ။) = “ကြမ်းတမ်းရုန့်ရင်းသောစကားကို သူပြောဆိုသည်။”/ “လဟီုမရုန်မဵု မစုတ်ပ္ဍဲလိက်ဝွံ ဂလာန်ဟွံသေၚ်—။” (အကြီုရာဇာဓိရာဇ်) = “စာတွင်ထည့်ရေးသော ရင့်သီးသောအပြောအဆိုသည် မှန်သောစကားမဟုတ်။”/ ၂။ မာကျောသော။ ကြမ်းတမ်းသော။ မပျော့ပျောင်းသော။/ ဖုန်မရုန်မဵု =မာကြမ်းသောမွေ့ရာ။/ ယာတ်မရုန်မဵု = မာကြမ်းသောအဝတ်။/ “မိ၊ ယာတ်ဝွံ ကြံၚ်မ္ၚိုဟ်ရုန်မဵုက္ဍၚ်သန်။ ယာတ်သ္အာၚ် မိကဵုကုအဲညိ” မၚ်ဗၠာဲဂး။ (ဓမ္မဒေသနာ။ မာံရွှေငိုး။) = “မိခင်၊ဤအဝတ်ပုဆိုးသည် မာကျောကြမ်းတမ်းလွန်း၏။ အခြားတစ်ပါးသော အဝတ်ပုဆိုးကို အကျွန်ုပ်အား ပေးပါလော့။”/ ၃။ ပြင်းထန်သော။/ ‘လွာဲဗမၞးမဍောၚ် သီုလမောင်မရုန်မိုဝ်—။’ (ဇ—ဝေသန္တဝ်။ အစွောံ။) = ‘ပြင်းထန်သောအမောအပန်းဖြင့် ပုဏ္ဏားမောပန်းနေစဉ်အခါ­။’/ “ညးလ္ၚဵုရ၊ လောဘရုန်မဵု။ ပိုဲဍောတ်ဏီရ၊ ဟွံပကုသဵု။” (လိက်ကာလထေ) = “အချို့သူတို့သည် လောဘပြင်းထန်ကုန်၏၊ တို့ငယ်ရွယ်ပါသေးသည်ဟုဆိုကာ ကုသိုလ်ကောင်းမှုမပြု။”
,ရေန် (န) ဖြုတ်ကောင်။
,ရောန်ရောန် (ကြိဝိ) ၁။ ပူပန်စွာဖြင့်။ ပူပန်လျက်။/ “ရမတ်ဗြိုဟ်ဗြိုဟ်၊ ဖျုန်ဂြိုဟ်ရောန်ရောန်။” (လိက်ဟတ္ထိပါလ။ အစွောံ။) = “မျက်ရည်ဖြိုင်ဖြိုင်ကျကာ နှလုံးပူပန်လျက်ရှိ၏။”/ ၂။ သည်းထန်စွာ။/ “စိုပ်တသီုဖူ၊ ဗြဲဂူရောန်ရောန်။” (လိက်ဟတ္ထိပါလ။ အစွောံ။) = “မိုးရာသီရောက်၍ မိုးသည်းထန်စွာရွာသွန်းသည်။”
,ရပ် (ကြိ) ၁။ ကိုင်သည်။/ ‘ရပ်လဝ်တဲဍေံညိ။’ = ‘သူ့လက်ကိုကိုင်ထားပါ။’/ ၂။ ဖမ်းသည်။/ဗ္ဂဲရပ်ကၞိ = ကြောင်သည် ကြွက်ကိုဖမ်းသည်။/ “ဗၠာဲသၟိၚ်တံ ရပ်ဏာကၠေံကမၠတ်ဂှ်ရ။” = “သူခိုးကို မင်းချင်းယောကျာ်းတို့ ဖမ်းဆီးခေါ်ဆောင်သွား၏။”/ ၃။ သုံးသည်။ သုံးစွဲသည်။/ “ညးဒိုက်ဂတ်ဟွံဂွံရပ်သြန်ဂၠိုၚ်ၚ်ရ။” = “သူဆင်းရဲသည် ငွေကို များများမသုံးနိုင်ပါ။”/ ၄။ အတင်းအကြပ်လုပ်စေသည်။/ “သၟတ်ဂှ် သီုမဟွံမိက်ပသာမဏဳဂှ်ဟေၚ် ထေဗျုဂှ် ရပ်ကဵုပသာမဏဳရ။” (ဇ—၂၄၉။ အစွောံ။) = “ထိုသူငယ်သည် သာမဏေမပြုချင်ဘဲလျက်လျှင် ရဟန်းကြီးက အတင်းအကြပ် သာမဏေပြုစေ၏။”
,ရပ်စပ် (ကြိ) ၁။ သုံးစွဲသည်။ အသုံးပြုသည်။ သုံးဆောင်သည်။/ ပ္ဍဲသ္ၚိဂှ်တုန် ထးထဝ်မွဲ မဒှ်ပရိဘောဂသေဋ္ဌဳဇၞော်တုဲ မစွံလဝ်အကြာဘာဇန ဗၞတ်အဓါန်မလအ် မဟွံရပ်စပ် မကၠိခ္ဍက်ဒၟံၚ်ဂှ်နွံ။ ဒဒှ်မဒှ်ထးထဝ်ဂှ်လေဝ် ညးၜါဟွံတီ။ (ဇ—၃။ အစွောံ။) = “ထိုအိမ်­ သူဋ္ဌေးကြီး၏ အသုံးအဆောင်ဖြစ်သော ရွှေခွက်တစ်ခုရှိ၏၊ အိုးခွက်ပန်းကန်အကြား­ ကာလရှည်မြင့်စွာ မသုံးစွဲဘဲထား၍ညစ်ပေနေ၏။ ရွှေခွက်ဖြစ်မှန်းကိုလည်း မြေးအဘွားနှစ်ဦးတို့သည် မသိကုန်။”/ “ယွံၝောံ၊ ထဝ်သီုဖအိုတ်ဝွံ ၝောံရပ်စပ်စဟာပ် ပ္တုဲကုသဵုရ။” (ဇ—၃၁။ အစွောံ။) = “ရှင်မ၊ ဤရွှေအားလုံးကိုသင်သုံးစွဲစားသောက်၍ ကုသိုလ်ကောင်းမှုပြုလော့။”/ “(ဗြဴဂှ်) တြုံတၠသ္ၚိကၠောန်နၚ် ရပ်စပ်ကၠေံမ္ၚးမတ်တၠသ္ၚိ။” (ဇ—၇၇။ အစွောံ။) = “ထိုမိန်းမသည် လင်လုပ်ကိုင်ရှာဖွေထားသောဥစ္စာကိုလၚ်၏မျက်ကွယ်­ သုံးဖြုန်းပစ်၏။”/ “ဒြၚ်ဂှ်ကီုလေဝ် လၟသွံဂွံၚုဟ် ရပ်စပ်အိုတ်အာတုဲ တိတ်စိုပ်ဗောဓိသတ် (သၟိၚ်စိၚ်) ပၠန်။” (ဇ—၇၂။ အစွောံ။) = “မုဆိုးသည် ထိုအစွယ်ကိုလည်း ရောင်း၍ရသောအဘိုးကို သုံးစွဲ၍ကုန်သွား၍ ဘုရားလောင်းဆင်မင်းထံသို့ လာရောက်ပြန်၏။”/ “ကလိဂွံဒြပ်တုဲ စဳရေၚ်စွံကဵုဒး စဟာပ်ရပ်စပ်ကဵုဒးညိ။” (ဇ—၁၃၇။ အစွောံ။) = “ဥစ္စာကိုရ၍ စီရင်ထားတတ်ပါစေ၊ စားသောက်သုံးစွဲတတ်ပါစေ။”/ ၂။ ကိုင်တွယ်သည်။/ “ပ္ၚာန်တိုက်ဂှ် ရပ်စပ်ကဵုဗိုန်ညိ။ ဖလုတ်စှ်ေအာနူတဲမ္ဂး ဒကးအာရောၚ်။” = “ကြွေပန်းကန်ကို မြဲစွာကိုင်တွယ်ပါ။လက်မှလွတ်ကျသွားလျှင် ကွဲသွားလိမ့်မည်။”/ ၃။ ဖမ်းသည်။ ဖမ်းဆီးသည်။/ “(ကုသၟတ်ၜါဂှ်ဗမၞး) ဟွံသေၚ်လှေံလှန်နၚ် ဟွံသေၚ်ရပ်စပ်နၚ် တန်ဒှ်ရ” သၟိၚ်ဇၞော်ဂး။ (ဇ—ဝေသန္တဝ်။ အစွောံ။) = “သူငယ်နှစ်ယောက်တို့အား ပုဏ္ဏားသည် ဖြားယောင်းခေါ်လာခြင်းသော်၄င်း ဖမ်းဆီးလာခြင်းသော်၄င်း ဖြစ်တန်ရာ၏။”
,ရပ်စပ်စကာ (ကြိ) သုံးဆောင်သည်။ အသုံးပြုသည်။ (ပါဠိ—ပရိဘုဥ္ဇန)
,ရပ်ဇုက် (ကြိ) ကြိုးကိုင်သည်။ (ဥပစာ) ခြယ်လှယ်သည်။
,ရပ်ထဝ် (ကြိ) (ဘုရား၊ စေတီစသည်ကို) ရွှေချသည်။
,ရပ်လက်ကၠိုက် (ကြိ) အကောက်ကြံသည်။ အကွက်ဆင်ဖမ်းသည်။ အငိုက်ဖမ်းသည်။/ “ကသပ်အ္စာသိုန်ဝွံ ရပ်လက်ကၠိုက်ကဵုအဲရောၚ်သွံ” မဟောဟ်သဓချပ်။ (ဇ—မဟောဟ်သဓ။ အစွောံ။) =“ဆရာသေနက၏အကြံသည် ငါ့ကို အကွက်ဆင်အငိုက်ဖမ်းခြင်းပါလား” ဟုမဟောသဓကြံ၏။
,ရပ်လက်ဗန် (ကြိ) နပန်းလုံးသည်။ နပန်းသတ်သည်။ လက်ပမ်းလုံးထွေးသည်။/ “ညးၜါရပ်လက်ဗန်—။” (ဇ—၃၇၄။ အစွောံ။) = “နှစ်ယောက်သောသူတို့သည် နပန်းသတ်ကြကုန်၏။”
,ရပ်သၞေဝ် (ကြိ) ပဲ့ကိုင်သည်။ (ဥပစာ) တည့်မတ်ထိန်းကျောင်းပေးသည်။/ “ကလောန်ဂကောံပိုဲသ္ဂောံစိုပ်တရဴ တာလျိုၚ်ညးဒးရပ်သၞေဝ်ရ။” = “ငါတို့အဖွဲ့အစည်းအလုပ် ထိရောက်စေရေးအတွက် ပဲ့ကိုင်ထိန်းကျောင်းပေးရန် သူ့တာဝန်ဖြစ်သည်။”
,ရပ်အလံၚ် (ကြိ) ဟန်ဆောင်သည်။ ဟန်အမူအရာလုပ်သည်။ ဂိုက်ဖမ်းသည်။/ “လ္ပရပ်ဒၟံၚ်အလံၚ်၊သ္ဇက်စနွံဂှ် စထောံညိ။” = “ဟန်အမူအရာလုပ်မနေနှင့်။ စားစရာရှိတာ စားလိုက်ပါ။”/ “ဍေံဗြဴဂှ် ရပ်ဒၟံၚ်အလံၚ်ကောန်သၟိၚ်ဗြဴ။” = “ထိုမိန်းမသည် ရုပ်ရှင်မင်းသမီးဂိုက်ဖမ်းနေသည်။”
,ရာပ် (န) ချုံ။
,ရာပ်စာပ် (န) ချုံနွယ်ပိတ်ပေါင်း။ တောချုံ။
,ရိပ်တီ (ကြိ) အနည်းငယ်မျှသိသည်။ (အထောက်အထားမခိုင်လုံဘဲ) ရော်ရမ်းမှန်းဆသည်။
,ရိပ်ရံၚ် (ကြိ) လိုက်ဖက်ညီသည်။ (?)/ “သီုညးၜါ ခါမတိုန်ဒၟံၚ်လတူသၞာရတ်တုဲ မူညံၚ်မတုပ်ရော၊ညံၚ်မၞိက်ဝိပူလပဝ်ကဵုထဝ်ဇမ္မုနတ် မဒုၚ်ဗဗဵုသၟိၚ်စက္ကဝဝ်ကီု လစးလမးရာၚ်ဆာဲ ရိပ်ရံၚ်ကြိုက်လ္ၚေၚ်လောန်သန်။” (အာန်ဇုနာန်) = “နှစ်ဦးသားတို့သည် ရတနာထိုင်ခင်းပေါ် တက်နေသောအခါအဘယ်နှင့်ပမာတူသနည်း။ စကြဝတေးမင်း၏ ရှုစားခြင်းကိုခံထိုက်သော ဝိပူလပတ္တမြားနှင့်ဇမ္ဗူရစ်ရွှေစင်ကဲ့သို့ အရောင်ဖိတ်ဖိတ်တောက်ကာ တင့်တယ်၍ အလွန်လိုက်ဖက်ညီ၏။”/ “ညံၚ်ဍာ်ကဵုဒကှ် မပတိတ်ကဵုသၟိၚ်တ္ၚဲတၠလျးကမုသာ်သြန် ကြိုက်လ္ၚေၚ်ရိပ်ရံၚ် ရာၚ်ဆာဲက္ဍၚ်သန်။” (အာန်ဇုနာန်) (ရိပ်ရံၚ် = ကြိုက်လ္ၚေၚ်) = “ရေနှင့်ကြာပမာ ငွေရောင်ခြည်ရှင်နေမင်းသို့ ထုတ်ဆောင်သောအခါ လိုက်ဖက်ညီ၍ အလွန်တင့်တယ်၏။”
,ရုပ်—၁ (ပါသက်) (န) ရုပ်။ ရုပ်ပုံ။ (ပါဠိ—ရူပ)
,ရုပ်—၂ (ကြိ) ၁။ ရုပ်သည်။ ပြန်၍သိမ်းယူသည်။ သိမ်းစုသည်။/ “ယာတ်စဲလဝ်ဂှ် ရုပ်ထောံညိ။”= “လှန်းထားသောအဝတ်ကို ရုပ်လိုက်ပါ။”/ “တမ္ၚာတံဂှ် ဍေံရုပ်ဇာရ။” (ဇ—၄ဝ၇။ အစွောံ။) = “တံငါတို့သည် ပိုက်ကွန်ကို ရုပ်ကြကုန်၏။”/ ၂။ (ရာထူး၊ စည်းစိမ်စသည်မှ) ရုပ်သိမ်းသည်။/ “ဗြဴကမၠောန်သၟိၚ်မွဲဂှ် သၟိၚ်ဖျေံကၠေံ ရုပ်ကၠေံပိုန်ဟာန်ဍေံရ။” (ဇ—၅၂၂။ အစွောံ။) =“မင်းမောင်းမတစ်ယောက်အား မင်းသည် အရာမှချ၍ စည်းစိမ်တို့ကို ရုပ်သိမ်းလိုက်၏။”
,ရုပ်ဂိုၚ်၊ ဂိုၚ်ရုပ် (ကြိ) ပြန်သိမ်းယူသည်။ ပြန်ရုပ်သိမ်းသည်။/ “အပေါတ်တွဵုညးအိုဿီုဂှ် ညးဂိုၚ်ရုပ်ကေတ်ကၠေံအိုတ်တုဲရအဴ။” (ဇ—၄ဝ၉။ အစွောံ။) = “၄င်းပေးအပ်ထားသော ပစ္စည်းအားလုံးတို့ကို ၄င်းပြန်သိမ်းယူလိုက်ကုန်ပြီ။”/ “အာဲကၟာဲပိုန်ဟာန်မကဵုလဝ်ဂှ် သၟိၚ်ကဵုရုပ်ဂိုၚ်ကၠေံရ။” (ဇ—၄ဝ၉။ အစွောံ။) = “ပေးအပ်ထားသော စည်းစိမ်ဥစ္စာတို့ကို မင်းသည် ပြန်သိမ်းယူစေ၏။”
,ရုပ်ဆာဲ (ကြိ) (စည်းစိမ်ဥစ္စာ၊ အခွင့်အာဏာစသည်) ရုပ်သိမ်းသည်။ ပြန်နုတ်ယူသည်။/ “—၊ မရုပ်ဆာဲဂိုၚ်ကေတ်ကၠေံ ပိုန်ဟာန်ယဿပတ်ညးပၠန်ဂှ် ဒှ်မဟွံဂွံဂြၚ်ဂုန်ညးရ။ ဒှ်ပူဂဵုမဒြိုဟ်ကဵုမိတ်ရ။” (ဇ—၄ဝ၉။ အစွောံ။) = “ပေးအပ်ပြီးသောစည်းစိမ်ဥစ္စာကို ပြန်နုတ်ယူရုပ်သိမ်းခြင်းသည်ကား သူ့ကျေးဇူးကို မသိတတ်ခြင်း အဆွေခင်ပွန်းကို ပြစ်မှားခြင်းမည်၏။”/ “ယွံမိ၊ ကာလသၟိၚ်ရုပ်ဆာဲကၠေံ ပိုန်ဟာန်မိကၠာတေံဂှ် ပသာ်မိပတုဲ သၟိၚ်ဇိုန်ကဵုမိပၠန်ရော” ပြောဟိတ်သၟာန်။ (ဇ—၅၂၂။ အစွောံ။) = “အမိ၊ မင်းသည် အမိအား ယခင်စည်းစိမ်မှ ရုပ်သိမ်းသောကာလ­ အမိသည် အဘယ်သို့ပြု၍ မင်းကအမိအား ထိုစည်းစိမ်ကို ချီးမြှင့်ပြန်ပါသနည်း။”/ “(သၟိၚ်ဖျေံကၠေံပြောဟိတ်တုဲ) ဒြပ်ဂသပ်ပြောဟိတ်နွံညိည (ဒကိုပ်ပၞာန်ဂှ်) ရုပ်ဆာဲစဖအိုတ်။” (သၠပတ်ဒ္ၚောဝ်သၜောံ) = “ပုရောဟိတ်အား မင်းသည် အရာမှချပြီးနောက် ပုရောဟိတ်­ရှိသော အနည်းငယ်သောဥစ္စာတို့ကို ထိုစစ်သူကြီးသည် ရုပ်သိမ်းယူစားလိုက်၏။”
,ရုပ်ပယောဝ်၊ ရုပ်ပယျောဝ် (န) ယဉ်မင်းရုပ်။
,ရုပ်ပဝေၚ်၊ ကောန်ရုပ်ပွေၚ် (န) ကစားစရာအရုပ်။/ ‘ပဝေၚ်/ပွေၚ်’ (န) တွင်ရှု။
,ရုပ္ပါရီု (န) ရူပါရုံ။/ ‘ရူပါရီု’ နှင့်အတူတူ။
,ရုပ်ပုၚ်သမောဝ်၊ ရုပ်ပုၚ်ခၟောဝ် (န) ရေတွင်မြင်ရသော မိမိကိုယ်ရိပ်။/ “(ကၠဵုသမၠီုဂှ်) တုဲဍေံကျောဝ်ရံၚ်ကမၠိုၚ်ဂှ် ဍေံညာတ်ကေတ်ရုပ်ပုၚ်သမောဝ်ဍေံ ပ္ဍဲကမၠိုၚ်ဂှ်ရ။” (သၠပတ်သုရသာ) =“ထိုခွေးမိုက်သည် ရေတွင်းကိုကြည့်သည်ရှိသော် မိမိကိုယ်ရိပ်ကို မြင်၏။”/ “ဇာဒိသိုၚ်ဂှ် ဟွံဂွံဟိုတ်မာဲ အာကျောဝ်ရံၚ်ကမၠိုၚ်ဂှ်တုဲ ဇာဒိသိုၚ်ဂှ်ညာတ်ကေတ် ရုပ်ပုၚ်သမောဝ်ဇာဒိသိုၚ် ပ္ဍဲကမၠိုၚ်ဂှ်တုဲ။” (သၠပတ်သုရသာ)/ “ကမၠိုၚ်ဒမြိုဟ်၊ ဒိုဟ်ဂှ်နွံမွဲ။ — ခါကၠဵုဂွံညာတ်၊ ခါတ်မှာတ်ဂၠာဲကျောဝ်။ ရုပ်ပုၚ်ခမောဝ်၊ ဗီုအၚဝ်ကၠဵု။ ကျောဝ်စှ်ေညာတ်အဵု၊ ကၠဵုပ္တိုန်ဓရံၚ်။” (လိက်မ္ၚဵုပိစှ်ောဒစာံ။ မာံထဝ်စိုပ်။) = “ထိုအရပ်မျက်နှာ­ ကြမ်းကြုတ်သောရေတွင်းတစ်ခုရှိ၏၊ ခွေးသည်သွား၍ ချောင်းကြည့်ကာ မိမိနှင့်အသွင်တူသော ရေမှမိမိကိုယ်ရိပ်ကို မြင်ရသည်ရှိသော်ခွေးသည်မာန်ဖီ၏။”
,ရုပ်ရဴ (န) ၁။ ရုပ်ပုံ။ ရုပ်အသွင်။/ “ဘဒ္ဒေ၊ ဍိုက်ပေၚ်ကဵုစရာဲ ဂေါဝ်ဆာဲရုပ်ရဴ ယွံဒေံဗြဴ။” (သုဓမ္မဒေသနာ။ ဂရိုက်သာံ။) = “အဆင်းအသရေနှင့်ပြည့်စုံသော တင့်တယ်လှပသော ရုပ်အသွင်ရှိသောနှမငယ်။”/ “(ဗညာဓရေမ်) ညာတ်ကောန်ချေံ ရုပ်ရဴကြိုအ်ကျေဝ်ခိုဟ် ဒးစိုတ်ဗွဲမလောန်။” (အကြီုဇာရာဓိရာဇ်) = “သမိန်ဗရမ်းသည် ဝဖြိုးလှပသော မြင်းငယ်ရုပ်အသွင်ကို မြင်သည်ရှိသော် အလွန်နှစ်သက်၏။”/ ၂။ ရုပ်လုံးရုပ်ကြွ။/ “ဆပြာသာဒ်တရၚ်ဝွံတုန်လေဝ် တၟေၚ်ရုပ်ရဴနာနာသာ်ရောၚ်။” (ဇ—၂၂၉။ အစွောံ။) = “တံခါးမုခ်ပြာသာဒ်သည်ပင် အထူးထူးအပြားပြားသော ရုပ်လုံးရုပ်ကြွများဖြင့် တန်ဆာဆင်၏။”/ “သီုရုပ်ရဴပ္ကဴသၠမချူပုတ်လဝ်။” (အကြီုရာဇာဓိရာဇ်) = “အပွင့်အရွက်စသော ရုပ်လုံးရုပ်ကြွများကို ရေးခြယ်ထုဆစ်ထား၏။”
,ရုပ်သာ် (န) ရုပ်ရည်။ ရုပ်အဆင်း။ ရူပကာ။/ နွံကဵုရုပ်သာ်၊ ဍိုက်ပေၚ်တဴကဵုရုပ်သာ် = ရုပ်အဆင်းလှပသည်။ ရုပ်အဆင်းနှင့်ပြည့်စုံသည်။/ အောန်ကဵုရုပ်သာ် = အရုပ်ဆိုးသည်။ အကျည်းတန်သည်။/ “သၟတ်ဗြဴသုန္ဓရဳဂှ် နွံကဵုရုပ်သာ်သန်—။” (ဇ—၂၈၅။ အစွောံ။) = “အမျိုးသမီးငယ်သုန္ဒရီသည် ရုပ်အဆင်းရှိသူဖြစ်၏။”
,ရုပ်သီ (ကြိ) ရုပ်သိမ်းသည်။
,ရုပ်သာဲ (န) ရေထဲ­မြင်ရသောမိမိ၏ပုံရိပ်။/ “သမၠီုမွဲရ၊ ဇၞတ်မကြိုင်အာ။ ဆဵုကၟာမွဲ၊ ပ္ဍဲဂှ်ဟွံခြာ။ညာတ်ရုပ်သာဲဟေၚ်၊ ပ္ဍဲဍာ်သေၚ်ဟာ။ ဖျေံစိုတ်သြာဲဍာ်၊ သပါ်သပါ။ ရုပ်သာဲရောၚ်သွံ၊ ဟွံဗ္စာရဏာ။ ချပ်စှ်ေဗၠိုပ်ရ၊ ပလွဳပရာ။” (လိက်ပဒုမဝတဳ) = “တစ်ယောက်သောသူမိုက်သည် ခြေဦးတည့်ရာသွားရင်း ရေကန်တစ်ခုကို တွေ့သောအခါ ရေထဲ­မိမိပုံရိပ်ကိုမြင်လတ်သော် ရေသရဲဟုထင်မှတ်ပူပန်ကာ ရေမှပုံရိပ်ပါလားဟု မဆင်ခြင်ဘဲ ရေကန်ထဲဆင်း၍ ရေၚုပ်ရန်ကြံစည်အားထုတ်၏။”
,ရောပ်ရေၚ် (ကြိ) ကိုယ်လက်ကိုက်ခဲသည်။/ “ကၠောန်လဝ်ကလောန်ဇြိုၚ်ၚ်တုဲ ရောပ်ရေၚ်ဒၟံၚ်အလုံဇကုမွဲရ။” = “လေးလံသောအလုပ်ကို လုပ်ထားသောကြောင့် တစ်ကိုယ်လုံးနာကျင်ကိုက်ခဲနေသည်။”
,ရမ္မာ (န) ယမနေပင်။
,ရမျှာၚ်၊ ရမ်သာၚ်၊ ရမ္မသာၚ် (န) အသံ။/ “ဒၞာဲညးဒုၚ်ပါၚ်၊ ရမ်သာၚ်မွဲစွံ။” (လိက်ဘောဂရေန်) /“(ကျာ်တြဲ) မၞုံရမျှာၚ် မတုပ်တဴညံၚ်ရဴရမျှာၚ်မှာဗြီုဂှ်—။” (ဇ—၁။ အစွောံ။) = “မဟာဗြဟ္မာ၏အသံနှင့်တူသော အသံတော်ရှိသောမြတ်စွာဘုရား။”
,ရမျှာၚ်ကၠဴ (ကြိ) အသံမပီမသဖြစ်သည်။ အသံလုံးသည်။/ “ရမျှာၚ်ဍေံလေဝ်ကၠဴ။” (လိက်လက္ခဏဒိပ္ပဗိန္ဒော) = “သူ့အသံသည်လည်း လုံး၍မပီမသဖြစ်သည်။”
,ရမျှာၚ်ဇၟူလုပ် (ကြိ) ကြီးကောင်ဝင်သည်။ အပျိုပေါက် လူပျိုပေါက်ဖြစ်လာသည်။
,ရမျှာၚ်ပၞာၚ် (န) အသံဗလံ။/ “သ္ၚောဲခြာနူကဵုဍုၚ်ကွာန်တုဲ ဟွံမိၚ်ရမျှာၚ်ပၞာၚ်မၞိဟ်။” (သၠပတ်စန္ဒဝတဳ) = “မြို့ရွာမှဝေးကွာ၍ လူ့အသံဗလံများမကြားရ။”
,ရမျှာၚ်လရိုအ်တိတ် (ကြိ) ငိုချင်သောကြောင့် တုန်ရီသောအသံဖြစ်ပေါ်သည်။ ငိုသံပါသည်။
,ရမျှာၚ်အပ္ဍဲတိတ် (ကြိ) (ကြောက်လွန်း၍) ငယ်သံပါအောင်အော်သည်။
,ရမျှာၚ်အာတ် (န) အသံဝင်သည်။ အသံတိမ်၍ ပျောက်လုနီးဖြစ်သည်။
,ရာံ (န) ထူထပ်သောတောချုံ။/ (ကြိ) လူဝတ်လဲသည်။/ “ထပိုဲဂှ် ရာံတုဲရ။” = “ထိုကိုရင်သည်လူဝတ်လဲပြီးပြီ။”
,ရီရီ၊ ရိမ်ရိမ် (ကြိဝိ) ၁။ တဖြည်းဖြည်း။/ “ကုန်ဒဵုဂှ် သၠုၚ်တိုန်ဒၟံၚ်ရီရီရ။” = “ထိုတောင်ကုန်းသည် တဖြည်းဖြည်းမြင့်တက်သွားသည်။” (မမတ်စောက်ဟူလို။)/ “ဂၠံဂဝ်နာဲကၠာ၊ ကြံၚ်အာရီရီ။” (လိက်ရတနပဇ္ဇောတ) = “သင့်ကိုယ်ဝန်သည် တဖြည်းဖြည်းရင့်သွား၏။”/ “ဂၠံဂဝ်နာဲကၠာ၊ ကြံၚ်အာရီရီ။” (လိက်ဝါရဝေါၚ်သ။ အစွောံ။) = “သင့်ကိုယ်ဝန်သည် တဖြည်းဖြည်းရင့်လာ၏။”/ ၂။ ဖြည်းဖြည်းညင်းညင်း။/ “သီုတွဳဗွိုၚ် ဇက်တိုန်ရီရီ။” (အာန်ဇုနာန်) = “အခြံအရံများနှင့်တကွ ဖြည်းဖြည်းညင်းညင်း ချီတက်သွား၏။”/ “တက်မွဲအခါ၊ ကျာပိုက်ရီရီ။” (လိက်ကောန်သၟိၚ်ပိ။ မာံခစုန်အံက်။) = “နာရီတစ်ချက်ထိုး၍ ဖြည်းဖြည်းညင်းညင်း လေတိုက်နေ၏။”/ ၃။ တရိပ်ရိပ်။/ “ဂျိတိုန်ရီရီ၊ သ္ၚီပ္ဍဲစိတ္တ။” (လိက်တလိၚ်ပန်) = “တရိပ်ရိပ်အဆိပ်တက်၍စိတ်ထဲမှာ ပူပန်ပင်ပန်းသည်။”
,ရီရီညှာညှာ (ကြိဝိ) ဖြည်းဖြည်းညင်းညင်း။ ဖြည်းဖြည်းသာသာ။/ “ဇက်အာရီရီညှာညှာ။” (အာန်ဇုနာန်) = “ဖြည်းဖြည်းသာသာ ချီတက်သွားသည်။”
,ရုံ (ကြိ) လောက်သည်။/ “(ပုၚ်) ဟွံရုံပၠန် သေဋ္ဌဳတြုံဟွံစ ကဵုကၠေံဒါန်တုဲရ။” (ဇ—၃၄ဝ။ အစွောံ။) = “ထမင်းမလောက်ပြန်သော် သူဋ္ဌေးကြီးသည်မစားဘဲ အလှူပေးလိုက်၏။”
,ရုံဂပ် (ကြိ) လုံလောက်သည်။/ “သွက်ကၟုဲပလုၚ်ဂမၠိုၚ်ဂွံစ ပုၚ်သွရုံဂပ်ဒၟံၚ်ရဟာ။” = “ရပ်ဝေးမှလာသော ဧည့်သည်များစားရန်အတွက် ထမင်းဟင်းလုံလောက်ပါသလား။”/ “ယာတ်မဂၠိုၚ်ကဵုၚုဟ် မရုံဂပ်ကဵုသ္ၚာပိဂှ် ဗဂိန်ကဵုဒါန်ရ။” (ဇ—၄၉၆။ အစွောံ။) = “သင်္ကန်းသုံးထည်အတွက်လုံလောက်သော အဖိုးများစွာထိုက်သောအဝတ်ကို ကပ်လှူ၏။”/ “ပုၚ်သွမရုံဂပ်ကဵုမၞိဟ်မသုန်စဂှ်အဲတောံတိုပ်လဝ်တုဲရ။” = “လူငါးယောက်စားရန် လုံလောက်သောထမင်းဟင်းကို ကျွန်မချက်ပြုတ်ထားပြီးပြီ။”
,ရောံ၊ ရောမ် (ကြိ) မဝံ့မရဲဖြစ်သည်။
,ရောံဂွ (ကြိ) ရှက်ကိုးရှက်ကန်းဖြစ်သည်။/ “ပ္ဍဲဝိုၚ်ဂှ် သၟတ်ဗၠာဲတအ်ကောံဒၟံၚ်တုဲ သၟတ်ဗြဴဝုတ်ဂှ်ရောံဂွဒၟံၚ် ဟွံဂံၚ်လုပ်ရ။” = “ထိုဝိုင်းတွင် လူပျိုများစုဝေးနေကြသဖြင့် ထိုမိန်းမပျိုသည် ရှက်ကိုးရှက်ကန်းဖြစ်၍ မဝင်ရဲပါ။”
,ရောံဆ (ကြိ) မဝံ့မရဲဖြစ်သည်။ ရွံ့သည်။ တွန့်ဆုတ်သည်။/ “ပူဂဵုဟွံရောံဆဂှ် ပ္ဍဲဒေါဝ်ပုရိသာတ်ပန်ဂှ် တိုၚ်ဟွံပေၚ်တရိုပ်စိုတ်။” (ဇ—၄ဝ၂။ အစွောံ။) = “ရဲရင့်သော (မတွန့်ဆုတ်တတ်သော) ပုဂ္ဂိုလ်သည် ပရိသတ်လေးပါးအလယ်­ မရောင့်ရဲနိုင်။”/ “ပ္ဍဲဒေါဝ်ပူရိသာတ်သၟိၚ်ဂှ် မအံက်ရောံဆတဴတုဲ နဂလာန်မွဲသၟိက်ဟီုဂှ် ဂလာန်ဟီုဟွံဒး ဂလာန်သ္အာၚ်ရောၚ် မဟီုဒးစုတ်—။” (ဇ—၂၁၁။အစွောံ။) = “မင်းပရိသတ်အလယ်­ ဖခင်သည် မရဲမဝံ့ရွံ့သည်ဖြစ်၍ ပြောလိုသောစကားကို မပြောတတ်ဘဲ အခြားတစ်ပါးသောစကားကိုသာလျှင် ပြောလိုက်မိ၏။”/ “ဖေက်ဂွတဴကီု၊ ဟီုသီုရောံဆ။” (လိက်ကောန်သၟိၚ်ပိ။ မာံခစုန်အံက်။) = “ရှက်ကြောက်သည်ဖြစ်၍ မဝံ့မရဲပြောဆို၏။”/ “အမာတ်တအ်မာ၊ သေဏာတအ်ရ။ ယာံမိၚ်အသံ၊ သီုမရောံဆ။ ပၚ်တဲတယျောဝ်၊ လ္ၚောဝ်ဂၠးပါဒ။” (လိက်ဇိဝှစက္က) = “အမတ်သေနာပတိတို့သည် အမိန့်တော်ကို ကြားသည်ရှိသော် မဝံ့မရဲဖြင့် လက်အုပ်ချီကာ ရွှေဖဝါးတော်အစုံကို ဦးခိုက်ကြကုန်၏။”
,ရောံညှာ (ကြိ) ရိုသေလေးမြတ်သည်။ ရိုသေခန့်ညားသည်။/ “ယွံမၞးတံ၊ ရာဟုလကုမာဝွံ ရောံညှာပ္ဍဲသိက္ခာပိုတ်သန်” ခမဳတံဂး။ (ဇ—၃၁၉။ အစွောံ။) = “ငါ့သျှင်တို့၊ အရှင်ရာဟုလာသည်သိက္ခာပုဒ်တော်­ အလွန်ရိုသေလေးမြတ်၏” ဟုရဟန်းတို့ဆို၏။/ “(လောသကထေဝွံ) ရောံညှာသီုအဲပရဲရဴဂဴကဵုထေသာရိပိုတ်တုဲ (ၜိုန်ထေသာရိပိုတ်ကော်က္ညကီုလေဝ်) ဟွံဂံၚ်ကဵုပိုန်ရ။” (ဇ—၄၁။ အစွောံ။) = “လောသကမထေရ်သည် အရှင်သာရိပုတ္တရာအား ရိုသေတုံ့ဝပ်ခန့်ညားသည်ဖြစ်၍ အရှင်သာရိပုတ္တရာက ခေါ်တော်မူသော်လည်း ဆွမ်းမဘုဉ်းဝံ့။”
,ရောံဒည၊ ရောံဓည (ကြိ) မဝံ့မရဲဖြစ်သည်။ ရွံ့သည်။/ “(ဗောဓိသတ်စၞေဟ်ကဵုကလော်) ဟွံဖေက်ဂၟံက် ဟွံရောံဒညသက်သက်ဟေၚ်။” (ဇ—၅၅။ အစွောံ။) = “(ဘုရားလောင်းသည် ဘီလူးနှင့်စစ်ထိုးရာတွင်) ကြောက်ခြင်းမရှိသည်သာလျှင် ရွံ့ရှားခြင်းမရှိုသည်သာလျှင်ဖြစ်၏။” (ညောင်ကန်)
,ရောံပြဝါ၊ ရောမ်ပြဝါ (န) အပေါင်းအဖော်။ အခြံအရံ။/ “ဒေဝဳအဂ္ဂ၊ ဒ္ၚဳပယာတြာ။ — သီုရောံပြဝါ၊ဂကူသာကျ။” (လိက်ဗောဓိသတ်စှ်။ ပဏ္ဍိတ။) = “အဂ္ဂဒေဝီမိဖုရားသည် သာကီဝင်မင်းမျိုးဖြစ်သော အခြံအရံများနှင့်တကွ ဖြည်းဖြည်းသာသာ ကြွမြန်းတော်မူ၏။”/ “ဗောဓိသတ်ကီု၊ သီုရောံပြဝါ။” (လိက်သၟိၚ်စိၚ်ဆဒ္ဒန်။ နာဲထဝ်စိုပ်။) = “ဘုရားလောင်းနှင့်တကွ အပေါင်းအဖော်အခြံအရံများ။”
,ရီု (ကြိ) ကူသည်။ ကူညီသည်။/ “အဲသ္အာရီုမရ။” (ဇ—၄ဝဝ။ အစွောံ။) = “သင့်အား ငါသွားကူအံ့။”/ “ညးသ္ကဵုဍာ်ပုၚ်၊ ညးဂှ်ကၠုၚ်ရီု။” (လိက်ပုညကာရဳ) = “မည်သူသည် ထမင်းအဖျော်တို့ကိုပေး၍ မည်သူသည် လာကူပါမည်နည်း။”/ “ကုသဵုဟွံရီု၊ သီုပိုဲညးၜါ။” (လိက်ပဒုမဝတဳ) =“ငါတို့နှစ်ဦးစလုံးကို ကုသိုလ်မကူ။”
,ရီုဇအ် (ကြိ) ကူညီသည်။ ပံ့ပိုးသည်။
,ရီုဇျဲ၊ ရီုဇျောဲ (ကြိ) ကူညီသည်။/ “ညးသ္ဂောံရီုဇျောဲ၊ ဟွံမွဲဆောံမ။” (လိက်ပထမဗောဓိ။ မၚ်ဍိက်လ။) = “ကူညီစောင့်မမည့်သူမရှိ။”
,ရီုထံက် (ကြိ) ကူညီသည်။ ထောက်ကူသည်။
,ရီုဗၚ် (ကြိ) ကူညီသည်။ ရိုင်းပင်းသည်။/ “မိတ်သဟာဲဂှ် ဂွံရီုဗၚ်ပြာ်ဒဒိုက်ရောၚ်။” (ဇ—၄၈၆။ အစွောံ။) = “အဆွေခင်ပွန်းမည်သည် ကူညီရိုင်းပင်းရန် ဒုက္ခမှကယ်ရန်ဖြစ်သည်။”/ “ဒါန်ကုသဵုဟေၚ်၊ ရီုဗၚ်သေၚ်ဟာ။” (လိက်မေဃကောန်ဒြာဲ) = “ဒါနကုသိုလ်က ကူညီစောင်မသည်ဟုတ်သလော။”
,ရီုသဘာ် (ကြိ) ကူညီဖေးမသည်။/ “သီုညးဂမၠိုၚ်၊ ဗိုၚ်ရီုသဘာ်။” (လိက်ဇမ္ဗူပတိ။ မာံဒေံဍောတ်) = “လူအများဝိုင်ဝန်းးကူညီဖေးမသည်။”
,ရာဲ (န) မုန်ညင်း။/ “ရာဲကီု မူလာကီု က္ဍိုပ်ကြဴကီု က္ဍိုပ်ကွာဲကီု—။” (ဇ—၅ဝ၅။ အစွောံ။) =“မုန်ညင်းကို၄င်း မုန်လာကို၄င်း ပိန်းဥကို၄င်း မျောက်ဥကို၄င်း—။”/ ခၟာဲရာဲ = မုန်လာဥ။
,ရာဲကၞပ် (န) ဆလတ်ရွက်။
,ရာဲကြုက် (န) ဂေါ်ဖီထုပ်။
,ရာဲဇမာတ်၊ ရာဲဇၟာတ် (န) ရာဇမတ်အကာအရံ။/ ‘ရာဇမာတ်’/‘ရာဇာဒၟာတ်’ ရှု။
,ရာဲဇိုန်၊ ရာဇိုန် (သသက်) (န) သစ်မွှေး။/ “ရာဲဇိုန်စလန်အဴ၊ စဳရေၚ်တဴဟွံခြာ။” (လိက်သၠပတ်သၟိၚ်ပဿိုန်) = “သစ်မွှေး၊ စန္ဒကူးနံ့သာတို့ကို မပြတ်မလပ်စီရင်ထား၏။”/ “ရာဇိုန်စလန်။ ဒသဂန္ဓ။” (လိက်ပထမဗောဓိ။ မၚ်ဍိက်လ။) = “သစ်မွှေးစန္ဒကူး ဆယ်မျိုးသောရနံ့။”
,ရာဲတံၚ်ခေါန် (န) ကုက္ကား။ ရဲတံခွန်။/ “ဇၞောဝ်ရာဲတံၚ်ခေါန်တံဂှ် ကဵုသြံက်ဗျိၚ်လဝ်တုဲ—။” (ဇ—၄၉၇။ အစွောံ။) = “တံခွန်ကုက္ကားတို့ကို စိုက်ထူစီတန်းထားစေ၍—။”
,ရာဲတၞး (န) မုန်လာရွက်။ အရွက်စားသောမုန်လာ။
,ရာဲဏဳ (န) မုန်လာ။/ ရိုဟ်ရာဲဏဳ = မုန်လာမြစ်။ (ပါဠိ—မူလကမူလ)
,ရာဲပ္ကဴ (န) ဂေါ်ဖီပန်း။
,ရာဲသဳ၊ ရာဲသြဳ (န) ပီယဆေး။ လူချစ်ခင်စေတတ်သောဆေး။/ “သၟိက်ဒှ်ရာဲသဳ၊ အနဳကာလ။ ဇၟာပ်ကောန်ဂကူ၊ လ္ဂူကဵုမိမ။ မိမသ္ဍိုက်လောန်၊ ကောန်ဂှ်မူလ။ သာ်ဝွံအနဳ၊ ဒှ်ရာဲသဳရ။” (လိက်နဲယသမုဒ္ဒြဳ။ အစွောံ။) = “ပီယဆေးကို အမှန်လိုချင်ပါက အမျိုးကောင်းသားတိုင်းသည် မိဘအပေါ်ရိုးသားသစ္စာရှိပါ။ မိဘချစ်သောသားသမီးသည်ကား ပီယဆေးအမှန်ပင်ဖြစ်တော့သည်။”/“လက်သတ်ဍုန်တှ်၊ အာစာတွံဂၠာဲ၊ ရာဲသြဳဇၞော်အိုတ်။” (လောကသိဒ္ဓိ။ အစွောံ။) = “ရင်သား­ မွေးရာပါအမှတ်စွဲပါက အကြီးဆုံးသောပီယဆေးဟု ဆရာများဟောကုန်၏။”/ “(ကလော်ဗြဴဂှ်) ဍေံလုပ်စုတ်ဂဥုဲရာဲသဳ ပ္ဍဲကောန်သၟိၚ်တုဲ—။” (သၠပတ်စန္ဒဝတဳ) = “ထိုဘီလူးမသည် ဝင်သွားကာမင်းသားအား ပီယဆေးကိုထည့်၏။”/ “သ္ဍိုက်မၠိုက်တဴကွေံ၊ ညံၚ်ဒးရာဲသဳ။” (လိက်ကောန်သၟိၚ်ပိ။ မာံခစုန်အံက်။) = “ပီယဆေးထိထားသကဲ့သို့ တကယ်ချစ်နှစ်သက်၏။”/ “လေပ်မန်ယန်ဆာဲ၊ လေပ်ကွတ်ရာဲသြဳ။” (လိက်သၟိၚ်ဇဲယဒတ္တ) = “မန္တန်မန္တရားကိုတတ်၍ ပီယဆေးအတတ်ကိုတတ်၏။”
,ရာဲသဳဓတ် (န) မုန်ညင်း။/ “ညံၚ်မရာဲသဳဓတ် ဍောတ်သွတ်ဇိပ်ကၠိပ်လောန်ဂှ်။” (ဓမ္မဒဳပနဳ။ မာံရွှေငိုး။) = “သေးငယ်သိမ်မွေ့သော မုန်ညင်းစေ့ကဲ့သို့။”/ ကၠေၚ်ရာဲသဳဓတ် = မုန်ညင်းဆီ။
,ရာဲသာတ် (ကြိ) ၁။ ထူးဆန်းသည်။ ဆန်းပြားသည်။/ “ယွံတၠသ္ၚိ၊ အၚပ်အဲဒှ် အဲသၟိက်စခ္ဍောၚ်မတ်ဗမၞးဂှ်ကွေံရောၚ်။ တၠသ္ၚိကေတ်ကဵုအဲညိအဴ” ခ္ဍာ်ဗြဴဂး။ “ၝောံဏအ်မွဲ ရာဲသာတ်ကွေံရောၚ်။ခ္ဍောၚ်မတ်ဗမၞးဂှ် ဂွံမာန်ကီုဟာ” ခ္ဍာ်ကၟက်ဂး။ (ဇ—၃၈၉။ အစွောံ။) = “သခင်၊ ငါ့အား ပုဏ္ဏား၏မျက်လုံးကို စားလိုသောချင်ခြင်းသည်ဖြစ်၏။ သခင်ယူပေးပါ” ဟုကျီးမ၊ဆို၏။ “ရှင်မ၊ သင်သည်ကား ထူးခြားဆန်းပြားစွ။ (ပေါက်ပေါက်ရှာရှာ) ပုဏ္ဏား၏မျက်လုံးမည်သည် ယူ၍ရရိုးလား” ဟုကျီးဖိုဆို၏။/ “မဒးသှ်သၟာန်၊ ဂလာန်ရာဲသာတ်။” (လိခ်မဒံက်ခေဝ်) = “ထူးဆန်းသောစကားဖြစ်သော အမေးကိုဖြေရ၏။”/ “သဂါတ္ၚဲလောန်၊ ဆိုက်ညန်ယးကၠာ။ သၟိၚ်လပအ်ညာတ်၊ ရာဲသာတ်သေၚ်ဟာ။” (လိက်ဝိဓူရ) = “သန်းခေါင်ယံလွန်၍ အရုဏ်ကျင်းခါနီး­ မင်းသည် ထူးဆန်းသောအိပ်မက်ကို မြင်မက်၏။”/ “သီုပိုဲညးၜါ၊ သ္ဒဟ်မှာဥပါတ်။ လ္ပအ်ရာဲသာတ်၊ဒးညာတ်ရောၚ်မိ။” (လိက်ပဒုမဝတဳ) = “ငါတို့နှစ်ဦးစလုံး ဘေးဥပါတ်ကြီးသင့်မည်ကြောင့် ထူးဆန်းသောအိပ်မက်ကို မြင်မက်ရခြင်းဖြစ်မည်—မယ်။”/ “ခါကကြၚ်ထဝ်၊ အသဝ်ဂၠိုၚ်သာ်။ ညးဗစိုပ်ကျာ်၊ ခါကျာ်ဂွံညာတ်။ အသဝ်ရာဲသာတ်၊ ညာတ်တုဲသ္ဂးရ။” (လိက်မ္ၚဵုပိစှ်ောဒစာံ။ မာံထဝ်စိုပ်။) = “အံ့ဖွယ်များသော ရွှေငါးကြင်းကို မြတ်စွာဘုရားထံပို့ဆောင်၍ အံ့ဖွယ်ထူးခြားဆန်း ပြားသည်ကို မြတ်စွာဘုရားမြင်တော်မူ၍ မိန့်တော်မူ၏။”/ ၂။ ကွဲကွာသည်။ အဆက်ပြတ်သည်။/ “အဵုဂၠုဂေါဝ်လောန်၊ ကောန်ဨကရာတ်။ ဗှ်ဒးခြာသာဲ၊ နူနာဲမန္ဓာတ်။ ကလောဟွံမွဲ၊ အဲကၠုၚ်ရာဲသာတ်။” (လိက်သၚ်ဂဒါ။ သဳလဝန္တ။) = “ရုပ်အဆင်းတင့်တယ်သော အို—မယ်မယ့်ချစ်သား ဘုရင့်သား၊ ဆွေမျိုးမရှိသောအရပ်­ သင်ချစ်သားနှင့် လာကွဲကွာရပြန်၏။”
,ရုဲ (န) ယင်ကောင်။/ (ကြိ) ရွေးသည်။/ “(ဂစေံဒဂိုတ်ဂှ်) ဟွံသုၚ်ဍာ် ဟွံစစၞ ဇြာဲသကှ်ဒၟံၚ် ဆဇုတ်မသှ်ေရ။ တၠကသာပ်တံညာတ်တုဲ ရုဲထောံကၠေံ ဟွံရာန်ရ။” (ဇ—၁၁၈။ အစွောံ။) = “ထိုငုံးငှက်သည် ရေမသောက် အစာမစား ပိန်ခြောက်ကာ အရိုးမျှသာကျန်၏။ ဝယ်သူများမြင်သော်မဝယ်ကြဘဲ ရွေးပယ်လိုက်ကြကုန်၏။”
,ရုဲကံက် (ကြိ) ရွေးယူသည်။ ရွေးကောက်ယူသည်။
,ရုဲကေတ် (ကြိ) ရွေးယူသည်။/ “ဒၞာဲမဒးဂၞပ်ဂှ် ရုဲကေတ်မွဲညိ။၊” = “လိုချင်တာတစ်ခုကို ရွေးယူပါ။”
,ရုဲစှ် (ကြိ) ၁။ ရွေးချယ်သည်။/ “အပေါတ်ကယိုင်နွံဂၠိုၚ်ရ။ ဒၞာဲဒးစိုတ်ဂှ် ရုဲစှ်ကေတ်ညိ။” = “အဆင်တန်ဆာများစွာရှိသည်။ ကြိုက်ရာကို ရွေးချယ်ယူပါ။”/ “ပိုဲဍိက်ဟီုအကြီုသၟိၚ်ပဿိုန် မရုဲစှ်သၚ်မကဵုဒါန်ရောၚ်အဴ။” (ဇ—၄၉၅။ အစွောံ။) = “ကောသလမင်း၏ သံဃာတော်များကိုရွေးချယ်၍ အလှူပေးသောအကြောင်းကို တပည့်တော်တို့ ပြောဆိုကြပါကုန်၏။”/ ၂။ (တောင်းကြေးကိုပေး၍) ရွေးယူသည်။ နုတ်ယူသည်။/ “ကမၠတ်တံဂှ် ယဝ်ဍေံရပ်ဂွံကောန်ကဵုမမ္ဂး ကောန်ဂှ် ဍေံတံရပ်လဝ်တုဲ ဗလးကၠေံမဂှ် ကဵုအာကေတ်နၚ်ဒြပ်ရတ် သွက်ဂွံရုဲစှ်ကေတ်ကောန်ဂှ်ရ။” (ဇ—၄၅၉။ အစွောံ။) = “ထိုခိုးသူတို့သည် သားအဖနှစ်ယောက်ကို ဖမ်းမိပါက သားကိုချုပ်ထား၍သားကိုရွေးယူရန်အတွက် အဖကိုလွှတ်၍ ဥစ္စာယူလာစေ၏။”
,ရုဲစှ်ဂၠဟ် (ကြိ) ရွေးချယ်သည်။ စိစစ်ရွေးချယ်သည်။/ “တၠပညာတမၠာတမၠာတေံဂှ် ၜိုန်ကျာ်ဟွံမွဲကီုလေဝ် ရုဲစှ်ဂၠဟ်တုဲ မကဵုဒါန်ဂှ် မဂပ်ဂဝ်ပအသဝ်ရောၚ်။” (ဇ—၄၉၅။ အစွောံ။) = “ရှေးပညာရှိတို့သည် ဘုရားရှင်တို့သည်မရှိသော်လည်း ရွေးချယ်စီစစ်၍ အလှူပေးခြင်းသည်သာ အံ့ဖွယ်ဖြစ်၏။”/ “ပ္ကဴသာ်တၞဟ်ဟ်သာ်တံဂှ် ရုဲစှ်ဂၠဟ်တုဲ အဲပြေၚ်ပကောံလဝ်ရ။” (ဇ—၅ဝ၄။ အစွောံ။) =“အဆင်းအရောင်အမျိုးမျိုးရှိသော ပန်းတို့ကိုရွေးချယ်၍ ငါစုစည်းထား၏။”/ “(သတ်ဆုတံဂှ်) ဒၞာဲမဍုဟ်လေဝ်ဍုဟ် ဒၞာဲမတ္ၜတ်လေဝ်တ္ၜတ် ရုဲစှ်ဂၠဟ်တုဲ သြဝ်ပပြဘိုက်ရ။” (ဇ—ဝေသန္တဝ်။ အစွောံ။) = “သစ်သီးတို့သည် မှည့်သည်များလည်းမှည့်၍ နုသည်များလည်းနု၏။ ကြိုက်ရာရွေးချယ်၍ သုံးဆောင်ပါလော့။”/ “သစ္ဆုတံဝွံ ရာမဍုဟ်ရုဲစှ်ဂၠဟ်တုဲ သြဝ်ပပြဘိုက်ရ။” (ဇ—ဝေသန္တဝ်။ အစွောံ။) = “ဤသစ်သီးတို့ကို မှည့်ရာရာရွေးချယ်၍ သုံးဆောင်ပါလော့။”/ ‘စှ်ဂၠဟ်’ (ကြိ) လည်းရှု။
,ရုဲစၞ (ကြိ) အစာရွေးသည်။ အစားအသောက်တွင် ကြေးများသည်။/ “မၞိဟ်တၠပိုန်တံဂှ် စၞခိုဟ်ညးမဂွံပပြဘိုက်ရောၚ်။ ပိုဲဂစေံသတ်ယုတ်ရောၚ်၊ လ္ပရုဲစၞရ” ဖရာပ်ဂးကဵုခ္ဍာ်။ (ဇ—၂၇၄။ အစွောံ။) =“စည်းစိမ်ရှင်လူတို့သာလျှင် အစာကောင်းကို သုံးဆောင်ရကုန်၏။ ငှက်ဖြစ်သောငါတို့သည်ယုတ်သောသတ္တဝါဖြစ်၏။ အစာမရွေးလေနှင့်” ဟုခိုသည် ကျီးအားပြော၏။
,ရုဲဒွၚ် (န) ယင်မမဲရိုင်း။ ယင်ကောင်အကြီးမျိုး။/ “ဂစေံတၞောတ်ဗြဴဂှ် အာသဳကၠဳရုဲဒွၚ်ဂှ်ပၠန်ရ။” (ဇ—၃၅၇။ အစွောံ။) = “(နှံစုတ်ငှက်မသည်) တစ်ခုသောယၚ်မမဲရိုင်းကို ခစား၏။” (ညောင်ကန်)
,ရုဲပၠာ (န) ယင်ရဲ။ (?)
,ရုဲမုက်၊ ရုဲမုက်မတ် (ကြိ) မျက်နှာရွေးသည်။ မျက်နှာလိုက်သည်။ လိုလားသူ မလိုလားသူဟူ၍ ခွဲခြားသည်။
,ရုဲမာဲ (ကြိ) မဲဖြင့်ရွေးကောက်သည်။/ ပေဲါရုဲမာဲ = ရွေးကောက်ပွဲ။
,ရုဲသောဲ၊ ရုဲသောန် (န) ယင်ငယ်။/ “ဗောဓိသတ်တုန်လေဝ် ဗက်ဗ္ဒဴကၠေံသၟိၚ်ထပှ်က္ဍိုၚ်ဗ္တာၚ် ဆဗၞတ်ရုဲသောဲမွဲသုၚ်ဂွံကီု ဆီညးဟွံဂွံတိတ်သက်က်ဟေၚ်။” (ဇ—၁၈၁။ အစွောံ။) = “ဘုရားလောင်းသည် တခုသောယင်ငယ်သည် သောက်လောက်ရုံသော သွေးကိုလည်းမဖြစ်စေမူ၍ ခုနစ်ပြည်ထောင်ကုန်သောမင်းတို့ကို ပြေးစေ၍—။” (ညောင်ကန်)/ “ယွံမရှာတ်၊ သတ္တံဂမၠိုၚ်ဂှ် ဆဗၞတ်ရုဲသောန်ဍောတ်မွဲ သုၚ်ဂွံဂှ်လေဝ် ဟွံကဵုဆီတိတ်သက်က်ရ။” (ဇ—၅၃၂။ အစွောံ။)
,ရုဲၜိုတ် (ကြိ) ရွေးချယ်ကောက်ယူသည်။/ “တၠကွတ်လ္ၚတ် ပါန်မုတ်၊ ပါန်ခဳ၊ ဗဳသကဝ်၊ သၟာတဲ၊ တၠပညာသၟာကလောန်တံဂှ် ဗောဓိသတ်ရုဲၜိုတ်ဏာဖအိုတ်—။” (ဇ—မဟောဟ်သဓ။ အစွောံ။) =“ပန်းပွတ်၊ ပန်းချီ၊ ဗိသုကာ၊ လက်သမား၊ လက်မှုလက်ရာအတတ်ပညာရှင်များကို ဘုရားလောင်းသည် ရွေးချယ်ကောက်ယူ၏။”
,ရေဲ (ကြိ) မျှင်သည်။ အစိတ်စိတ်အမြွာမြွာဖြစ်အောင် ခွဲဖြာသည်။/ ရေဲဖျုန်ကဵုမြ = ဓါးနှင့် အသားကိုမျှင်သည်။/ ရေဲဆု = သစ်ကို ပါးပါးဖြစ်အောင် ခွဲဖြာသည်။
,ရဝ်ရဝ် (ကြိဝိ) တရစပ်။ အဆက်မပြတ်။/ “ကျာၜဳလဝိုက်၊ ပိုက်ကၠုၚ်ရဝ်ရဝ်။” (လိက်သောဝိန်ဇဲယ။ မာံရောဂေါ။) = “ပင်လယ်လေသည် တရစပ်တိုက်ခတ်လာ၏။”
,ရေဝ်ရောတ် (ကြိ) ‘ရေရောတ်’ ရှု။
,ရေဝ်ရေဝ် (ကြိဝိ) (နေ) ညိုညို။ (နေပူရှိန်) ညှိုးညှိုးမှိန်မှိန်။/ “ဂၠာဲၚုဲဂၠာဲက၊ ဂၠာဲစခၞေဝ်။ ရိုဟ်တ္ၚဲဟွံဖိုတ်၊ သီုစိုတ်ဂၠာဲသ္ၚေဝ်။ တ္ၚဲသဝ်ရေဝ်ရေဝ်၊ ညးတိတ်တေဝ်ဖျာ။” (လိက်ကကၠာ်။ ကောန်ဍး။) =“ပုစွန်၊ ငါး၊ ဟင်းရွက်တို့ကို နေ့စဉ်မပြတ် စိတ်ပါလက်ပါရှာဖွေ၏၊ ညနေချမ်းအချိန် နေပူရှိန်ညှိုးညှိုးမှိန်မှိန်ဝယ် သူတကာတို့ ထွက်၍ဈေးတည်ခင်းကြ၏။”/ “တ္ၚဲသဝ်ရေဝ်ရေဝ်၊ ကျာၜဳကလေၚ်။” (လိက်ကကၠာ်။ ကောန်ဍး။) = “နေညိုချိန်­ ပင်လယ်လေပြန်လှည့်တိုက်ခတ်သည်။”
,ရဵု၊ ရိုဝ် (ကြိ) စကားသံဝဲသည်။ စကားဝဲသည်။
,ရှ် (ပါသက်) (န) ၁။ အရသာ။/ ‘ (ဂၠဴမ္ဂးဂှ်) ကမတ်ချောဲဆံက် မအောန်ကဵုရှ်ဂှ် မစရ။’ (ဇ—၂၈၆။အစွောံ။) = ‘နွားတို့သည် အရသာနည်းပါးသော မြက်ကောက်ရိုးတို့ကို စားရ၏။’/ ၂။ မြေဆီသြဇာ။/ “တိနွံရဟ်ကွေံ၊ ဖျေံမသဒ္ဓါ။” (လိက်လက္ခဏပိ) = “တကယ်မြေဆီသြဇာရှိသောမြေ­ သဒ္ဓါတည်းဟူသောမျိုးစေ့ကို ချ၏။”
,ရှ်ဍောၚ်ပ္ကဴ၊ ရှ်ပ္ကဴ (န) ပန်းဝတ်ရည်။ မြဝတ်ရည်။/ “ညံၚ်ရဴထိုၚ်ထဝ် မဂၠာဲဇာပ်ရှ်ဍောၚ်ပ္ကဴကီု။” (ဇ—၃၉၆။ အစွောံ။) = “ပန်းဝတ်ရည်ကိုစုပ်သော ရွှေပိတုန်းကဲ့သို့။”/ ‘ညံၚ်သာဲမဂၠာဲၚဳရှ်ဍောၚ်ပ္ကဴကီု။’ (ဇ—၈၄။ အစွောံ။) = “ပန်းဝတ်ရည်ကို ရှာသောပျားကဲ့သို့။”/ “ဂွံရှ်ပ္ကဴဟေၚ်၊ ပဝ်ကလေၚ်စဴ။ ရှ်ပ္ကဴဖဲစိုတ်၊ ထိုၚ်ဝိုတ်ဍောၚ်ပ္ကဴ။” (လိက်သၟိၚ်ဇဲယဒတ္တ) = “ပန်းဝတ်ရည်ကို ရရှိပြီးနောက် ပျံ၍ပြန်၏၊ ပန်းဝတ်ရည်ဖြင့် ရောင့်ရဲပြီးနောက် ပိတုန်းသည် ပန်းပွင့်တို့ကို မေ့၏။”
,ရှ်တိ (န) မြေဆီမြေနှစ်။ မြေဆီသြဇာ။/ “သၟိၚ်ဟွံမၚ်မွဲဓဝ်တုဲ ရှ်တိဟွံမွဲ—။” (ဇ—၃၃၄။ အစွောံ။) = “မင်းသည် တရားမစောင့်သဖြင့် မြေဆီသြဇာမရှိ။”
,ရှ်ပ္ကဴ (န) ‘ရှ်ဍောၚ်ပ္ကဴ’ (န) ရှု။
,ရှ်ဗတဝ်တိ (န) မြေဆီမြေနှစ်။/ “ရှ်ဗတဝ်တိ၊ ကိုပ်အာဒိဟေၚ်။ မောဝ်လမာဲထီု၊ ဗြီုစိုတ်ဒစေၚ်။ ဗြီုထပှ်ဟေၚ်၊ လၟေၚ်လောဘ။ စှ်ေစရှ်တိ၊ အာဒိကပ္ပ။” (လိက်မေဃသန်) = “ကမ္ဘာဦးအစ­မွှေးကြိုင်နေသော မြေဆီမြေနှစ်ရနံ့ကြောင့် ဗြဟ္မာခုနစ်ယောက်တို့သည် စိတ်ကိုမချုပ်တည်းနိုင်ဘဲ ထိုမြေဆီမြေနှစ်ကို ဆင်းစားကြကုန်၏။”
,ရှ်ဗပေဟ်တိ (န) မြေလွှာသြဇာ။ (ပါဠိ—ပပ္ပဋကောဇ)
,ရှ်ဗှ် (န) အရသာ။/ “သွဂှ်ဍာ်ဂၠိုၚ်အာ အောန်ကဵုရှ်ဗှ်ရ။” = “ထိုဟင်းသည် ရေများ၍ အရသာနည်းပါးသည်။”
,ရှ်လိက်ပတ်ဒစိတ်ပြကာ (န) စာပေရသကိုးမျိုး။ (၁။ သိၚ်္ဂရရသ ၂။ ဟဿရသ။ ၃။ ကရုဏာရသ။ ၄။ ရုဒ္ဒရသ။ ၅။ ဝီရရသ။ ၆။ ဘယာနကရသ။ ၇။ ဝိဘစ္ဆရသ။ ၈။ အဗ္ဘုတရသ။ ၉။သန္တရသ။)
,ရှ်သာ (န) အရသာ။ အနှစ်သာရ။/ “ယွံဂစေံမပြဲ၊ ဗရုတၠအဲ ဇိပ်ဂၠိပ်ဍိုန်ဍောတ် နွံတဴကဵုရှ်သာကွေံရောၚ်သွံ။” (ဇ—၂၆၉။ အစွောံ။) = “အိုမြတ်သောငှက်၊ သင်၏အသံသည် သာယာပြေပြစ်၍အလွန်အရသာရှိလှ၏။”/ “ဓဝ်မစိုန်ဒှ်၊ လအိတ်ရှ်သာ။” (လိက်ပထမဗောဓိ။ မၚ်ဍိက်လ။) =“အထွတ်အထိပ်အရသာဖြစ်သောတရားတော်။”
,ရှ်အမြိုတ် (န) အမြိုက်အရသာ။/ “(သၟတ်ဗြဴဂှ်) ချိုန်မမိၚ်ပါၚ်ဗောဓိသတ်ဗက်ဂှ်ရ ညံၚ်ရှ်အမြိုတ်ဗတဝ်သာဲ ညးမဖျုၚ်လဝ်ပ္ဍဲကတောဝ်ကီု (မဒှ်ရ။)” (ဇ—၃၈၇။ အစွောံ။) = “ထိုမိန်းမပျိုသည်ဘုရားလောင်းနှုတ်သံကို ကြားရသည်နှင့် အမြိုက်အရသာပျားသကာကို နားထဲတွင်သွန်းလောင်းသည့်နှယ်ဖြစ်၏။”
,ရှ်ေသှ်ေ (ကြိ) ၁။ ရိုသေလေးစားသည်။ ရိုသေလေးမြတ်သည်။/ “ပ္ဍဲလိုက်ဝွံ မူရဴပူဂဵုမွဲ မဥပကာမိမ မရှ်ေသှ်ေအဲပရဲ ညးမဗျုဇၞော်ညိသ္ဂးဟာ။” (ဇ—၃၄၄။ အစွောံ။) = “လူ့ပြည်­ အဘယ်သူတို့သည် အမိအဘတို့ကို လုပ်ကျွေးကုန်သနည်း။ အမျိုး­ကြီးသောသူတို့အား အရိုအသေအမှုကိုပြုကုန်သနည်း။” (ညောင်ကန်)/ “သၟိၚ်ရှ်ေသှ်ေရဴဂဴအဲဂှ် ဟိုတ်နူဓဝ်သဳလအဲမ္ဂးဟာ” ဗမၞးချပ်။ (ဇ—၃၆၂။ အစွောံ။) = “မင်းသည် ငါ့ကို ရိုသေလေးမြတ်သည်မှာ ငါ၏သီလတရားကြောင့်ပေလော။”/ ၂။ အလေးပြုသည်။/ “ရှ်ေသှ်ေအလာံကောန်ဂကူမန်။” = “မွန်အမျိုးသားအလံတော်ကို အလေးပြုသည်။”
,ရောဟ် (ကြိ) လှည့်လည်သည်။ လှည့်ပတ်သည်။ (?)/ “ယဵုဂွံစန်အှ်ော၊ ကော်သွံရောဟ်အာ။” (လိက်သုပိဏ္ဏကုမ္မာ။ မၚ်သၚ်ကြာ။) = “ထင်းစည်းကိုရွက်ကာ ခေါ်ရောင်းလျက် လှည့်ပတ်သွား၏။”/ “တ္ၚဲယးအာအှ်ော၊ ရောဟ်ဒၟံၚ်ဇိုၚ်ဝါ။” (လိက်သုပိဏ္ဏကုမ္မာ။ မၚ်သၚ်ကြာ။) = “မိုးလင်းသောအခါ ထင်းခွေသွားကာ လွင်ပြင်အစပ်တွင် လှည့်လည်နေ၏။္ဒ”/ (ကြိဝိ) တွေ့ကရာ။ပေါက်ကရ။/ “ဟီုဒၟံၚ်ရောဟ်။” = “တွေ့ကရာပေါက်ကရ လျှောက်ပြောသည်။”
,ရိုဟ် (န) အမြစ်။/ ရိုဟ်ဆု = သစ်မြစ်။/ ရိုဟ်ဂဥုဲ = ဆေးမြစ်။/ (ကြိ) ၁။ ရေတွက်သည်။/ရိုဟ်သြန် = ငွေကိုရေတွက်သည်။/ ရိုဟ်မၞိဟ် = လူအရေအတွက်ကို ရေတွက်သည်။/ ၂။ အစိတ်စိတ်ဖြစ်အောင်ဖြိုသည်။ ဖျက်သည်။/ “တာဲတြေံဂှ် ညးရိုဟ်ထောံတုဲ သိုၚ်လဝ်တာဲတၟိရ။”= “တဲဟောင်းကိုဖျက်ပြီး တဲသစ်သူဆောက်ထားသည်။”/ “ရုၚ်ဒါန်တံဂှ် (သေဋ္ဌဳ) ရိုဟ်ပလီုကၠေံတုဲ—။” (ဇ—၅၃၅။ အစွောံ။) = “သူဋ္ဌေးသည် အလှူတင်းကုပ်တို့ကို ဖြိုဖျက်စေ၏။”/ (နဝိ) တိုင်း။/ ရိုဟ်တ္ၚဲ = နေ့တိုင်း။/ ရိုဟ်သၞာံ = နှစ်တိုင်း။/ (စည်း) တိုင်း။/ ‘ရိုဟ်မကလိဂွံသြန်ညးကဵုဒါန်ရ။’ = ‘ပိုက်ဆံရတိုင်း သူအလှူပေးသည်။’
,ရိုဟ်ကၞက် (န) အမြစ်မကြီး။ ရေသောက်မြစ်။/ “လောဘမ္ဂးဂှ် မဒှ်ရိုဟ်ကၞက်လလေၚ်ရောၚ်။” (ဇ—၂၅၆။ အစွောံ။) = “လောဘမည်သည်ကား ပျက်စီးခြင်း၏အရင်းအမြစ်တည်း။”/ “အနတ္တပၠန်၊ လက်သန်ဗြာတ်ထဝ်။ ဟွံမွဲရိုဟ်ကၞက်၊ ကြက်ညိဟွံလဝ်။” (လိက်ပရေၚ်ခန္ဓ) = “အနတ္တသည် ရွှေငှက်ပျောပၚ်နှင့်ပမာတူ၏၊ အမြစ်မကြီးမရှိ၊ စိုးစဉ်းမျှအနှစ်မရှိ။”/ “မတုပ်တဴညံၚ်ရဴဆုမဟွံမွဲကဵုရိုဟ်ကၞက်ဂှ်ကီု။” (လိက်ပရေၚ်ခန္ဓ) = “ရေသောက်မြစ်မရှိသော သစ်ပင်နှင့်ပမာတူ၏။”
,ရိုဟ်ကျာ (န) အမြစ်ကြီးမဟုတ်သော အမြစ်ငယ်။
,ရိုဟ်ဂိုဟ် (ကြိ) ကော်ရော်သည်။ ရိုသေသည်။ ပူဇော်သည်။ ကြည်ညိုသည်။/ “ယြဴပူဂဵုမွဲ —ဆိုက်ဗ္ဒက်အဲပရဲညးတုဲ သဒှ်ရဴဂဴအဲပရဲရ။ သဒှ်ရိုဟ်ဂိုဟ်ညးမဇၞော်ဂုန်ရ။” (ဇ—၃၇။ အစွောံ။) =“ကြီးသောသူတို့အား ပူဇော်သောတရား­ လိမ္မာကုန်သော အကြင်သူတို့သည် ကြီးသောသူကိုပူဇော်ကုန်၏။” (ညောင်ကန်)/ “ဒဒှ်ဂှ် ပ္တီကောအဲတလညးဇၚ်မှာဲ သီုမရိုဟ်ဂိုဟ်ရ” တၠညးဗၟာဂး။ (အကြီုရာဇာဓိရာဇ်) = “ထိုအကြောင်းကို နောင်တော်ဇင်းမယ်မင်းအား ရိုသေစွာသိစေအပ်ပါ၏။”/ “ပ္ဍဲအစာမဇၞော်ကဵုဂုန်ဂှ် မှတ်ဖျေံက္ဍိုပ်ရိုဟ်ဂိုဟ် သၚ်ရိုဟ်ဗစဲပန်။” (ဓမ္မဒဳပနဳ။ မာံရွှေငိုး။) = “ကျေးဇူးကြီးသောဆရာသမားကို ဦးချရိုသေ၍ ပစ္စည်းလေးပါးထောက်ပံ့လော့။”/“(ညာတ်ရုပ်ခမဳတုဲ) သ္ဍိုက်မၠိုက်ရိုဟ်ဂိုဟ်၊ အိုဟ်တၟိုဟ်ဒှ်တဴ။” (လိက်ဟတ္ထိပါလ။ အစွောံ။) =“ရဟန်းရုပ်အသွင်ကိုမြင်၍ မြတ်နိုးကြည်ညိုဝမ်းမြောက်၏။”/ “ပွမရှ်ေသှ်ေရိုဟ်ဂိုဟ်ဟွံမွဲရသွံ။” (အာန်ဇုနာန်)
,ရိုဟ်စ (ကြိ) ၁။ ရေတွက်သည်။ အဓိကထားသည်။ ပဓါနပြုသည်။/ “မိမအဲဒမၠုမတ်ဝွံဂှ် သ္ဍိုက်ကောန်တုဲ ဟွံရိုဟ်စလမျီု (ဇကု) သွံ။ လမျီုကောန်ဂှ်ရောၚ် မရိုဟ်စသွံ။” (ဇ—၅၂၂။ အစွောံ။) =“ငါ၏မျက်မမြင်မိဘတို့သည် သားကိုချစ်၍ မိမိအသက်ကိုပင် မရေတွက်ဘဲလျှင် သား၏အသက်ကိုသာလျှင် ပဓါနပြု၏။”/ “အဲတုန်လေဝ် ဒှ်စမိန်စမာန်ဗြဴတုဲ ဟွံရိုဟ်စလမျီုတုဲ မဒးကၠုၚ်ကၠတ်ကေတ်ဒြပ်သၟိၚ်—။” (ဇ—၃ဝ၉။ အစွောံ။) = “အကြင်ငါသည် မိန်းမအလိုသို့လိုက်၍ ကိုယ့်အသက်ကို မရေတွက်ဘဲ (မင်း၏ဥစ္စာကို) ခိုး၏။” (ညောင်ကန်)/ ၂။ လိုက်နာသည်။ နာယူသည်။/ “ဂစေံဂမၠိုၚ်သၟေဟ် — လဟီုဒွးတၠပညာမဟီုဂှ်လေဝ်မိၚ်ဒၟံၚ် ဟွံရိုဟ်စ ဒၟံၚ်အာတုဲ မဒးအာစိုပ်ဂစိုတ်ဝွံရ။” (ဇ—၁၃၃။ အစွောံ။) = “ကျန်သောငှက်များသည် မှန်သောပညာရှိစကားကိုလည်း ကြားနေလျက် မနာယူကုန်ဘဲနေသဖြင့် သေခြင်းသို့ရောက်ရကုန်၏။”/ “ခဍာ်ဂှ် ၜိုန်အကၠဟ်ဆေဝ်ဒဝ်တဴကီုလေဝ် ဟွံဂွံရိုဟ်စကဵုဂလာန်အကၠဟ်တုဲ — ဒးပကာဂစိုတ်ရ။” (ဇ—၂ဝ၄။အစွောံ။) = “ထိုကျီးသည် တင်ကျီးကတားမြစ်သော်လည်း တင်ကျီး၏စကားကို မနာယူသဖြင့်သေရလေ၏။”
,ရိုဟ်စသာဲ (ကြိ) ပျားဖွပ်သည်။ (ပျားရည်ကိုရယူရန် ပျားကောင်များကို ပျားအုံမှဖယ်ရှားသည်။) /“ညံၚ်ရဴညးမအာရိုဟ်စသာဲကီု။” (ဇ—၃၆၆။ အစွောံ။) = “ပျားဖွပ်သောသူကဲ့သို့၄င်း—။”
,ရိုဟ်ဇုက် (န) သစ်မြစ်။ သစ်ဥ။/ “(ဗောဓိသတ်) လုပ်အာဂြိုပ်ဟေမဝန် ပခမဳဣသိ ဂၠာဲစသစ္ဆုရိုဟ်ဇုက်။” (ဇ—၁၇၃။ အစွောံ။) = “(ဘုရားလောင်းသည်) ဟိမဝန္တာသို့ဝင်ပြီးလျှင် ရသေ့ရဟန်းပြု၍ အလိုလိုသာလျှင်ဖြစ်သော သစ်မြစ်သစ်သီးဟူသော အာဟာရရှိသည်ဖြစ်၍ နေ၏။” (ညောင်ကန်)/ ရိုဟ်ဇုက်ကြုက်ပၞဟ် = သစ်မြစ်သစ်သီးမျိုးစုံ။/ ‘ပဒတဴပ္ဍဲဂြိုပ်ဟေမဝန် ဂၠာဲစရိုဟ်ဇုက်ကြုက်ပၞဟ်တုဲ ပတဴအဟာရ။’ (ဇ—၄၃၁။ အစွောံ။) = ‘ဟိမဝန္တာတော­နေထိုင်၍တောသစ်မြစ်သစ်သီးများကို အာဟာရအလို့ငှာ ရှာစား၏။’
,ရိုဟ်တာန် (ကြိ) တိုင်တန်းသည်။ တဖွဖွပြောဆိုသည်။ တတွတ်တွတ်ပြောဆိုသည်။ ဆိုမြည်သည်။/ “(ဣသိမသုန်ကၠံ သုၚ်ဒးသူရာဗ္ၜူသ္ၚဳအာ ကာလဗ္ၜူဟဲ တီဒုဟ်သူရာတုဲ) ကၠုၚ်ရိုဟ်တာန်ကဵုအ္စာရ။” (ဇ—၈၁။ အစွောံ။) = “ငါးရာကုန်သောရသေ့တို့သည် အရက်သောက်မိ၍ မူးမေ့သွားကြပြီး အမူးပြေလတ်သော် အရက်၏အပြစ်ကိုသိသဖြင့် ဆရာ့အား လာရောက်တိုင်တန်းကုန်၏။”/“ရိုဟ်တ္ၚဲကောအဲဟီုရိုဟ်တာန် ရိုဟ်တ္ၚဲကောအဲဟီုသၟာန်သၟုက် တ္ၚဲဏံမွဲတ္ၚဲဂှ် — မူပကောဂၞဴဂွံကၞပ်ဒၟံၚ်ကဵုအဲဍိက်ဗြဴ ဒှ်ရောလေဝ်ကော။” (ဇ—၄၈၅။ အစွောံ။) = “နေ့တိုင်းပင် မယ့်မောင်တတွတ်တွတ်စကားဆို၏။ နေ့တိုင်းပင် မယ့်မောင်ဆိုမြည်မေးမြန်း၏။ ဤယနေ့­မူ အဘယ်ကြောင့်မယ့်ကို မောင်ကြီးနှုတ်ဆိတ်၍ နေရက်ဘိသနည်း။”/ “ရိုဟ်တာန်သၟာန်သၟုက်၊ သုက္ခဒုက္ခ။” (လိက်မေဃသန်) = “သုခဒုက္ခကို ဆိုမြည်မေးမြန်းသည်။”/ “ခါဂှ်တြုံလွုဲ၊ တီသဳတုဲသၟတ်။ ဂလာန်ရိုဟ်တာန်၊ သၟာန်သၟုက်စံၜတ်။” (လိက်သၚ်ဂဒါ။ သဳလဝန္တ။) = “ယောကျာ်းမြတ်သည် မိမိ၏အဒေါ်ဖြစ်ကြောင်း သိရသောအခါ စကားတဖွဖွပြောဆိုလျက် ဆိုမြည်မေးမြန်း၏။”
,ရိုဟ်တၞံ၊ ရိုဟ်တၞမ် (န) အရင်းအမြစ်။ ရင်းမြစ်။
,ရိုဟ်ထဝဲါ (ကြိ) တင်ပျဉ်ခွေကိုဖြုတ်သည်။ တင်ပျဉ်ခွေထိုင်ရာမှထသည်။/ “တုပ်ဗီုသာ်လွာ၊ အစာဓမ္မ။ ရိုဟ်ထဝဲါဗက်၊ ချိုန်သက္ခဏ။ ဂံါစှ်ေကၠုၚ်ဟေၚ်၊ လၟေၚ်မူလ။” (လိက်ပထမဗောဓိ။ မၚ်ဍိက်လ။) = “တင်ပျဉ်ခွေကို ဖြုတ်ပြီးသည့်ခဏ­ မူလနေရာသို့ လှမ်းလျှောက်ဆင်းလာသော တရားဟောဆရာနှင့် ပုံဟန်တူ၏။”
,ရိုဟ်ဒဒှ် (နဝိ) —တိုင်း။/ ရိုဟ်ဒဒှ်တ္ၚဲ = နေ့စဉ်နေ့တိုင်း။/ ရိုဟ်ဒဒှ်သၞာံ = နှစ်စဉ်နှစ်တိုင်း။
,ရိုဟ်ပယတ်တေံ (ကြိဝိ) အခါတိုင်း။ ယခင်အခါများအတိုင်း။/ “ယွံမၞးတံ၊ ရိုဟ်ပယတ်တေံဂှ် အဲကၠောံပြာသာဒ်မွဲမွဲဂှ် အလုံဍုၚ်ဝွံ ကွဳကဵုကွဳ ဇံၚ်ကဵုဇံၚ် ကၞုက်ကၞာဲအာရောၚ်။ ပ္ဍဲတ္ၚဲဝွံဂှ် (မၞိဟ်ဟွံမွဲသွံ)” ကောန်သေဋ္ဌဳဂး။ (ဇ—၂၆၄။ အစွောံ။) = “အချင်းတို့၊ အခါတိုင်းဆိုလျှင် ပြာသာဒ်တစ်ဆောင်မှတစ်ဆောင်သို့ ငါကူးသွားသောကာလ­ လှည်းအဆင့်ဆင့် ညောင်စောင်းအဆင့်ဆင့်ဖြင့်မြို့အလုံးသည် ချောက်ချား၏။ ဤယနေ့­မူ လူမရှိပါလား” ဟုသူဋ္ဌေးသားဆို၏။
,ရိုဟ်ပလီု (ကြိ) ဖျက်သိမ်းသည်။ ဖြိုဖျက်သည်။/ “တာဲဗျုတြေံဂှ် ညးရိုဟ်ပလီုထောံရ။” = “တဲအိုဟောင်းကို သူဖြိုဖျက်လိုက်သည်။”/ “ဒပ်ပၞာန်သီအဝဵုဍုၚ်တုဲ ရိုဟ်ပလီုကၠေံအလဵုအသဳရ။” =“စစ်တပ်အာဏာသိမ်းပြီး အစိုးရကို ဖျက်သိမ်းလိုက်သည်။”
,ရိုဟ်ရာ (ကြိ) တွက်ကပ်သည်။ သူတစ်ပါးကိုမှီခိုသည်။ (?)/ “ဗွဲဒဒှ်မဟွံဂွံဟိုတ်မာဲအာဂှ်ဒှ်တုဲ လ္ပရိုဟ်ရာကဵုညးညိ။ နအလဵုဇကုဟေၚ် သၟာန်သၟုက်စံၜတ်စဳရေၚ်ညိ၊ လ္ပလၞုဟ်ညိ။” (ဇ—၅၂၁။ အစွောံ။) = “မမေ့မလျော့သည်ဖြစ်၍ သူတစ်ပါးကို မမှီခိုမတွက်ကပ်ဘဲ မိမိကိုယ်တိုင် မေးမြန်းစုံစမ်းစိစစ်၍ ပြုအပ်သည်ကိုပြုစီရင်ပါ။ မပျင်းရိပါနှင့်။”
,ရိုဟ်ရေၚ် (ကြိ) မြည်တမ်းသည်။/ “(သၟိၚ်တ္ၚေက်ဒးဓနက်တုဲ) သၟိက်ဟီုဂလာန်ရိုဟ်ရေၚ်တုဲ—။” (ဇ—၄၈၄။ အစွောံ။) = “(ကျော့ကွင်းမိသောကျေးမင်းသည်) မြည်တမ်းလိုရကား—။” (ညောင်ကန်)/ “ပရန္တပဂှ် ဖေက်ဘဲဂစိုတ်တုဲ သၟိက်ယာံရိုဟ်ရေၚ်တုဲ ဂလာန်မရဴဝွံသ္ဂးရ။” (ဇ—၄၁၆။ အစွောံ) = “ပရန္တပသည် သေဘေးကိုကြောက်သဖြင့် ငိုကြွေးမြည်တမ်းလို၍ ဤသို့သောစကားကို ဆို၏။”/ “(သမ္ၚေဟ်ဂှ် ကောန်ချိုတ်အာတုဲ) ဂလာန်မြဴဝွံ ဟီုရိုဟ်ရေၚ်ကြာန်ဒမာန်တဴရ။” (ဇ—၄၄၉။ အစွောံ။) = “ထိုသူကြွယ်သည် သားသေ၍ မြည်တမ်းယောင်ယမ်းလျက်နေ၏။”
,ရိုဟ်လၟိဟ် (ကြိ) ၁။ အရေအတွက်ကို ရေတွက်သည်။/ “ရိုဟ်လၟိဟ်မၞိဟ်တုဲရဟာ။” = “လူအရေအတွက်ကို ရေတွက်ပြီးပြီလား။”/ ၂။ အသုံးဝင်သည်။ အသုံးကျသည်။/ “မၞိဟ်ဏအ်မွဲဂှ်ဒၞာဲလဵုလေဝ်စကာဟွံဂွံရ။ ၜိုန်နွံဒၟံၚ်ကီုလေဝ် ဟွံရိုဟ်လၟိဟ်ရ။” = “ဤလူတစ်ယောက်သည် မည်သည့်နေရာတွင်မျှ သုံး၍မရပါ၊ ရှိနေငြားသော်လည်း အသုံးမဝၚ်ပါ။ (ရေတွက်၍မရပါ။)”
,ရိုဟ်သာဲ (ကြိ) ပျားဖွပ်သည်။/ “မၞိဟ်ဂစိုတ်သတ်၊ စိုတ်သၟာ်ယုတ်မာ။ စံၚ်ဂြိုပ်ရိုဟ်သာဲ၊ ဂၠိုၚ်ဒၞာဲအရာ။” (လိက်လက္ခဏပိ) = “သတ္တဝါအသက်ကိုသတ်သော ယုတ်မာသောစိတ်ရှိသောလူတို့သည်တောမီးရှို့ခြင်း ပျားဖွပ်ခြင်း အရာများစွာတို့ကို ပြုကုန်၏။”
,ရောအ် (ကြိ) ချောင်သည်။ ပွသည်။/ “ဇုက်ဒက်လဝ်ဂၠုၚ်ဂှ် ရောအ်ဒၟံၚ်ရ။” = “လှေကို ကြိုးနှင့်ချည်ထားသည်မှာ ချောင်နေသည်။”/ “တိဏအ်ရောအ်ခိုဟ်ကွေံကွေံရ။” = “ဤမြေသည် အလွန်ပွကောင်းသည်။”/ “ပ္ဍဲဖျုန်ကသအ်ဝွံ ရောအ်ဒၟံၚ်ညံၚ်ခၞော်သတ်ဗြဴ။” (အဘိဓမ္မတ္ထဒဳပနဳ။ ဂရိုက်သာံ။) = “အဆုတ်သားသည် အုန်းခွံကဲ့သို့ ပွနေသည်။”/
,ရောအ်ရောအ် (ကြိဝိ) ချောင်ချောင်ပွပွ။/ “ယာတ်ထဍိုဟ်ဍာ် မဒက်လဝ်ရောအ်ရောအ်။” (အဘိဓမ္မတ္ထဒဳပနဳ။ ဂရိုက်သာံ။) = “ချောင်ချောင်ချည်ထားသော ရေစစ်အဝတ်။”
,ရှာဲ (ကြိ) ကွဲကွာသည်။ ကင်းကွာသည်။ ဝေးကွာသည်။/ “(ဂစေံတၟံၜါဂှ်) ဟွံရှာဲနူရၚ်သ္ကံမွဲလှ်ေ။” (ဇ—၄၉၈။ အစွောံ။) = “ထိုဝန်လိုငှက်နှစ်ခုတို့သည် အချင်းချင်းမကင်းကွာစဖူး။”/ ‘သၟတ်ဗြဴဂှ်ရှာဲအာနူအဲ—။’ (ဇ—၆၃။ အစွောံ။) = ‘သတို့သမီးငယ်သည် ငါမှကွဲကွာသွား၏။’/ ‘ပိုဲဍိက်မရှာဲနူအ္စာမထ္ၜးမုတ်ဒွး။’ (ဇ—၈၁။ အစွောံ။) = ‘တပည့်တော်တို့သည် အမှားအမှန်ကို ထောက်ပြသောဆရာမှ ဝေးကွာခဲ့၏။’/ “ပ္ဍဲဋ္ဌာန်မဟွံဂွံရှာဲကဵုဂမြင်ကၞိဂှ် (ကၠဵုဂြိုပ်စၞာဲဂှ် ဒတဴဒၟံၚ်ရ။)” (ဇ—၁၂၈။ အစွောံ။) = “ထိုကြွက်တွင်းနှင့် မဝေးသောအရပ်­ ထိုမြေခွေးစဉ်းလဲသည် ရပ်နေ၏။”/‘သြာဲ’ နှင့်အတူတူ။
,ရှာဲဂမ်စိုတ် (ကြိ) ‘သြာဲဂမ်စိုတ်’ ရှု။
,ရှာဲဂမျိုၚ် (ကြိ) ‘သြာဲဂမျိုၚ်’ ရှု။
